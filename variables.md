# Переменные (Variables)
Переменная позволяет вам хранить любые значения по заданному идентификатору. Чтобы достичь этого, сначала необходимо объявить переменную. Это делается с помощью ключевого слова **let**, после которого выбирается идентификатор.
```javascript
let pouet

```
Теперь идентификатор pouet можно использовать в остальной части кода. Если значение не задано, при обращении к переменной отобразится undefined:
```javascript
console.log(pouet) // выведет undefined

```
Чтобы присвоить значение, используется оператор =:
```javascript
pouet = 42
console.log(pouet) // выведет 42

```
Значение переменной, объявленной через let, можно переназначить:
```javascript
pouet = 'hehe'
console.log(pouet) // теперь показывает новое значение

```
Объявление и присваивание можно выполнить в одной строке:
```javascript
let yo = 'lo'

```
### Правила для идентификаторов
Идентификаторы могут содержать только:
 * Цифры
 * Символ $
 * Заглавные буквы (A-Z)
 * Строчные буквы (a-z)
 * Нижнее подчеркивание _
**Примеры:**
 * let POUET_pouet — допустимо.
 * let pouet4 — допустимо.
 * POUET-pouet — **недопустимо** (дефис запрещен).
 * 4pouet — **недопустимо** (нельзя начинать с цифры).
**Важные примечания:**
 * В JavaScript стандартно использовать **camelCase** для идентификаторов.
 * Вы не можете использовать переменную до ее объявления.
## Константные переменные
Если значение переменной не должно меняться, используются константные переменные с ключевым словом **const** вместо **let**:
```javascript
const isConstant = true

```
Использование const защищает переменную от переназначения. Если попытаться присвоить константе новое значение, возникнет ошибка.
## Математические сокращения
Существуют сокращения для выполнения математических операций над переменными:
 * **someVar += 5** — эквивалентно someVar = someVar + 5 (если someVar было 5, станет 10).
 * **someVar *= 10** — эквивалентно someVar = someVar * 10 (если someVar было 10, станет 100).
