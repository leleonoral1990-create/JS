# 📚 Основы JavaScript: Конспект
### 1. 📝 Комментарии
Комментарии используются для заметок и пояснения логики. Они полностью игнорируются движком при выполнении кода.
 * **Однострочные:** начинаются с //
 * **Многострочные:** заключаются в /* ... */
```javascript
// Это однострочный комментарий

/* Это многострочный комментарий.
   Его удобно использовать, если нужно
   написать длинное пояснение. */

```
### 2. 💎 Типы данных
#### **Логические значения (Booleans)**
Самый простой тип, принимающий только два значения: true (истина) или false (ложь).
```javascript
console.log(true)
console.log(false)

```
#### **Числа (Numbers)**
В JS один тип данных для всех чисел.
 * Поддерживает стандартные операции: +, -, *, /.
 * % — остаток от деления.
 * Приоритет операций меняется круглыми скобками.
```javascript
console.log(42)           // Целое
console.log(21 + 21)      // Сложение
console.log(1042 % 50)    // Остаток (42)
console.log(4.2 * (5 + 5)) // Скобки имеют приоритет

```
#### **Строки (Strings)**
Пишутся в одинарных ', двойных " или обратных ` кавычках.
```javascript
console.log('Hello World!')
console.log("I'm such a nice boy") // Двойные кавычки позволяют использовать ' внутри
console.log("It's time to escape !!") // Экранирование через обратный слэш
console.log('Hello\nWorld!')     // \n — перенос строки

```
### 3. ⚠️ Специальные значения
| Значение | Описание |
|---|---|
| **null** | Намеренное отсутствие значения. |
| **undefined** | Значение не присвоено (дефолтное состояние). |
| **NaN** | "Not a Number" — возникает при ошибках вычислений. |
| **Infinity** | Математическая бесконечность. |
> **Совет:** Лучше избегать null и использовать undefined для обозначения отсутствующих данных.
> 
### 4. 🔀 Приведение типов и сравнения
JavaScript часто пытается автоматически преобразовать типы, что может привести к странным результатам:
```javascript
console.log('21' + 21)    // "2121" (конкатенация)
console.log('21' * 2)     // 42 (строка стала числом)
console.log('21' * true)  // 21 (true = 1)
console.log('21' * false) // 0 (false = 0)

```
#### **Правила сравнения**
Всегда используйте **строгое равенство ===**, чтобы избежать ошибок приведения типов.
 * === — Равенство (значение и тип должны совпадать).
 * !== — Неравенство.
 * ! — Отрицание (инвертирует логическое значение).
```javascript
console.log('5' == 5)   // true (неявное приведение — опасно!)
console.log('5' === 5)  // false (строгая проверка — безопасно)

```
### 5. 🔬 Особенности вычислений
В JavaScript используется стандарт **IEEE 754** (64-битные числа с плавающей запятой).
 1. **Точность:** Целые числа точны до 9 \times 10^{15}.
 2. **Дроби:** Из-за особенностей двоичной системы некоторые вычисления неточны.
```javascript
console.log(0.1 + 0.2) // Результат: 0.30000000000000004

```
### 💡 Truthy и Falsy значения
Некоторые не-логические значения ведут себя как false в условиях:
 * 0, "" (пустая строка), null, undefined, NaN.
 * Все остальные значения считаются за true.
```javascript
console.log(!0)       // true
console.log(!'text')  // false

```
