# Основы JavaScript: Справочник
## 1. Комментарии
Комментарии используются для заметок и пояснения логики. Они полностью игнорируются движком при выполнении кода.
 * **Однострочные**: начинаются с //.
 * **Многострочные**: начинаются с /* и заканчиваются */.
```javascript
// Однострочный комментарий

/* Многострочный комментарий
   для подробных описаний */

```
## 2. Типы данных
### Логические значения (Booleans)
Тип данных, принимающий только два значения: true (истина) или false (ложь).
```javascript
console.log(true)
console.log(false)

```
### Числа (Numbers)
В JavaScript используется один числовой тип для целых и дробных чисел.
 * Поддерживает операции: +, -, *, /, % (остаток от деления).
 * Приоритет операций управляется круглыми скобками.
```javascript
console.log(42)           // Целое число
console.log(21 + 21)      // Сложение
console.log(1042 % 50)    // Остаток от деления
console.log(4.2 * (5 + 5)) // Скобки имеют приоритет

```
### Строки (Strings)
Текст заключается в одинарные ', двойные " или обратные ` кавычки.
```javascript
console.log('Hello World!')
console.log("I'm such a nice boy")    // Двойные кавычки удобны, если внутри есть '
console.log("It's time to escape !!") // Экранирование символа \
console.log('Hello\nWorld!')          // \n — перенос строки

```
## 3. Специальные значения
| Значение | Описание |
|---|---|
| **null** | Намеренное отсутствие значения. |
| **undefined** | Значение не присвоено или временно отсутствует. |
| **NaN** | "Not a Number" — результат некорректной математической операции. |
| **Infinity** | Математическая бесконечность (бывает и -Infinity). |
*Рекомендуется использовать undefined вместо null для обозначения отсутствия данных.*
## 4. Приведение типов и сравнения
При операциях с разными типами данных JavaScript выполняет автоматическое преобразование:
```javascript
console.log('21' + 21)    // "2121" (преобразование в строку)
console.log('21' * 2)     // 42 (преобразование в число)
console.log('21' * true)  // 21 (true приравнивается к 1)
console.log('21' * false) // 0 (false приравнивается к 0)

```
### Операторы сравнения
Результатом сравнения всегда является логическое значение.
 * === : Строгое равенство (проверяет и значение, и тип). **Рекомендуется к использованию.**
 * !== : Строгое неравенство.
 * ! : Логическое "НЕ" (инверсия значения).
```javascript
console.log('5' == 5)   // true (неявное приведение, часто ведет к ошибкам)
console.log('5' === 5)  // false (строгая проверка)

```
## 5. Особенности вычислений (IEEE 754)
Числа в JavaScript представлены в 64-битном формате с плавающей запятой.
 1. **Точность целых чисел**: Гарантирована до 9 \times 10^{15}.
 2. **Погрешность дробей**: Из-за особенностей двоичной системы некоторые десятичные дроби вычисляются неточно.
```javascript
console.log(0.1 + 0.2) // Результат: 0.30000000000000004

```
## 6. Логический контекст (Truthy / Falsy)
Значения, которые интерпретируются как false в логических условиях:
 * 0, "" (пустая строка), null, undefined, NaN.
Все остальные значения в JavaScript воспринимаются как true.
```javascript
console.log(!0)       // true
console.log(!'text')  // false

```
