# Тернарный оператор (Ternary Operator)

Тернарный оператор — самый простой способ выразить условие в коде. Он позволяет выбрать одно из двух выражений в зависимости от того, истинно условие или ложно.

### Синтаксис

Общая структура оператора выглядит так:
**условие ? выражение_если_истина : выражение_если_ложь**

```javascript
count > 9000 ? 'OVER 9000!!' : 'not over 9000'
```

**Логика работы:**
1. Проверяется **условие** (count > 9000).
2. Если **да** (истина): возвращается строка 'OVER 9000!!'.
3. Если **нет** (ложь): возвращается строка 'not over 9000'.

Оператор состоит из 3 выражений и 2 символов:
* **Первое** — условие, за которым следует знак `?`.
* **Второе** — выражение, выполняемое, если условие истинно (truthy), за ним следует `:`.
* **Третье** — выражение, выполняемое, если условие ложно (falsy).

---

### Примеры использования

Функция для проверки «истинности» (truthy) значения:

```javascript
const isTruthy = (value) => (value ? 'yes' : 'no')

console.log(isTruthy(5))      // 'yes'
console.log(isTruthy(0))      // 'no'
console.log(isTruthy([]))     // 'yes' (пустой массив — это истина)
console.log(isTruthy(''))     // 'no' (пустая строка — это ложь)
console.log(isTruthy(null))   // 'no'
```

### Многострочная запись
Для длинных выражений тернарный оператор можно разбивать на несколько строк для лучшей читаемости:

```javascript
const isTruthyVerbose = (value) =>
  value
    ? 'It appears to be something the truth can be find in'
    : 'no, It is not anything close to the truth'

console.log(isTruthyVerbose({}))        // 'It appears to be something...'
console.log(isTruthyVerbose())          // 'no, It is not anything close...'
console.log(isTruthyVerbose(undefined)) // 'no, It is not anything close...'
```

---

### Реализация встроенных функций

Используя тернарный оператор, можно переписать стандартную функцию **Math.min**:

```javascript
const min = (a, b) => (a < b ? a : b)

console.log(min(4, 29)) // 4
console.log(min(4, 2))  // 2
```

**Разбор кода:**
Мы объявляем константную переменную `min` и присваиваем ей функцию с двумя аргументами `a` и `b`. Если `a` меньше `b`, функция возвращает `a`, в противном случае возвращается `b`.
