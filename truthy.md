# Truthy значения в JavaScript

В JavaScript **truthy** (истинное) значение — это любое значение, которое приводится к `true` (истине) при вычислении в логическом (boolean) контексте (например, внутри условия `if`).

Главное правило: **Все значения в JavaScript являются truthy, кроме небольшого списка falsy-значений.**

## Список Falsy-значений (Ложных)
Чтобы легко запомнить `truthy`, достаточно выучить исключения. Следующие значения являются `falsy` (приводятся к `false`):
* `false` (само логическое "ложь")
* `0`, `-0` (число ноль)
* `0n` (ноль в формате BigInt)
* `""`, `''`, ` `` ` (пустая строка)
* `null` (отсутствие значения)
* `undefined` (неопределенное значение)
* `NaN` (не число)
* `document.all` (историческое исключение в браузерах)

**Абсолютно всё остальное — это truthy.**

## Примеры Truthy-значений
Даже если значения кажутся "пустыми" или содержат слово "false", в JavaScript они будут считаться истинными.

```javascript
// Следующие условия сработают (код внутри выполнится), 
// так как все эти значения — truthy:

if (true);
if ({});             // Пустой объект — это truthy!
if ([]);             // Пустой массив — это truthy!
if (42);             // Любое число, кроме 0 и NaN
if (-42);            // Отрицательные числа тоже truthy
if (3.14);           // Дробные числа
if (Infinity);       // Бесконечность
if (-Infinity);
if ("0");            // Строка, содержащая ноль (строка не пустая)
if ("false");        // Строка со словом "false" (строка не пустая)
if (new Date());     // Любой созданный объект
if (12n);            // BigInt число (кроме 0n)
```

## Как это работает с операторами
Приведение типов (Type coercion) активно используется логическими операторами. Например, оператор логического И (`&&`) вернет второй операнд, если первый является `truthy`:

```javascript
// Так как true — это truthy, возвращается второе значение:
const result1 = true && "dog"; 
console.log(result1); // "dog"

// Так как пустой массив [] — это truthy, возвращается второе значение:
const result2 = [] && "dog"; 
console.log(result2); // "dog"
```
