# Итоговая лекция: Мир Объектов в JavaScript

Объекты позволяют нам хранить данные в виде пар `ключ: значение`. Однако у объектов нет встроенных методов для фильтрации или трансформации (как `map` или `filter` у массивов). Именно здесь на сцену выходят методы `entries` и `fromEntries`.


### 1. Глобальный объект `Object`
Это «прародитель» всех объектов. Большинство полезных функций являются его **статическими методами**. Это значит, что мы вызываем их через имя самого объекта: `Object.имяМетода(целевойОбъект)`.

### 2. `Object.entries(obj)` — Разборка
Этот метод берет объект и «раскладывает» его на массив массивов. Каждая пара становится маленьким массивом из двух элементов.

* **Зачем:** Чтобы получить доступ к мощным методам массивов (`forEach`, `filter`, `map`).

### 3. `Object.fromEntries(iterable)` — Сборка
Это обратная операция. Она берет массив пар и «склеивает» их обратно в один объект.

* **Зачем:** Чтобы после обработки данных массивом вернуть их в исходный формат объекта.

## 💻 Комплексный пример: Обработка данных

Представим, что у нас есть объект со стоимостью товаров, и нам нужно:
1.  Оставить только товары дороже 100.
2.  Сделать скидку 20% на оставшиеся.
3.  Вернуть результат обратно в объект.

```javascript
// Исходные данные
const products = {
    "Keyboard": 150,
    "Mouse": 40,
    "Monitor": 300,
    "USB-Hub": 25
};

// 1. Превращаем объект в массив (Object.entries)
// Результат: [ ["Keyboard", 150], ["Mouse", 40], ... ]
const entries = Object.entries(products);

// 2. Используем методы массивов для обработки
const processedData = entries
    // Оставляем товары дороже 100
    .filter(([name, price]) => price > 100)
    // Применяем скидку 20% к цене
    .map(([name, price]) => [name, price * 0.8]);

// 3. Собираем массив обратно в объект (Object.fromEntries)
const saleProducts = Object.fromEntries(processedData);

console.log("Товары со скидкой:", saleProducts);
// Вывод: { Keyboard: 120, Monitor: 240 }
```

## 🛠 Полезные инструменты "в связке"

Для полной картины стоит помнить еще о двух методах, которые часто используются вместе с `entries`:

* **`Object.keys(obj)`**: Если вам нужны только названия свойств (ключи). Возвращает массив строк.
* **`Object.values(obj)`**: Если вам нужны только данные (значения). Например, чтобы быстро посчитать сумму всех цен через `reduce`.


### Пример быстрой проверки:
```javascript
const user = { name: "Admin", role: "Superuser" };

// Проверка на пустоту объекта
const isEmpty = Object.keys(user).length === 0; // false

// Сбор всех значений в строку
const infoString = Object.values(user).join(", "); // "Admin, Superuser"
```

## Резюме

Работа с объектами в современном JavaScript строится на **цикле трансформации**:
1.  **`Object.entries()`** — открываем дверь в мир массивов.
2.  **`filter/map/reduce`** — выполняем любую логику.
3.  **`Object.fromEntries()`** — закрываем дверь, возвращаясь к структуре объекта.

Эта связка методов позволяет писать чистый, читаемый код без использования громоздких циклов `for...in`.
