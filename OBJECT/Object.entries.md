# Метод Object.entries()

Метод **`Object.entries()`** возвращает массив пар `[ключ, значение]` собственных перечисляемых свойств указанного объекта. Если `Object.keys()` дает нам только «заголовки», а `Object.values()` — только «содержимое», то `entries()` дает нам **всё и сразу** в удобном для перебора формате.



---

## 1. Синтаксис и результат

```javascript
const result = Object.entries(obj);
```

**Что получается на выходе:**
Массив массивов. Каждый вложенный массив состоит ровно из двух элементов: `[0]` — имя свойства (строка), `[1]` — его значение.

**Пример:**
```javascript
const assets = {
    cash: 5000,
    equity: 12000,
    crypto: 2000
};

console.log(Object.entries(assets));
// Вывод: [ ["cash", 5000], ["equity", 12000], ["crypto", 2000] ]
```

---

## 2. Зачем это нужно? (Основные сценарии)

### А. Удобный перебор в цикле
Вместо старого `for...in` (который тянет лишние свойства из прототипов) мы используем `Object.entries()` в связке с современным циклом `for...of` и деструктуризацией.

```javascript
const salaries = {
    "Иван": 1000,
    "Анна": 1500,
    "Петр": 1200
};

for (const [name, salary] of Object.entries(salaries)) {
    console.log(`${name} получает ${salary}$`);
}
```

### Б. Трансформация объектов (Filter / Map)
Поскольку `Object.entries()` возвращает **массив**, мы можем использовать мощные методы массивов (`filter`, `map`, `reduce`) для изменения структуры объекта.

```javascript
const prices = { apple: 2, orange: 4, meat: 10 };

// Увеличим все цены в 2 раза и вернем обратно в объект
const doubledPrices = Object.fromEntries(
    Object.entries(prices).map(([key, value]) => [key, value * 2])
);

console.log(doubledPrices); // { apple: 4, orange: 8, meat: 20 }
```
*(Метод `Object.fromEntries()` — это антипод `entries()`, он собирает массив пар обратно в объект).*

### В. Преобразование в Map
Объект `Map` в JavaScript гораздо лучше подходит для хранения данных, где ключи могут быть чем угодно, а не только строками. `Object.entries()` — это «мостик» для перехода к `Map`.

```javascript
const user = { id: 1, name: "Admin" };
const userMap = new Map(Object.entries(user));
```

---

## 3. Сравнение "Святой Троицы" методов Object

| Метод | Что возвращает | Когда использовать |
| :--- | :--- | :--- |
| **`Object.keys()`** | `['key1', 'key2']` | Нужно проверить наличие ключей или просто их список. |
| **`Object.values()`** | `[val1, val2]` | Нужно посчитать сумму значений (например, баланс). |
| **`Object.entries()`** | `[['k1', 'v1'], ['k2', 'v2']]` | Когда важна связь ключа и значения при обработке. |

---

## Нюансы и "грабли"

1.  **Порядок свойств**: В современных браузерах порядок элементов в массиве соответствует порядку их перечисления в объекте. Однако, если ключи — это целые числа (например, `"1"`, `"2"`), браузер отсортирует их по возрастанию.
2.  **Только собственные свойства**: Метод игнорирует свойства, которые объект унаследовал от своего прототипа.
3.  **Символы**: Если у объекта есть ключи типа `Symbol`, `Object.entries()` их проигнорирует (для них нужен `Object.getOwnPropertySymbols()`).
