# Object
Если DOM — это структура здания, то **Объекты (Objects)** — это всё, что находится внутри: мебель, техника, чертежи и даже правила, по которым это здание работает.

В JavaScript почти всё является объектом. Объект — это набор свойств (ключей) и их значений.

---

## 🧱 Основы: Создание и доступ

Объекты позволяют группировать данные. Вместо того чтобы хранить имя, возраст и профессию в разных переменных, мы создаем одну сущность.



### 1. Создание
```javascript
// Литерал объекта (самый частый способ)
const user = {
    name: "Eleonora",
    role: "Accountant",
    "years of experience": 10 // Ключи с пробелами пишутся в кавычках
};
```

### 2. Доступ к свойствам
* **Через точку (`.`)**: `user.name` — когда мы заранее знаем имя ключа.
* **Через скобки (`[]`)**: `user["years of experience"]` — когда ключ содержит пробелы или хранится в переменной.

---

## 🛠️ Статические методы Object

Это инструменты, которые лежат в «коробке» самого глобального объекта `Object`. Они помогают нам исследовать и трансформировать данные.

| Метод | Что делает | Результат |
| :--- | :--- | :--- |
| **`Object.keys(obj)`** | Возвращает массив всех ключей. | `["name", "role", ...]` |
| **`Object.values(obj)`** | Возвращает массив всех значений. | `["Eleonora", "Accountant", ...]` |
| **`Object.entries(obj)`** | Возвращает массив пар `[ключ, значение]`. | `[["name", "Eleonora"], [...]]` |
| **`Object.assign(dest, src)`** | Копирует свойства из одного объекта в другой. | Измененный объект |
| **`Object.freeze(obj)`** | «Замораживает» объект: нельзя добавлять, удалять или менять свойства. | Неизменяемый объект |

## 🏗️ Продвинутые приемы

### 1. Деструктуризация (Destructuring)
Позволяет быстро «вытащить» нужные данные из объекта в отдельные переменные.
```javascript
const settings = { theme: 'dark', fontSize: 16, showSidebar: true };

const { theme, fontSize } = settings;
console.log(theme); // 'dark'
```

### 2. Spread-оператор (`...`)
Используется для создания копий объекта или объединения нескольких объектов.
```javascript
const baseInfo = { id: 1, type: 'user' };
const detailedInfo = { ...baseInfo, name: 'Alex', active: true };
// Создан новый объект, объединивший всё вышеперечисленное
```

## 🚀 Практический пример: Обработка данных

Давай свяжем это с твоей предыдущей темой. Представь, что мы получаем данные о пользователях и нам нужно их отфильтровать и подготовить для отображения в DOM.

```javascript
const userData = {
    id: 101,
    firstName: "Sergey",
    lastName: "Pak",
    status: "active",
    preferences: {
        lang: "ru",
        theme: "system"
    }
};

// 1. Проверяем наличие свойства
if (Object.hasOwn(userData, 'status')) {
    console.log("Статус пользователя определен");
}

// 2. Превращаем объект в массив для итерации (например, для создания таблицы)
Object.entries(userData).forEach(([key, value]) => {
    if (typeof value !== 'object') {
        console.log(`${key.toUpperCase()}: ${value}`);
    }
});

// 3. Защита данных (Immutable)
const config = Object.freeze({
    apiUrl: "https://api.example.com",
    timeout: 5000
});

config.timeout = 1000; // Ошибка (в строгом режиме) или просто проигнорируется
```

## 🔍 Важные нюансы

1.  **Копирование по ссылке**: Объекты в JS передаются по ссылке. Если ты напишешь `const a = {}; const b = a;`, то изменив `b`, ты изменишь и `a`. Для создания «честной» копии используй `{ ...a }` или `Object.assign()`.
2.  **Прототипы**: У каждого объекта есть «скрытый родитель» (`__proto__`), от которого он наследует методы (например, `.toString()`). Это основа объектно-ориентированного программирования в JavaScript.
3.  **JSON**: Объекты легко превращаются в строку для отправки на сервер (`JSON.stringify(obj)`) и обратно в объект (`JSON.parse(str)`).
