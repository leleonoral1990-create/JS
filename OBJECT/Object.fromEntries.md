# Метод Object.fromEntries()

Если `Object.entries()` — это разборка шкафа на отдельные детали, то **`Object.fromEntries()`** — это инструкция по его сборке обратно. Этот метод принимает список пар «ключ-значение» и превращает их в полноценный объект. Это своего рода «антипод» для `entries()`, и вместе они составляют мощный дуэт для трансформации данных.



---

## 1. Синтаксис

```javascript
const obj = Object.fromEntries(iterable);
```

**Параметры:**
* **`iterable`**: Перечисляемый объект (например, `Array` или `Map`), содержащий объекты, которые сами являются перечисляемыми и имеют два элемента: `[ключ, значение]`.

**Возвращаемое значение:**
* Новый объект, свойства которого определены парами из итерируемого объекта.

---

## 2. Основные сценарии использования

### А. Преобразование Map в Object
`Map` удобен для частых операций записи и чтения, но иногда сторонние библиотеки или API требуют именно простой объект `{}`.

```javascript
const map = new Map([ ['apples', 10], ['oranges', 20] ]);
const obj = Object.fromEntries(map);

console.log(obj); // { apples: 10, oranges: 20 }
```

### Б. Работа с URL-параметрами
Метод идеально подходит для быстрой конвертации параметров строки запроса (query string) в удобный объект.

```javascript
const paramsString = 'category=books&author=tolstoy&sort=new';
const searchParams = new URLSearchParams(paramsString);

const paramsObj = Object.fromEntries(searchParams);
console.log(paramsObj); // { category: "books", author: "tolstoy", sort: "new" }
```

### В. Трансформация существующего объекта
Это самый элегантный способ изменить объект: «разобрать» его в массив, применить фильтрацию или маппинг, и «собрать» обратно.

```javascript
const students = {
    "Alice": 85,
    "Bob": 40,
    "Charlie": 92
};

// Оставим только тех, у кого балл выше 50 (Passed)
const passedStudents = Object.fromEntries(
    Object.entries(students).filter(([name, score]) => score > 50)
);

console.log(passedStudents); // { Alice: 85, Charlie: 92 }
```

---

## 3. Сравнение entries и fromEntries

| Метод | Входные данные | Результат | Направление |
| :--- | :--- | :--- | :--- |
| **`Object.entries()`** | Объект `{}` | Массив `[[k, v], ...]` | Объект → Массив |
| **`Object.fromEntries()`** | Массив/Итератор `[[k, v], ...]` | Объект `{}` | Массив → Объект |

---

## ⚠️ Важные нюансы

1.  **Дубликаты ключей**: Если в итерируемом объекте один и тот же ключ встречается несколько раз, в итоговый объект попадет **последнее** значение.
    * `Object.fromEntries([ ['a', 1], ['a', 2] ])` → `{ a: 2 }`
2.  **Типы ключей**: Хотя в `Map` ключами могут быть объекты или функции, при использовании `fromEntries` все ключи будут приведены к строкам (как и в обычном объекте JS).
3.  **Поддержка**: Метод появился в стандарте ES2019. В совсем древних браузерах (вроде IE11) он не сработает без полифила, но для современной разработки это стандарт.

---

## Резюме
Используйте `Object.fromEntries()`, когда у вас есть массив данных и вам нужно быстро превратить его в объект для более удобного доступа к свойствам по имени. В паре с `Object.entries()` это позволяет манипулировать объектами так же легко, как мы привыкли манипулировать массивами.
