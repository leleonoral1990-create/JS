## 💎 Что такое Object?

**`Object`** — это встроенный конструктор, который лежит в основе практически всех структур данных в языке. Объект представляет собой коллекцию свойств типа «ключ: значение», где ключ — это строка (или символ), а значение может быть чем угодно.



### Способы создания
1.  **Литерал объекта** (самый частый): `const obj = {};`
2.  **Конструктор**: `const obj = new Object();`
3.  **Метод `Object.create(proto)`**: создает новый объект с указанным прототипом.

---

## 🛠️ Главный инструментарий (Статические методы)

Статические методы вызываются напрямую у `Object`, а не у конкретного экземпляра. Это ваш набор инструментов для анализа и трансформации данных.

| Группа | Методы | Описание |
| :--- | :--- | :--- |
| **Анализ ключей/значений** | `keys()`, `values()`, `entries()` | Превращают части объекта в массивы для удобного перебора. |
| **Создание/Копирование** | `assign()`, `fromEntries()` | Копируют свойства или собирают объект из массива пар. |
| **Безопасность/Защита** | `freeze()`, `seal()`, `preventExtensions()` | Запрещают изменять, добавлять или удалять свойства. |
| **Прототипы** | `getPrototypeOf()`, `setPrototypeOf()` | Работают с «ДНК» объекта — его наследованием. |

---

## 🧬 Прототипное наследование

Каждый объект в JavaScript имеет скрытое свойство `[[Prototype]]`, которое ссылается либо на другой объект, либо на `null`. Это механизм, благодаря которому объекты могут «пользоваться» методами своих предков.



> **Важно:** Поиск свойства идет «вверх» по цепочке. Если вы вызываете `.toString()` у своего объекта, JS сначала ищет его внутри объекта, а не найдя — идет в `Object.prototype`.

## 🏗️ Продвинутое управление свойствами

Вы можете не просто добавлять свойства, но и тонко настраивать их поведение с помощью **дескрипторов**.

```javascript
const user = {};

Object.defineProperty(user, 'id', {
  value: 123,
  writable: false,    // Нельзя перезаписать
  enumerable: true,   // Будет виден в циклах
  configurable: false // Нельзя удалить или перенастроить
});

user.id = 456; // Ошибка в строгом режиме, значение останется 123
```

## 🚀 Комплексный пример: Управление данными

Давай представим, что ты разрабатываешь систему для хранения данных о сотрудниках. Нам нужно объединить несколько объектов, защитить ID и подготовить данные для экспорта.

```javascript
// 1. Исходные данные
const baseProfile = { role: 'Accountant', department: 'Finance' };
const personalInfo = { name: 'Eleonora', city: 'Astana' };

// 2. Слияние объектов (Object.assign или Spread)
const employee = Object.assign({ id: Date.now() }, baseProfile, personalInfo);

// 3. Защита от случайных изменений (Object.seal позволяет менять значения, но не структуру)
Object.seal(employee);

employee.role = 'Senior Accountant'; // Разрешено
delete employee.name;              // Проигнорируется (свойство не удалится)
employee.bonus = 500;              // Проигнорируется (новые свойства не добавятся)

// 4. Проверка состояния
console.log('Можно ли менять структуру?', !Object.isSealed(employee));

// 5. Итерация и трансформация
const report = Object.entries(employee)
  .filter(([key, val]) => typeof val === 'string')
  .map(([key, val]) => `${key.toUpperCase()}: ${val}`);

console.log(report);
```

## ⚡️ Тонкие моменты
* **`Object.hasOwn(obj, prop)`**: Самый современный и безопасный способ проверить, принадлежит ли свойство самому объекту, а не его прототипу. Пришел на замену `hasOwnProperty`.
* **Сравнение**: Помни, что `{} === {}` — это всегда `false`. Объекты сравниваются по ссылке в памяти, а не по содержимому. Для сравнения «по значениям» нужно либо писать свою функцию, либо использовать `JSON.stringify()`.
