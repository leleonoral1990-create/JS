# Math.abs()

---

## Описание
Статический метод **Math.abs()** возвращает абсолютное значение числа (модуль). Он делает любое отрицательное число положительным, а положительные числа и ноль оставляет без изменений.

Поскольку `Math` не является конструктором, `abs()` — это статический метод. Вы всегда используете его как `Math.abs(x)`, а не как метод созданного экземпляра.

---

## Синтаксис

```javascript
Math.abs(x)
```

**Параметры:**
* **x**: Числовое значение.

**Возвращаемое значение:**
* Абсолютное значение `x`. Если `x` отрицательное или `-0`, возвращается противоположное ему положительное число. В остальных случаях возвращается сам `x`. Результат всегда является положительным числом или `0`.

---

## Приведение типов (Coercion)
Метод автоматически приводит переданный параметр к числу. Если значение невозможно привести к числу, метод вернет `NaN`.

| Входное значение | Результат | Комментарий |
| :--- | :--- | :--- |
| `"-1"` | **1** | Строка преобразуется в число |
| `null` | **0** | `null` приводится к 0 |
| `""` (пустая строка) | **0** | Пустая строка приводится к 0 |
| `[]` (пустой массив) | **0** | Пустой массив приводится к 0 |
| `[2]` | **2** | Массив с одним числом приводится к этому числу |
| `[1, 2]` | **NaN** | Массив с несколькими элементами не приводится к числу |
| `{}` | **NaN** | Объект не приводится к числу |
| `"string"` | **NaN** | Нечисловая строка |
| `undefined` / без аргумента | **NaN** | |

---

## Примеры

### Базовое использование
```javascript
Math.abs(-Infinity); // Infinity
Math.abs(-1);        // 1
Math.abs(-0);        // 0
Math.abs(0);         // 0
Math.abs(1);         // 1
Math.abs(Infinity);  // Infinity
```

### Реализация через тернарный оператор
В качестве упражнения `Math.abs` можно представить так:
```javascript
const myAbs = (x) => (x < 0 ? -x : x);
```
