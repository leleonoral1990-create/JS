# Метод String.prototype.split()

Метод `split()` разбивает строку на массив подстрок на основании заданного разделителя и возвращает этот массив.



## Синтаксис

```javascript
split(separator)
split(separator, limit)
```

### Параметры
1.  **`separator`** (необязательно): Определяет, где именно должен происходить разрыв строки.
    * Может быть **строкой** или **регулярным выражением**.
    * Если передан как пустая строка `""`, исходная строка будет разбита на массив отдельных символов (точнее, кодовых единиц UTF-16).
    * Если параметр опущен или не найден в строке, возвращается массив, содержащий одну целую строку.
2.  **`limit`** (необязательно): Целое число, ограничивающее количество элементов в массиве. Метод прекращает работу, как только будет достигнут лимит, даже если в строке остались разделители.

### Возвращаемое значение
* Массив строк, разделенных в тех местах, где встретился `separator`.

---

## Примеры использования

### 1. Базовое разбиение по пробелам и символам
```javascript
const str = 'The quick brown fox';

const words = str.split(' ');
console.log(words); // ["The", "quick", "brown", "fox"]

const chars = str.split('');
console.log(chars[0]); // "T"
```

### 2. Использование лимита
```javascript
const str = 'один-два-три-четыре';
const limited = str.split('-', 2);

console.log(limited); // ["один", "два"]
```

### 3. Особенности при отсутствии разделителя
```javascript
const str = 'Hello world';

console.log(str.split());     // ["Hello world"] (целая строка в массиве)
console.log(str.split('z'));  // ["Hello world"] (разделитель не найден)
```

## Важные нюансы

1.  **Немутирующий метод:** `split()` не изменяет исходную строку, а создает и возвращает новый массив.
2.  **Связка со `join()`:** Эти методы часто используются вместе для замены частей строки.
    ```javascript
    // Замена всех дефисов на точки
    const date = '2026-04-25';
    const formatted = date.split('-').join('.'); // "2026.04.25"
    ```
3.  **Пустые строки в результате:** Если разделитель находится в самом начале или в самом конце строки, массив будет содержать пустые строки на соответствующих позициях.
    ```javascript
    const str = '.test.';
    console.log(str.split('.')); // ["", "test", ""]
    ```
4.  **Разбиение по регулярному выражению:** Позволяет использовать сложные правила, например, разбиение по нескольким разным символам одновременно.
    ```javascript
    const names = 'Harry;John,Alice';
    const splitNames = names.split(/[;,]/); // ["Harry", "John", "Alice"]
    ```
