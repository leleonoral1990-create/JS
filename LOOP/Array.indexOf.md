# Метод Array.prototype.indexOf()

Метод `indexOf()` возвращает первый индекс, по которому данный элемент может быть найден в массиве, или `-1`, если такой элемент отсутствует.



## Синтаксис

```javascript
indexOf(searchElement)
indexOf(searchElement, fromIndex)
```

**Параметры:**
1.  **`searchElement`**: Элемент, поиск которого ведется в массиве.
2.  **`fromIndex`** (необязательно): Индекс, с которого следует начинать поиск. 
    * Если индекс отрицательный, он отсчитывается от конца массива (например, `-1` — это последний элемент).
    * Если индекс больше или равен длине массива, возвращается `-1` (массив не просматривается).

**Возвращаемое значение:**
* Первый индекс элемента в массиве; `-1`, если не найден.

---

## Особенности работы

### 1. Строгое сравнение
Метод использует алгоритм **строгого равенства** (`===`). Это означает, что он не будет пытаться привести типы данных. Также стоит помнить, что `indexOf` не сможет найти `NaN`.

```javascript
const array = [1, '2', 3];

console.log(array.indexOf(2));   // -1 (число 2 не равно строке '2')
console.log(array.indexOf('2')); // 1
```

### 2. Поиск первого вхождения
Если элемент встречается в массиве несколько раз, `indexOf` вернет только индекс самого первого из них (двигаясь слева направо).

```javascript
const beasts = ['ant', 'bison', 'camel', 'duck', 'bison'];

console.log(beasts.indexOf('bison')); // 1
```

### 3. Использование `fromIndex`
Можно ограничить область поиска, указав начальную позицию.

```javascript
const numbers = [2, 5, 9, 2];

console.log(numbers.indexOf(2));     // 0
console.log(numbers.indexOf(2, 1));  // 3 (начинает поиск с индекса 1)
console.log(numbers.indexOf(2, -1)); // 3 (начинает поиск с последнего элемента)
```

## Практические примеры

### Проверка наличия элемента
Хотя сейчас для этих целей чаще используется метод `.includes()`, `indexOf` часто встречается в старом коде для проверки существования значения.

```javascript
const fruits = ['apple', 'banana', 'mango'];

if (fruits.indexOf('banana') !== -1) {
  console.log('Банан есть в списке!');
}
```

### Нахождение всех вхождений элемента
С помощью `indexOf` и цикла можно найти все позиции конкретного значения:

```javascript
const indices = [];
const array = ['a', 'b', 'a', 'c', 'a', 'd'];
const element = 'a';
let idx = array.indexOf(element);

while (idx !== -1) {
  indices.push(idx);
  idx = array.indexOf(element, idx + 1);
}

console.log(indices); // [0, 2, 4]
```
