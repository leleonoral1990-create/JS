# Метод Array.prototype.reverse()

Метод `reverse()` изменяет порядок элементов массива на обратный. Первый элемент становится последним, а последний — первым.



## Синтаксис

```javascript
reverse()
```

### Параметры
Метод не принимает никаких параметров.

### Возвращаемое значение
* Ссылка на тот же самый (оригинальный) массив, но с измененным порядком элементов.

---

## Ключевые особенности

1.  **Мутирующий метод:** `reverse()` — это "разрушающий" метод. Он изменяет оригинальный массив на месте (in-place), а не создает копию.
2.  **Возвращает ссылку:** Метод возвращает ссылку на тот же массив, который был изменен. Это позволяет использовать его в цепочках методов.
3.  **Работа с "дырами" (Sparse arrays):** Если в массиве есть пустые ячейки, после реверсии они сохранят свои позиции относительно значений (то есть пустая ячейка с начала переместится в конец).

---

## Примеры использования

### 1. Базовая инверсия
```javascript
const items = ['one', 'two', 'three'];
const reversed = items.reverse();

console.log(items);    // ["three", "two", "one"]
console.log(reversed); // ["three", "two", "one"]
console.log(items === reversed); // true (это один и тот же объект в памяти)
```

### 2. Реверс без изменения оригинала
Если вам нужно сохранить исходный массив, сначала сделайте его копию (например, через spread-синтаксис или `slice()`).

```javascript
const numbers = [1, 2, 3];
const reversedNumbers = [...numbers].reverse();

console.log(numbers);         // [1, 2, 3] (оригинал цел)
console.log(reversedNumbers); // [3, 2, 1]
```

---

## Важные нюансы

### Работа с объектами и ссылками
Метод меняет только порядок индексов. Сами элементы (если это объекты) не копируются и не меняются — они просто перемещаются на новые позиции.

### Применение к строкам
У строк нет метода `reverse()`. Чтобы перевернуть строку, ее сначала нужно превратить в массив, перевернуть его и склеить обратно:
```javascript
const str = "hello";
const reversedStr = str.split("").reverse().join("");

console.log(reversedStr); // "olleh"
```

### Применение к массивоподобным объектам
Метод `reverse()` является универсальным. Его можно вызвать для объектов, имеющих свойство `length` и целочисленные ключи, используя `call` или `apply`.
```javascript
const obj = {0: 'a', 1: 'b', 2: 'c', length: 3};
Array.prototype.reverse.call(obj);
console.log(obj); // {0: 'c', 1: 'b', 2: 'a', length: 3}
```
