# Метод Array.prototype.slice()

Метод `slice()` возвращает новый массив, в который копируются элементы, начиная с индекса `start` и до `end` (не включая `end`). При этом исходный массив **не изменяется**.



## Синтаксис

```javascript
slice()
slice(start)
slice(start, end)
```

### Параметры
1.  **`start`** (необязательно): Индекс, с которого начинается копирование.
    * Если индекс отрицательный, он отсчитывается от конца массива (например, `-2` скопирует последние два элемента).
    * Если не указан, по умолчанию равен `0`.
2.  **`end`** (необязательно): Индекс, на котором копирование заканчивается (элемент с этим индексом **не включается** в новый массив).
    * Если индекс отрицательный, он также отсчитывается от конца массива.
    * Если не указан, копируются все элементы до конца массива.

### Возвращаемое значение
* Новый массив, содержащий скопированные элементы.

---

## Ключевые особенности

1.  **Немутирующий метод:** `slice()` не изменяет оригинальный массив, что делает его безопасным инструментом для функционального программирования.
2.  **Поверхностное копирование (Shallow Copy):** Метод копирует элементы по значению для примитивов и **по ссылке** для объектов. Если изменить объект внутри нового массива, он изменится и в оригинальном.
3.  **Клонирование массива:** Вызов `slice()` без аргументов часто используется для создания полной копии массива.

---

## Примеры использования

### 1. Извлечение части массива
```javascript
const animals = ['ant', 'bison', 'camel', 'duck', 'elephant'];

console.log(animals.slice(2));      // ["camel", "duck", "elephant"]
console.log(animals.slice(2, 4));   // ["camel", "duck"] (индекс 4 'duck' не включен)
```

### 2. Использование отрицательных индексов
```javascript
const fruits = ['Banana', 'Orange', 'Lemon', 'Apple', 'Mango'];
const citrus = fruits.slice(-3, -1); 

console.log(citrus); // ["Lemon", "Apple"]
```

### 3. Создание копии массива
```javascript
const original = [1, 2, 3];
const copy = original.slice();

copy.push(4);
console.log(original); // [1, 2, 3] (оригинал не изменился)
console.log(copy);     // [1, 2, 3, 4]
```

### 4. Поверхностное копирование объектов
```javascript
const orders = [{ id: 1 }, { id: 2 }];
const slicedOrders = orders.slice(0, 1);

slicedOrders[0].id = 99; 

console.log(orders[0].id); // 99 (так как объект был скопирован по ссылке)
```
