# Метод String.prototype.repeat()

Метод `repeat()` конструирует и возвращает новую строку, которая содержит указанное количество копий исходной строки, объединенных вместе.



## Синтаксис

```javascript
str.repeat(count)
```

**Параметры:**
* **`count`**: Целое число от `0` до `+Infinity`, определяющее количество повторений строки.

**Возвращаемое значение:**
* Новая строка, содержащая указанное количество копий исходной строки.

---

## Примеры использования

### 1. Базовое повторение
```javascript
'abc'.repeat(3);    // "abcabcabc"
'hello '.repeat(2); // "hello hello "
```

### 2. Крайние случаи (0 и 1)
```javascript
'abc'.repeat(0);    // "" (пустая строка)
'abc'.repeat(1);    // "abc"
```

### 3. Работа с дробными числами
Если передать дробное число, оно будет **отсечено до целого** (аналогично `Math.floor()`).
```javascript
'abc'.repeat(2.9);  // "abcabc" (2.9 превращается в 2)
```

---

## Исключения (RangeError)

Метод выбросит ошибку `RangeError` в следующих случаях:
1.  **Отрицательное число:** `count` меньше 0.
2.  **Бесконечность:** `count` равен `Infinity`.
3.  **Переполнение:** Результат превышает максимально допустимый размер строки в JavaScript.

```javascript
'abc'.repeat(-1);   // RangeError: Invalid count value
'abc'.repeat(Infinity); // RangeError: Invalid count value
```

---

## Практическое применение

Метод удобен для создания визуальных разделителей или заполнения строк символами.

```javascript
const indent = ' '.repeat(4);
console.log(indent + 'Этот текст смещен на 4 пробела');

const line = '-'.repeat(20);
console.log(line); // "--------------------"
```
