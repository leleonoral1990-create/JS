# Рекурсия в JavaScript (Recursion)

**Рекурсия** — это прием программирования, при котором функция вызывает саму себя. Рекурсия позволяет заменять циклы (например, `while`) более декларативным кодом.



## 1. Базовая логика и синтаксис
Любая рекурсивная функция состоит из двух обязательных частей:
1.  **Базовый случай (Условие выхода):** Условие, при котором функция прекращает вызывать себя и возвращает результат. Без него возникнет бесконечный цикл и переполнение стека (Stack Overflow).
2.  **Рекурсивный шаг:** Вызов функции самой себя с измененными аргументами, чтобы постепенно приближаться к базовому случаю.

```javascript
// Простейшая схема рекурсии через тернарный оператор
const recursive = (arg) => condition ? recursive(updatedArg) : result;
```

---

## 2. Пример 1: Рекурсивный счетчик
В отличие от цикла `while`, где нам нужна была изменяемая переменная `let count`, в рекурсии каждое новое состояние передается как аргумент в следующий вызов. Это позволяет использовать только константы.

```javascript
const countTo10 = (count) => {
  if (count < 10) {
    console.log('counter at', count);
    // Рекурсивный шаг: вызываем себя, увеличив значение на 1
    countTo10(count + 1); 
  }
  // Если count >= 10, функция просто завершится (базовый случай)
};

countTo10(0); // Запуск рекурсии с начальным значением
```

---

## 3. Пример 2: Умножение через сложение
Для реализации логики накопления результата (как в цикле) рекурсивной функции часто требуется передавать дополнительные аргументы: текущий счетчик и промежуточный результат.

```javascript
// Функция-помощник с тремя аргументами
const times5Recursive = (n, count, result) =>
  count < 5 
    ? times5Recursive(n, count + 1, result + n) // Проходим шаг
    : result; // Возвращаем итог, когда count достиг 5
```

---

## 4. Паттерн "Функция-обертка" (Wrapper)
Пользователю функции неудобно передавать начальные нули (`count` и `result`) при каждом вызове. Поэтому создается чистая "обертка", которая сама запускает рекурсию с правильными стартовыми параметрами.

```javascript
// Основная функция для пользователя
const times5 = (n) => times5Recursive(n, 0, 0);

console.log(times5(5)); // 25
```

### Главные преимущества рекурсии:
* **Иммутабельность:** Нет необходимости изменять значения переменных (`let`), данные передаются "через параметры".
* **Чистота:** Код часто выглядит более элегантным и математически строгим.
* **Работа со вложенностью:** Рекурсия незаменима при работе с глубоко вложенными структурами (например, деревьями объектов или папками на диске).
