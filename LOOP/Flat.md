# Метод Array.prototype.flat()

Метод `flat()` создает новый массив, в который рекурсивно копируются все элементы вложенных массивов до указанной глубины.



## Синтаксис

```javascript
flat()
flat(depth)
```

### Параметры
* **`depth`** (необязательно): Уровень глубины, определяющий, насколько глубоко должна быть произведена "распаковка" вложенных массивов.
    * По умолчанию равен `1`.
    * Можно передать `Infinity`, чтобы полностью развернуть массив любой вложенности.

### Возвращаемое значение
* Новый массив с элементами вложенных массивов, объединенных в него.

---

## Ключевые особенности

1.  **Немутирующий метод:** `flat()` не изменяет исходный массив, а возвращает новую копию.
2.  **Удаление пустых ячеек:** Метод автоматически удаляет "дыры" (пустые элементы) в массиве.
3.  **Рекурсивная обработка:** Если указана глубина больше 1, метод будет заходить во вложенные массивы до тех пор, пока не достигнет лимита или конца вложенности.

---

## Примеры использования

### 1. Базовое развертывание (глубина 1)
```javascript
const arr1 = [1, 2, [3, 4]];
console.log(arr1.flat()); 
// [1, 2, 3, 4]

const arr2 = [1, 2, [3, 4, [5, 6]]];
console.log(arr2.flat()); 
// [1, 2, 3, 4, [5, 6]] (уровень 2 остался нетронутым)
```

### 2. Указание глубины
```javascript
const arr3 = [1, 2, [3, 4, [5, 6]]];
console.log(arr3.flat(2)); 
// [1, 2, 3, 4, 5, 6]
```

### 3. Развертывание любой вложенности (`Infinity`)
```javascript
const arrDeep = [1, [2, [3, [4, [5]]]]];
console.log(arrDeep.flat(Infinity)); 
// [1, 2, 3, 4, 5]
```

### 4. Очистка массива от "дыр"
```javascript
const sparseArray = [1, 2, , 4, 5];
console.log(sparseArray.flat()); 
// [1, 2, 4, 5]
```

---

## Когда использовать?

Метод `flat()` незаменим, когда данные приходят из API в виде сложной вложенной структуры, а вам нужен линейный список элементов для отрисовки или фильтрации.
