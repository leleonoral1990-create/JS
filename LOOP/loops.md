# Циклы в JavaScript: while и for..of

Циклы позволяют выполнять блок кода многократно. Это один из важнейших инструментов для автоматизации задач и обработки данных.

---

## 1. Цикл `while`

Цикл `while` выполняет блок кода до тех пор, пока указанное условие является **truthy** (истинным).



### Синтаксис
```javascript
while (условие) {
  // код, который будет повторяться
}
```

### Базовый пример: Счетчик
Важно изменять переменную внутри цикла, иначе он станет "бесконечным" и программа зависнет.

```javascript
let count = 0; // Используем let, так как значение будет меняться

while (count < 10) {
  count = count + 1; // Увеличиваем счетчик
  console.log('Счетчик на отметке:', count);
}
```

### Пример: Функция умножения через сложение
```javascript
const times5 = (n) => {
  let result = 0;
  let count = 0;

  while (count < 5) {
    count = count + 1;
    result = result + n; // Прибавляем n пять раз
  }

  return result;
};

console.log(times5(10)); // 50
```

## 2. Цикл `for..of`

Цикл `for..of` — это современный и лаконичный способ перебора итерируемых объектов, таких как **массивы** или **строки**. Он автоматически проходит от начала до конца коллекции.



### Синтаксис
```javascript
for (const элемент of коллекция) {
  // код, выполняемый для каждого элемента
}
```

### Пример: Подсчет букв в строке
В этом цикле нам не нужно вручную управлять счетчиком или следить за длиной строки.

```javascript
const sentence = 'How are you today ?';
let countOfTheLetterO = 0;

// На каждой итерации переменная letter получает значение следующего символа строки
for (const letter of sentence) {
  if (letter === 'o') {
    countOfTheLetterO = countOfTheLetterO + 1;
  }
}

console.log('Количество букв "o":', countOfTheLetterO); // 3
```

### Ключевые отличия
* **`while`** лучше использовать, когда вы точно не знаете, сколько раз должен выполниться код (вы ждете наступления определенного условия).
* **`for..of`** идеален, когда вам нужно просто перебрать все элементы массива или символы строки по порядку.
