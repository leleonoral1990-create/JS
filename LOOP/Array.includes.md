# Метод Array.prototype.includes()

Метод `includes()` проверяет, содержит ли массив определенный элемент, и возвращает `true` или `false` в зависимости от результата.



## Синтаксис

```javascript
includes(searchElement)
includes(searchElement, fromIndex)
```

### Параметры
1.  **`searchElement`**: Значение, которое нужно найти в массиве.
2.  **`fromIndex`** (необязательно): Позиция в массиве, с которой следует начинать поиск.
    * По умолчанию равен `0`.
    * Если значение отрицательное, оно отсчитывается от конца массива (например, `-2` означает поиск в последних двух элементах).

### Возвращаемое значение
* **`true`**, если значение найдено.
* **`false`**, если значение не найдено.

---

## Важные особенности

1.  **Работа с `NaN`:** В отличие от методов `indexOf` и `lastIndexOf`, метод `includes()` **умеет находить** `NaN` в массиве.
2.  **Регистрозависимость:** При поиске строк метод учитывает регистр (например, `'Apple'` и `'apple'` — это разные значения).
3.  **Сравнение объектов:** Если в массиве лежат объекты, `includes()` найдет их только в том случае, если передана ссылка на **тот же самый** объект.

---

## Примеры использования

### 1. Базовый поиск
```javascript
const pets = ['cat', 'dog', 'bat'];

console.log(pets.includes('cat')); // true
console.log(pets.includes('at'));  // false (ищет полное совпадение)
```

### 2. Поиск с использованием `fromIndex`
```javascript
const arr = ['a', 'b', 'c'];

console.log(arr.includes('a', 1)); // false (поиск начался с индекса 1)
console.log(arr.includes('c', -1)); // true (поиск в последнем элементе)
```

### 3. Решение проблемы с `NaN`
```javascript
const numbers = [1, 2, NaN, 4];

console.log(numbers.indexOf(NaN));    // -1 (не находит)
console.log(numbers.includes(NaN));   // true (находит!)
```

### 4. Поиск в "разреженных" массивах
Если в массиве есть пустые ячейки (дыры), `includes()` воспринимает их как `undefined`.
```javascript
const sparseArray = [1, , 3]; // Пропущено значение на индексе 1
console.log(sparseArray.includes(undefined)); // true
```
