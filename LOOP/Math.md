# Объект Math в JavaScript

`Math` — это встроенный объект, который предоставляет свойства и методы для выполнения математических операций. В отличие от других глобальных объектов (`String`, `Number`, `Array`), `Math` не является конструктором. Все его свойства и методы являются статическими, то есть их нужно вызывать напрямую у объекта `Math`.



---

## 1. Статические свойства (Константы)

Объект `Math` содержит несколько математических констант, которые часто используются в вычислениях.

* **`Math.PI`**: Отношение длины окружности к её диаметру ($\approx 3.14159$).
* **`Math.E`**: Число Эйлера, основание натуральных логарифмов ($\approx 2.718$).
* **`Math.SQRT2`**: Квадратный корень из 2.
* **`Math.LN10`**: Натуральный логарифм числа 10.

---

## 2. Методы округления

В JavaScript есть несколько способов округления чисел, каждый из которых работает по-своему.



| Метод | Описание | Пример (3.1 / 3.9) |
| :--- | :--- | :--- |
| **`Math.floor()`** | Округляет вниз до ближайшего целого. | `3 / 3` |
| **`Math.ceil()`** | Округляет вверх до ближайшего целого. | `4 / 4` |
| **`Math.round()`** | Округляет к ближайшему целому по правилам математики. | `3 / 4` |
| **`Math.trunc()`** | Просто отбрасывает дробную часть. | `3 / 3` |

```javascript
console.log(Math.floor(-3.1)); // -4 (вниз)
console.log(Math.trunc(-3.1)); // -3 (просто убрал .1)
```

---

## 3. Базовые вычисления

* **`Math.abs(x)`**: Возвращает абсолютное значение (модуль) числа.
    ```javascript
    Math.abs(-5); // 5
    ```
* **`Math.pow(base, exponent)`**: Возводит число в степень. Современная альтернатива — оператор `**`.
    ```javascript
    Math.pow(2, 3); // 8
    ```
* **`Math.sqrt(x)`**: Квадратный корень числа.
* **`Math.sign(x)`**: Возвращает знак числа: `1` (положительное), `-1` (отрицательное) или `0`.

---

## 4. Поиск Минимума и Максимума

Методы `min` и `max` принимают любое количество аргументов. Чтобы передать в них массив, обычно используют spread-синтаксис (`...`).

```javascript
console.log(Math.max(1, 10, 5)); // 10

const nums = [10, 20, 30];
console.log(Math.min(...nums)); // 10
```

---

## 5. Генерация случайных чисел

Метод **`Math.random()`** возвращает случайное число с плавающей точкой в диапазоне от `0` (включительно) до `1` (не включая).



Для получения целого числа в заданном диапазоне используется формула:
```javascript
// Случайное целое число от min до max (включительно)
function getRandomInt(min, max) {
  return Math.floor(Math.random() * (max - min + 1)) + min;
}
```

---

## 6. Тригонометрия и Логарифмы

Для более сложных инженерных задач `Math` предоставляет полный набор функций:
* **Тригонометрия**: `Math.sin()`, `Math.cos()`, `Math.tan()`, `Math.asin()`, и т.д. (принимают значения в радианах).
* **Логарифмы**: `Math.log()` (натуральный логарифм), `Math.log10()`, `Math.log2()`.
* **Экспонента**: `Math.exp()`.

---

## Важные нюансы

1.  **Не является конструктором**: Вы не можете написать `new Math()`.
2.  **Точность**: Как и все вычисления с плавающей точкой в JS, методы `Math` могут сталкиваться с мелкими погрешностями из-за стандарта IEEE 754.
3.  **Приведение типов**: Если методам передать не числовые значения, они попытаются привести их к числу. Если это невозможно, вернется `NaN`.
    ```javascript
    Math.max(1, "5", 3); // 5
    Math.max(1, "abc", 3); // NaN
    ```
