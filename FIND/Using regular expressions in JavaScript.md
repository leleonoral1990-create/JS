# Использование регулярных выражений в JavaScript

В JavaScript регулярные выражения — это не просто синтаксис поиска, а полноценные объекты типа `RegExp`. Они применяются с помощью встроенных методов объекта `RegExp` и методов объекта `String`.

В зависимости от задачи (нужно ли просто проверить наличие, найти все совпадения или заменить текст) используются разные методы.

---

## 1. Методы объекта RegExp (вызываются у регулярки)

Эти методы используются, когда само регулярное выражение является главным действующим лицом.

### `test()` — Проверка на наличие (Да/Нет)
Выполняет поиск совпадения в строке. Возвращает `true`, если совпадение найдено, и `false`, если нет.
**Когда использовать:** Если вам нужно просто узнать, подходит ли строка под шаблон (например, валидация email или пароля). Это самый быстрый метод.

```javascript
const regex = /^hello/;
console.log(regex.test("hello world")); // true
console.log(regex.test("say hello"));   // false
```

### `exec()` — Детальный поиск с сохранением состояния
Ищет совпадение в строке и возвращает **массив** с подробной информацией (само совпадение, индекс, исходная строка) или `null`, если ничего не найдено.
**Особенность:** Если у регулярки стоит флаг `g` (глобальный поиск), `exec()` запоминает позицию, на которой остановился. При следующем вызове он продолжит поиск с этого места.

```javascript
const regex = /a/g;
const str = "banana";

console.log(regex.exec(str)); // ['a', index: 1, ...]
console.log(regex.exec(str)); // ['a', index: 3, ...]
console.log(regex.exec(str)); // ['a', index: 5, ...]
console.log(regex.exec(str)); // null (совпадения кончились)
```

## 2. Методы объекта String (вызываются у строки)

Эти методы используются, когда вы работаете со строкой и применяете к ней регулярное выражение как инструмент.

### `match()` — Получение совпадений
Возвращает массив найденных совпадений. Поведение зависит от флага `g`:
* **Без флага `g`:** Работает почти как `exec()`, возвращает массив с деталями только первого совпадения.
* **С флагом `g`:** Возвращает простой массив всех найденных совпадений (без индексов и деталей).

```javascript
const str = "I see 1 apple and 5 oranges";
console.log(str.match(/\d+/));  // ['1', index: 6, ...] (только первое)
console.log(str.match(/\d+/g)); // ['1', '5'] (все совпадения)
```

### `matchAll()` — Получение всех деталей всех совпадений
Возвращает итератор, содержащий массивы с полными деталями для **каждого** совпадения. Обязательно требует использования флага `g`.
```javascript
const str = "test1 test2";
const results = [...str.matchAll(/t(e)(st(\d?))/g)];
// Возвращает массив массивов со всеми группами захвата и индексами
```

### `search()` — Поиск индекса (аналог indexOf)
Проверяет, есть ли совпадение, и возвращает **индекс** начала первого совпадения. Если ничего не найдено, возвращает `-1`. Флаг `g` здесь игнорируется.
```javascript
const str = "hello world";
console.log(str.search(/world/)); // 6
console.log(str.search(/xyz/));   // -1
```

### `replace()` и `replaceAll()` — Замена текста
Ищет совпадения и заменяет их на новую строку (или результат вызова функции).
* `replace()` заменит только первое совпадение (если нет флага `g`).
* `replaceAll()` заменяет все совпадения, но строго требует, чтобы у регулярного выражения был флаг `g`.

```javascript
const str = "Apples are round, and apples are juicy.";
// Заменяем 'apples' (игнорируя регистр с флагом 'i') глобально (флаг 'g')
const newStr = str.replace(/apples/gi, "oranges");
console.log(newStr); // "oranges are round, and oranges are juicy."
```

### `split()` — Разделение строки
Работает так же, как обычный `String.split()`, но в качестве разделителя использует регулярное выражение. Это очень удобно, если разделители могут быть разными (например, запятая, точка с запятой или пробел).

```javascript
const str = "Harry, Trump; Obama   Biden";
// Разбиваем по запятой, точке с запятой или пробелу (1 или более)
const names = str.split(/[,\s;]+/);
console.log(names); // ["Harry", "Trump", "Obama", "Biden"]
```

---

## Шпаргалка: что выбрать?

| Цель | Метод | Возвращает |
| :--- | :--- | :--- |
| **Просто узнать, есть ли совпадение** | `RegExp.test()` | `true` / `false` |
| **Узнать позицию первого совпадения** | `String.search()` | Индекс (число) или `-1` |
| **Получить все совпадения списком** | `String.match()` (с флагом `g`) | Массив строк (`['a', 'b']`) |
| **Заменить текст** | `String.replace()` | Новую строку |
| **Разбить строку на массив** | `String.split()` | Массив подстрок |
| **Пройтись циклом по всем деталям совпадений** | `RegExp.exec()` или `String.matchAll()` | Массив данных или Итератор |
