# Итоговый конспект: Блок Call Me Maybe (Функциональное программирование и итерация)

Этот этап посвящен переходу от императивного стиля (циклов `for`) к **декларативному**. Мы учим программу не "как делать" (шаг за шагом), а "что мы хотим получить" в итоге.

---

## 1. Нативные методы итерации массивов

Эти методы позволяют обрабатывать данные без создания лишних переменных-счетчиков и ручного управления индексами.


### Трансформация данных
* **`map()`**: Создает новый массив такой же длины. Каждый элемент — результат функции.
    * *Пример:* `[1, 2].map(x => x * 2)` $\rightarrow$ `[2, 4]`
* **`flatMap()`**: Сначала делает `map`, а затем "разглаживает" результат на 1 уровень вложенности. Идеально для работы с вложенными списками.
    * *Пример:* `['a b', 'c'].flatMap(s => s.split(' '))` $\rightarrow$ `['a', 'b', 'c']`

### Фильтрация и поиск
* **`filter()`**: Оставляет только те элементы, для которых функция вернула `true`.
    * *Пример:* `[1, 10].filter(x => x > 5)` $\rightarrow$ `[10]`
* **`forEach()`**: Просто перебор. Ничего не возвращает (`undefined`). Используется только для побочных эффектов (вывод в консоль, изменение DOM).

### Проверки (Boolean)
* **`every()`**: `true`, если **все** элементы подходят под условие.
* **`some()`**: `true`, если **хотя бы один** элемент подходит под условие.

### Ультимативный метод
* **`reduce()`**: Сворачивает массив в одно значение (число, объект, другой массив).
    * *Важно:* Всегда указывайте `initialValue` (второй аргумент), чтобы избежать ошибок на пустых массивах.

## 2. Функциональные концепции: Каррирование (Currying)

**Каррирование** — это трансформация функции из вида `f(a, b)` в `f(a)(b)`. Это позволяет "замораживать" часть аргументов и создавать специализированные функции.

```javascript
const multiply = a => b => a * b;
const double = multiply(2); // Зафиксировали 'a' как 2
console.log(double(5)); // 10
```

## 3. Инструменты Lodash

Библиотека Lodash расширяет возможности JS, делая работу с коллекциями еще более лаконичной.

* **`_.reject()`**: Анти-фильтр. Оставляет те элементы, которые **не** подошли под условие.
* **`_.partition()`**: Разделяет массив на две части: `[ [прошедшие проверку], [не прошедшие] ]`.
* **`_.flow()`**: Создает конвейер из функций. Результат первой функции передается во вторую и т.д.

## 🚀 Финальный пример: Комбинируем всё

Представим, что у нас есть список студентов, и нам нужно:
1. Оставить только тех, кто сдал экзамен (score > 50).
2. Очистить их имена от пробелов.
3. Разделить их на две группы: "Отличники" (>= 90) и "Остальные".

```javascript
import _ from 'lodash';

const students = [
  { name: '  Eleonora ', score: 95 },
  { name: 'Sergey', score: 45 },
  { name: ' Alice  ', score: 92 },
  { name: 'Bob', score: 70 }
];

// 1. Каррированная функция для проверки минимального балла
const hasMinScore = min => obj => obj.score > min;

// 2. Функции для обработки имен (для flow)
const trimName = s => s.trim();
const getUpper = s => s.toUpperCase();

const formatName = _.flow([trimName, getUpper]);

// 3. Обработка данных
const processed = students
  .filter(hasMinScore(50)) // Убираем тех, кто не сдал
  .map(s => ({ ...s, name: formatName(s.name) })); // Форматируем имена

// 4. Разделение на группы
const [honors, others] = _.partition(processed, s => s.score >= 90);

console.log('Отличники:', honors);
console.log('Остальные:', others);

/* Результат:
Honors: [{ name: 'ELEONORA', score: 95 }, { name: 'ALICE', score: 92 }]
Others: [{ name: 'BOB', score: 70 }]
*/
```

### Шпаргалка: Что выбрать?
* Нужно преобразовать каждый элемент? $\rightarrow$ **`map`**
* Нужно выкинуть лишнее? $\rightarrow$ **`filter`**
* Нужно одно значение на выходе? $\rightarrow$ **`reduce`**
* Нужно разделить на два лагеря? $\rightarrow$ **`_.partition`**
* Нужно объединить цепочку действий в одну функцию? $\rightarrow$ **`_.flow`**
