# Метод Array.prototype.filter()

Метод `filter()` создает **новый массив**, в который попадут только те элементы исходного массива, которые прошли проверку (удовлетворяют условию), заданную в передаваемой функции-колбэке.



## Синтаксис

```javascript
filter(callbackFn)
filter(callbackFn, thisArg)
```

Функция `callbackFn` принимает три аргумента (так же, как и в методе `map`):
1.  **`element`**: Текущий обрабатываемый элемент массива.
2.  **`index`** (необязательно): Индекс текущего элемента.
3.  **`array`** (необязательно): Сам исходный массив.

### Возвращаемое значение
* **Новый массив**, содержащий элементы, для которых функция `callbackFn` вернула `true` (или любое "truthy" значение).
* Если ни один элемент не прошел проверку, возвращается **пустой массив** `[]`.

---

## Ключевые особенности

1.  **Немутирующий метод:** `filter()` не изменяет оригинальный массив, а возвращает совершенно новый.
2.  **Длина массива:** В отличие от `map()`, итоговый массив почти всегда будет короче исходного (или такой же длины, если все элементы прошли проверку).
3.  **Логическое преобразование:** Функция-колбэк должна возвращать логическое значение (`true` или `false`). Если вы вернете что-то другое (например, строку или объект), `filter` автоматически приведет это к логическому типу (truthy/falsy).

---

## Примеры использования

### 1. Простая фильтрация чисел
```javascript
const words = ['spray', 'elite', 'exuberant', 'destruction', 'present'];

// Оставляем только те слова, длина которых больше 6 символов
const result = words.filter(word => word.length > 6);

console.log(result); // ["exuberant", "destruction", "present"]
console.log(words);  // (оригинальный массив не изменился)
```

### 2. Фильтрация массива объектов (Классический сценарий)
Это один из самых частых приемов при работе с данными с бэкенда.

```javascript
const users = [
  { id: 1, name: 'Alice', isActive: true },
  { id: 2, name: 'Bob', isActive: false },
  { id: 3, name: 'Charlie', isActive: true }
];

// Получаем список только активных пользователей
const activeUsers = users.filter(user => user.isActive);

console.log(activeUsers); 
// [{ id: 1, name: 'Alice', isActive: true }, { id: 3, name: 'Charlie', isActive: true }]
```

### 3. Удаление дубликатов с помощью индекса
Используя параметры `index` и `array`, можно написать элегантный фильтр уникальных значений.

```javascript
const numbers = [1, 2, 2, 3, 4, 4, 5];

const uniqueNumbers = numbers.filter((num, index, arr) => {
  // indexOf всегда возвращает индекс ПЕРВОГО вхождения элемента.
  // Если текущий индекс не совпадает с первым, значит это дубликат.
  return arr.indexOf(num) === index;
});

console.log(uniqueNumbers); // [1, 2, 3, 4, 5]
```

## Важные нюансы и крутые трюки

### Трюк: очистка массива от "мусора" (falsy значений)
Часто массив нужно очистить от `null`, `undefined`, `0`, пустых строк `""` или `NaN`. Поскольку `filter` сам приводит возвращаемое значение к Boolean, можно просто передать конструктор `Boolean` в качестве колбэка:

```javascript
const dirtyData = [1, null, 'text', undefined, 0, false, 42, ''];

// Оставляем только "истинные" (truthy) значения
const cleanData = dirtyData.filter(Boolean);

console.log(cleanData); // [1, "text", 42]
```

### Что если ничего не найдено?
Запомните важное отличие `filter()` от методов поиска вроде `find()` или `indexOf()`:
* Если `filter` ничего не нашел, он вернет **пустой массив** `[]`. Он никогда не вернет `undefined` или `null`.
* Это значит, что после `filter()` можно смело продолжать цепочку методов (например, `.filter(...).map(...)`), и код не упадет с ошибкой `Cannot read properties of undefined`.
