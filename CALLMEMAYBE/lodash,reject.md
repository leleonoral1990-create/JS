# Метод _.reject() (библиотека Lodash)

Метод `_.reject()` — это логическая противоположность метода `filter()`. Если `filter` оставляет элементы, которые **подходят** под условие, то `reject` — это фильтр «наоборот»: он создает новый массив из элементов, которые **НЕ удовлетворяют** условию (для которых функция-предикат вернула `false`).



## Синтаксис

```javascript
_.reject(collection, [predicate=_.identity])
```

**Параметры:**
1.  **`collection`**: Массив или объект, который нужно обработать.
2.  **`predicate`**: Функция, объект или строка, определяющая условие «отсева».

**Возвращаемое значение:**
* Новый массив отфильтрованных элементов.

---

## В чем преимущество перед нативным JS?

В чистом JavaScript нет метода `reject()`. Чтобы добиться такого же результата, приходится инвертировать условие в `filter()` с помощью оператора `!`:

```javascript
// Native JS
const activeUsers = users.filter(u => !u.isActive);

// Lodash (более читаемо)
const activeUsers = _.reject(users, { 'isActive': true });
```

---

## Способы использования (Iteratee Shorthands)

Lodash позволяет передавать предикат в разных форматах, что делает код очень лаконичным:

### 1. Использование функции
```javascript
const numbers = [1, 2, 3, 4, 5, 6];

// Отсеиваем четные числа
const odds = _.reject(numbers, n => n % 2 === 0);

console.log(odds); // [1, 3, 5]
```

### 2. Использование объекта (matches)
Самый удобный способ для работы с массивами объектов.

```javascript
const users = [
  { 'user': 'barney', 'age': 36, 'active': false },
  { 'user': 'fred',   'age': 40, 'active': true }
];

// Удаляем всех активных пользователей
const inactive = _.reject(users, { 'active': true });

console.log(inactive); // [{ 'user': 'barney', 'age': 36, 'active': false }]
```

### 3. Использование строки (property)
Позволяет отсеять объекты, у которых указанное свойство имеет значение `true` (truthy).

```javascript
const users = [
  { 'user': 'barney', 'active': true },
  { 'user': 'fred',   'active': false }
];

// Отсеиваем тех, у кого active === true
console.log(_.reject(users, 'active')); // [{ 'user': 'fred', 'active': false }]
```

---

## Ключевые особенности

* **Не мутирует данные:** Как и большинство методов Lodash, `reject` возвращает новый массив, не изменяя оригинал.
* **Работает с объектами:** В отличие от нативного `filter`, `reject` можно применять к обычным объектам (он пройдется по их значениям).
* **Семантика:** Использование `reject` делает намерения разработчика более понятными: «я хочу исключить вот эти элементы», вместо «я хочу оставить все элементы, кроме вот этих».
