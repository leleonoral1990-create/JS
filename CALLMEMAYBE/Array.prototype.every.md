# Метод Array.prototype.every()

Метод `every()` проверяет, удовлетворяют ли **все** элементы массива условию, заданному в передаваемой функции-колбэке. Он возвращает логическое значение (`true` или `false`).



## Синтаксис

```javascript
every(callbackFn)
every(callbackFn, thisArg)
```

Функция `callbackFn` принимает три аргумента:
1.  **`element`**: Текущий обрабатываемый элемент массива.
2.  **`index`** (необязательно): Индекс текущего элемента.
3.  **`array`** (необязательно): Исходный массив.

### Возвращаемое значение
* **`true`**: если функция-колбэк вернула «истинное» (truthy) значение для каждого элемента массива.
* **`false`**: если нашелся хотя бы один элемент, для которого функция вернула «ложное» (falsy) значение.

---

## Ключевые особенности

1.  **Принцип "До первого провала":** Метод прекращает перебор массива сразу же, как только находит элемент, не подходящий под условие. Это делает его эффективным для больших массивов.
2.  **Немутирующий метод:** `every()` не изменяет оригинальный массив.
3.  **Логическое значение:** В отличие от `filter()`, который возвращает подмножество элементов, `every()` всегда возвращает только `true` или `false`.

---

## Примеры использования

### 1. Простая проверка чисел
```javascript
const numbers = [12, 5, 8, 130, 44];
const allBig = numbers.every(num => num > 10);
const allPositive = numbers.every(num => num > 0);

console.log(allBig);      // false (так как 5 и 8 меньше 10)
console.log(allPositive); // true
```

### 2. Проверка массива объектов
Часто используется для валидации данных, например, заполнил ли пользователь все обязательные поля.

```javascript
const surveyResponses = [
  { questionId: 1, answer: "Yes" },
  { questionId: 2, answer: "Maybe" },
  { questionId: 3, answer: "" }
];

// Проверяем, что во всех ответах есть текст
const isComplete = surveyResponses.every(response => response.answer.length > 0);

console.log(isComplete); // false (в третьем объекте пустая строка)
```

## Важные нюансы

### Работа с пустыми массивами
Это важный момент для собеседований: для любого условия на **пустом массиве** метод `every()` всегда возвращает `true`. Это называется «вакуумная истина» (vacuous truth).

```javascript
const emptyArray = [];
console.log(emptyArray.every(x => x > 10)); // true
```

### every() vs some()
Эти методы являются логическими противоположностями:
* `every()` требует, чтобы условие выполнили **все**.
* `some()` требует, чтобы условие выполнил хотя бы **один**.



### Использование в условиях
Метод идеально подходит для охранных условий (guard clauses):
```javascript
function processData(users) {
  if (!users.every(user => user.hasPermission)) {
    throw new Error("Не у всех пользователей есть права доступа!");
  }
  // Дальнейшая обработка...
}
```
