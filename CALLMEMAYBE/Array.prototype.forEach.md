# Метод Array.prototype.forEach()

Метод `forEach()` — это базовый инструмент для перебора массива. Он выполняет переданную функцию-колбэк один раз для каждого элемента массива. В отличие от `map` или `filter`, этот метод **ничего не возвращает** (результат всегда `undefined`).



## Синтаксис

```javascript
forEach(callbackFn)
forEach(callbackFn, thisArg)
```

Функция `callbackFn` принимает три аргумента:
1.  **`element`**: Текущий обрабатываемый элемент.
2.  **`index`** (необязательно): Индекс текущего элемента.
3.  **`array`** (необязательно): Сам массив, по которому идет перебор.

---

## Ключевые особенности

1.  **Побочные эффекты (Side Effects):** Поскольку метод ничего не возвращает, его используют исключительно ради побочных эффектов: записи данных в базу, вывода в консоль, изменения DOM-элементов или модификации внешних переменных.
2.  **Нельзя остановить:** В `forEach` **не работают** операторы `break` или `continue`. Если вам нужно прервать цикл при определенном условии, используйте обычный `for`, `for...of`, `every()` или `some()`.
3.  **Пропуск пустых ячеек:** `forEach` не вызывается для пропущенных элементов в "дырявых" (sparse) массивах.

---

## Примеры использования

### 1. Вывод данных и модификация внешних объектов
```javascript
const fruits = ['apple', 'banana', 'cherry'];

fruits.forEach((fruit, index) => {
  console.log(`${index}: ${fruit}`);
});
```

### 2. Изменение исходного массива
Хотя для трансформации лучше использовать `map`, `forEach` позволяет изменять элементы прямо в исходном массиве, используя третий аргумент.

```javascript
const numbers = [1, 2, 3];

numbers.forEach((num, index, arr) => {
  arr[index] = num * 10;
});

console.log(numbers); // [10, 20, 30]
```

---

## Когда НЕ использовать forEach

1.  **Если нужна трансформация:** Если вам нужен новый массив на основе старого, используйте `map()`.
2.  **Если нужна фильтрация:** Используйте `filter()`.
3.  **Если важна скорость и возможность прерывания:** В критических для производительности местах обычный цикл `for` работает быстрее и позволяет выйти из цикла в любой момент.
4.  **Асинхронность:** `forEach` "не умеет" ждать выполнения `await` внутри колбэка. Если вам нужно последовательно выполнять асинхронные действия, используйте `for...of`.

```javascript
// ⚠️ ТАК НЕ РАБОТАЕТ
arr.forEach(async (item) => {
  await someAsyncFunction(item); // forEach не будет ждать завершения
});
```

### Резюме: forEach vs map
* **forEach**: "Сделай что-то с каждым элементом". (Возвращает `undefined`).
* **map**: "Преврати каждый элемент в другой и дай мне новый массив". (Возвращает массив).
