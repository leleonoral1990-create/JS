# Каррирование (Currying)

**Каррирование** — это техника в функциональном программировании, при которой функция с несколькими аргументами трансформируется в последовательность функций, каждая из которых принимает ровно **один аргумент**.

Вместо того чтобы вызывать функцию как `f(a, b, c)`, каррирование позволяет вызвать её как `f(a)(b)(c)`.



---

## Как это работает?

Когда вы вызываете каррированную функцию, она не выполняет вычисление сразу. Она возвращает новую функцию, которая ожидает следующий аргумент. И так продолжается до тех пор, пока не будут переданы все аргументы, после чего выполняется итоговый результат.

### Пример на JavaScript

**Обычная функция:**
```javascript
function sum(a, b) {
    return a + b;
}
console.log(sum(2, 3)); // 5
```

**Каррированная версия:**
```javascript
function currySum(a) {
    return function(b) {
        return a + b;
    };
}

// Или через стрелочные функции (более современно):
const currySumArrow = a => b => a + b;

console.log(currySum(2)(3)); // 5
```

## Зачем это нужно? (Преимущества)

### 1. Частичное применение (Partial Application)
Каррирование позволяет зафиксировать некоторые аргументы и создать новую, более специализированную функцию. Это мощный инструмент для переиспользования кода.

**Пример: Логирование**
```javascript
const log = date => severity => message => 
    `[${date.getHours()}:${date.getMinutes()}] [${severity}] ${message}`;

// Фиксируем дату (создаем логгер для "сейчас")
const logNow = log(new Date());

// Фиксируем тип ошибки
const debugNow = logNow("DEBUG");
const errorNow = logNow("ERROR");

console.log(debugNow("Проверка системы")); // [18:09] [DEBUG] Проверка системы
console.log(errorNow("Критический сбой!")); // [18:09] [ERROR] Критический сбой!
```

### 2. Упрощение передачи функций в колбэки
Каррированные функции отлично сочетаются с методами массивов (`map`, `filter`), так как они ожидают функцию с одним аргументом.

```javascript
const multiply = a => b => a * b;
const double = multiply(2); // Создали функцию удвоения

const numbers = [1, 2, 3, 4];
const doubledNumbers = numbers.map(double); // [2, 4, 6, 8]
```

---

## Разница между Каррированием и Частичным применением

Эти понятия часто путают, но между ними есть тонкое различие:
* **Каррирование:** Функция с $N$ аргументами превращается в цепочку из $N$ функций по **одному** аргументу в каждой.
* **Частичное применение:** Функция с $N$ аргументами превращается в функцию с меньшим количеством аргументов (за счет фиксации части из них).



---

## Автоматическое каррирование (библиотеки)

В реальных проектах редко пишут цепочки функций вручную. Обычно используют вспомогательные функции из библиотек типа **Lodash** или **Ramda**.

```javascript
import _ from 'lodash';

function abc(a, b, c) {
  return a + b + c;
}

const curried = _.curry(abc);

curried(1)(2)(3); // 6
curried(1, 2)(3); // 6 (Lodash позволяет передавать несколько аргументов сразу)
curried(1)(2, 3); // 6
```

### Резюме:
Каррирование делает ваш код более **модульным**, позволяет строить сложные функции из простых кирпичиков и облегчает чтение логики за счет декларативного стиля.
