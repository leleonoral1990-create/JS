# Метод Array.prototype.map()

Метод `map()` — это один из самых часто используемых методов для трансформации данных. Он проходит по каждому элементу массива, применяет к нему переданную функцию-колбэк (callback) и **создает абсолютно новый массив** из результатов выполнения этой функции.



## Синтаксис

```javascript
map(callbackFn)
map(callbackFn, thisArg)
```

Функция `callbackFn` принимает три аргумента:
1.  **`element`**: Текущий обрабатываемый элемент массива.
2.  **`index`** (необязательно): Индекс текущего элемента.
3.  **`array`** (необязательно): Сам исходный массив, по которому проходится `map`.

### Возвращаемое значение
* **Новый массив**, каждый элемент которого является результатом выполнения колбэка.

---

## Ключевые особенности

1.  **Немутирующий метод:** `map()` не изменяет оригинальный массив (хотя это можно сделать принудительно внутри колбэка, но так делать не рекомендуется).
2.  **Одинаковая длина:** Итоговый массив всегда будет иметь **ту же самую длину**, что и исходный массив. Вы не можете отфильтровать элементы с помощью `map` (для этого есть `filter()`).
3.  **Обязательный `return`:** Если внутри колбэка ничего не вернуть (нет слова `return` или стрелочная функция с фигурными скобками без возврата), то в новый массив на это место запишется `undefined`.

---

## Примеры использования

### 1. Базовая трансформация (математика)
```javascript
const numbers = [1, 4, 9];
const roots = numbers.map(num => Math.sqrt(num));

console.log(roots);   // [1, 2, 3]
console.log(numbers); // [1, 4, 9] (оригинал не изменился)
```

### 2. Извлечение данных из массива объектов
Это самый популярный сценарий использования `map` при разработке интерфейсов (например, в React).

```javascript
const users = [
  { id: 1, name: 'Alice' },
  { id: 2, name: 'Bob' },
  { id: 3, name: 'Charlie' }
];

// Получаем массив, состоящий только из имен
const names = users.map(user => user.name);

console.log(names); // ["Alice", "Bob", "Charlie"]
```

### 3. Использование индекса
```javascript
const elements = ['Fire', 'Air', 'Water'];

const listItems = elements.map((element, index) => {
  return `${index + 1}. ${element}`;
});

console.log(listItems); // ["1. Fire", "2. Air", "3. Water"]
```

## Важные нюансы и ловушки

### Ловушка с `parseInt`
Классический вопрос с собеседований: что выведет следующий код?
```javascript
const numbers = ['1', '2', '3'].map(parseInt);
console.log(numbers);
```
**Ответ:** `[1, NaN, NaN]`.
**Почему?** Метод `map` передает в колбэк три аргумента: `(element, index, array)`. Функция `parseInt` принимает два: `(string, radix)`. 
На первой итерации `parseInt('1', 0)` срабатывает нормально. На второй итерации происходит `parseInt('2', 1)`, что ломает парсер, так как системы счисления с основанием 1 не существует (возвращается `NaN`).

**Правильное решение:**
```javascript
const numbers = ['1', '2', '3'].map(str => parseInt(str)); // [1, 2, 3]
// или
const numbers = ['1', '2', '3'].map(Number); // [1, 2, 3]
```

### Когда НЕ нужно использовать `map`
Не используйте `map`, если вы не собираетесь использовать возвращаемый им массив (например, если вам нужно просто вывести элементы в консоль или изменить DOM). 
* Если массив не нужен — используйте `forEach()` или цикл `for...of`.
* `map` — это про **создание** новых данных на основе старых.
