# Метод Array.prototype.reduce()

Метод `reduce()` — это самый мощный и универсальный инструмент для работы с массивами в JavaScript. Он применяет функцию-колбэк к каждому элементу массива (слева направо), последовательно передавая результат предыдущего вычисления в следующее. В итоге массив "сворачивается" (редуцируется) в **одно-единственное итоговое значение**.

Это значение может быть чем угодно: числом, строкой, объектом или даже новым массивом. По сути, с помощью `reduce` можно воспроизвести поведение `map`, `filter` и любых других методов.



## Синтаксис

```javascript
reduce(callbackFn)
reduce(callbackFn, initialValue)
```

Функция `callbackFn` принимает четыре аргумента:
1.  **`accumulator`** (Аккумулятор): Значение, возвращенное предыдущим выполнением колбэка. При первом вызове он равен `initialValue` (если тот указан).
2.  **`currentValue`** (Текущее значение): Текущий обрабатываемый элемент массива.
3.  **`currentIndex`** (необязательно): Индекс текущего элемента.
4.  **`array`** (необязательно): Исходный массив.

**`initialValue`** (необязательно) — начальное значение, с которым стартует аккумулятор.

### Возвращаемое значение
* Итоговое значение аккумулятора после прохождения всего массива.

---

## 🚨 Главное правило: `initialValue`

Понимание того, как работает `reduce` без начального значения — ключ к избежанию 90% ошибок.

* **Если `initialValue` УКАЗАН:** Аккумулятор при первой итерации равен `initialValue`, а `currentValue` равен первому элементу массива (индекс 0).
* **Если `initialValue` НЕ УКАЗАН:** Аккумулятор при первой итерации равен **первому элементу массива** (индекс 0), а `currentValue` — **второму элементу** (индекс 1). То есть метод пропускает нулевой индекс.

*Если массив пустой и `initialValue` не указан, `reduce` выбросит ошибку `TypeError`.*

## Примеры использования

### 1. Базовая математика (Сумма всех чисел)
```javascript
const numbers = [1, 2, 3, 4];

// С начальным значением 0 (рекомендуемый подход)
const sum = numbers.reduce((acc, current) => acc + current, 0);

console.log(sum); // 10
```

### 2. Подсчет количества элементов (Таблица частот)
Частая задача: посчитать, сколько раз каждый элемент встречается в массиве. Здесь результатом должен быть **объект**, поэтому мы передаем пустой объект `{}` как `initialValue`.

```javascript
const fruits = ['apple', 'banana', 'orange', 'apple', 'orange', 'apple'];

const count = fruits.reduce((acc, fruit) => {
  // Если фрукт уже есть в объекте, увеличиваем счетчик, иначе задаем 1
  acc[fruit] = (acc[fruit] || 0) + 1;
  
  // ОБЯЗАТЕЛЬНО возвращаем аккумулятор для следующей итерации
  return acc; 
}, {});

console.log(count); 
// { apple: 3, banana: 1, orange: 2 }
```

### 3. Группировка массива объектов по свойству
Еще один классический сценарий из реальной практики — сгруппировать данные с бэкенда.

```javascript
const people = [
  { name: 'Alice', age: 21 },
  { name: 'Bob', age: 25 },
  { name: 'Charlie', age: 21 }
];

const groupedByAge = people.reduce((acc, person) => {
  const age = person.age;
  // Если массива для этого возраста еще нет, создаем его
  if (!acc[age]) {
    acc[age] = [];
  }
  // Пушим пользователя в нужную возрастную группу
  acc[age].push(person);
  return acc;
}, {});

console.log(groupedByAge);
/*
{
  '21': [{ name: 'Alice', age: 21 }, { name: 'Charlie', age: 21 }],
  '25': [{ name: 'Bob', age: 25 }]
}
*/
```

## Частые ошибки (Шпаргалка)

1.  **Забыли `return acc;`:** Если внутри фигурных скобок колбэка нет `return`, на следующей итерации аккумулятор станет `undefined`, и код сломается.
2.  **Забыли `initialValue` при работе с объектами:**
    ```javascript
    const items = [{ price: 10 }, { price: 20 }];
    // ОШИБКА: Если не передать 0, на первой итерации acc будет равен { price: 10 }
    // И вы попытаетесь сделать { price: 10 } + 20
    const total = items.reduce((acc, item) => acc + item.price); // вернет "[object Object]20"
    
    // ПРАВИЛЬНО:
    const correctTotal = items.reduce((acc, item) => acc + item.price, 0); // вернет 30
    ```
3.  **Не используйте `reduce` там, где есть более простые методы:** Если вам нужно просто отфильтровать массив, используйте `filter`. Если нужно изменить каждый элемент — используйте `map`. `reduce` хорош именно для "сворачивания" или сложных трансформаций (например, фильтрация + маппинг за один проход для оптимизации).
