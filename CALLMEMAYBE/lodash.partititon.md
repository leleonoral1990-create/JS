# Метод _.partition() (библиотека Lodash)

Метод `_.partition()` — это мощный инструмент, который позволяет за один проход разделить коллекцию на две части: на те элементы, которые удовлетворяют условию, и на те, которые нет. 

Вместо того чтобы вызывать `filter()` и `reject()` по отдельности (что заставило бы программу проходить по массиву дважды), `partition()` делает это одновременно и возвращает **массив из двух массивов**.



## Синтаксис

```javascript
_.partition(collection, [predicate=_.identity])
```

**Параметры:**
1.  **`collection`**: Массив или объект для разделения.
2.  **`predicate`**: Условие (функция, объект или строка), по которому происходит деление.

**Возвращаемое значение:**
* Массив массивов: `[ [элементы, прошедшие проверку], [элементы, не прошедшие проверку] ]`.

---

## Способы использования

### 1. С использованием функции
Самый гибкий способ для числовых или логических проверок.

```javascript
const numbers = [1, 2, 3, 4, 5, 6];

// Разделяем на четные и нечетные
const [evens, odds] = _.partition(numbers, n => n % 2 === 0);

console.log(evens); // [2, 4, 6]
console.log(odds);  // [1, 3, 5]
```

### 2. С использованием объекта (matches)
Идеально для сортировки данных по конкретным критериям.

```javascript
const users = [
  { 'user': 'barney',  'age': 36, 'active': false },
  { 'user': 'fred',    'age': 40, 'active': true },
  { 'user': 'pebbles', 'age': 1,  'active': false }
];

// Разделяем на активных и неактивных
const [activeUsers, inactiveUsers] = _.partition(users, { 'active': true });

console.log(activeUsers);   // [{ 'user': 'fred', ... }]
console.log(inactiveUsers); // [{ 'user': 'barney', ... }, { 'user': 'pebbles', ... }]
```

### 3. С использованием строки (property)
Разделяет по наличию или истинности свойства.

```javascript
const users = [
  { 'user': 'barney', 'active': true },
  { 'user': 'fred',   'active': false }
];

// Те, у кого 'active' истинно, попадут в первый массив, остальные — во второй
const [active, inactive] = _.partition(users, 'active');
```

---

## Ключевые особенности

* **Эффективность:** Это единственный проход по циклу. Для больших массивов данных это в два раза быстрее, чем последовательное использование `filter` и `reject`.
* **Деструктуризация:** Поскольку метод возвращает массив из двух элементов, его очень удобно использовать вместе с деструктуризацией массива: `const [pass, fail] = _.partition(...)`.
* **Универсальность:** Работает не только с массивами, но и с объектами (разделяя их значения).

## Сравнение с нативным JavaScript
В нативном JS (начиная с ES2024) появился похожий метод `Object.groupBy()`, но он создает объект с ключами, в то время как `partition` всегда гарантирует четкую структуру из двух массивов, что часто удобнее для дальнейшей обработки.
