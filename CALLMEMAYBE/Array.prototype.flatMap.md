# Метод Array.prototype.flatMap()

Метод `flatMap()` — это комбинация двух методов: сначала он работает как `map()`, а затем применяет `flat()` с глубиной 1 к полученному результату. Он невероятно полезен, когда в процессе трансформации массива у вас создаются вложенные массивы, которые нужно сразу "разгладить".



## Синтаксис

```javascript
flatMap(callbackFn)
flatMap(callbackFn, thisArg)
```

Функция `callbackFn` принимает те же аргументы: `element`, `index`, `array`.

### Возвращаемое значение
* **Новый массив**, в котором каждый элемент был трансформирован и поднят на один уровень вложенности вверх.

---

## Зачем он нужен? (flatMap vs map)

Представьте, что у вас есть массив предложений, и вы хотите получить массив всех слов.

```javascript
const sentences = ["JavaScript is fun", "I love coding"];

// Использование обычного map()
const mapped = sentences.map(s => s.split(" "));
console.log(mapped); 
// [["JavaScript", "is", "fun"], ["I", "love", "coding"]] <-- Вложенные массивы

// Использование flatMap()
const flatMapped = sentences.flatMap(s => s.split(" "));
console.log(flatMapped);
// ["JavaScript", "is", "fun", "I", "love", "coding"] <-- Плоский массив!
```

---

## Ключевые особенности

1.  **Глубина разглаживания:** `flatMap` разглаживает массив только на **один уровень** вложенности (`depth: 1`). Если ваш колбэк возвращает массив, в котором есть еще один массив, глубокой очистки не произойдет.
2.  **Эффективность:** Вызов `arr.flatMap(x => x)` работает эффективнее, чем цепочка `arr.map(x => x).flat()`, так как проход по массиву совершается только один раз.
3.  **Удаление элементов:** С помощью `flatMap` можно одновременно изменять и удалять элементы (работая как фильтр). Чтобы "удалить" элемент, нужно просто вернуть из колбэка пустой массив `[]`.

---

## Примеры использования

### 1. Добавление и удаление элементов (2-в-1)
Допустим, мы хотим удвоить положительные числа, а отрицательные — просто удалить.

```javascript
const numbers = [1, -2, 3, 4, -5];

const result = numbers.flatMap(n => {
  return n > 0 ? [n, n * 2] : []; 
});

console.log(result); // [1, 2, 3, 6, 4, 8]
```
*Здесь `flatMap` заменил нам связку `filter` + `map`.*

### 2. Раскрытие вложенных данных
Если у вас есть список заказов, и каждый заказ содержит массив товаров, `flatMap` соберет все товары в один список.

```javascript
const orders = [
  { id: 1, items: ['Laptop', 'Mouse'] },
  { id: 2, items: ['Monitor'] }
];

const allItems = orders.flatMap(order => order.items);

console.log(allItems); // ["Laptop", "Mouse", "Monitor"]
```

---

## Важные нюансы

* **Не подходит для глубокой вложенности:** Если вам нужно разгладить массив на 2 и более уровней, `flatMap` не поможет. Придется использовать `map().flat(2)`.
* **Поддержка:** Метод появился в стандарте ES2019, поэтому в совсем старых браузерах (вроде IE) он не поддерживается без полифилов.
* **Читаемость:** Несмотря на мощь, не стоит использовать `flatMap` для простой фильтрации, если это делает код менее понятным для коллег. Используйте его там, где логика "трансформируй и разгладь" является основной задачей.
