# JSON

**JSON** (JavaScript Object Notation) — это глобальный объект, который предоставляет методы для преобразования значений в формат JSON и обратно. В отличие от большинства глобальных объектов, `JSON` не является конструктором: его нельзя вызвать как функцию или использовать с оператором `new`.



---

## 1. Статические методы

Объект `JSON` содержит два основных метода:

| Метод | Описание |
| :--- | :--- |
| **`JSON.parse()`** | Разбирает строку JSON и строит соответствующее ей JavaScript-значение или объект. |
| **`JSON.stringify()`** | Преобразует JavaScript-значение в строку формата JSON. |

---

## 2. JSON.parse()

Метод анализирует строку как JSON.

```javascript
JSON.parse(text[, reviver])
```

* **`text`**: Строка для анализа.
* **`reviver`** (необязательно): Функция, которая будет вызвана для каждого ключа и значения перед возвратом результата. Позволяет трансформировать данные (например, превратить строку с датой в объект `Date`).

**Пример:**
```javascript
const json = '{"result": true, "count": 42}';
const obj = JSON.parse(json);

console.log(obj.count); // 42
```

---

## 3. JSON.stringify()

Метод переводит объект или значение в строковое представление.

```javascript
JSON.stringify(value[, replacer[, space]])
```

* **`value`**: Значение, преобразуемое в JSON.
* **`replacer`** (необязательно): Функция или массив имен свойств, которые должны быть включены в JSON.
* **`space`** (необязательно): Число или строка для управления отступами в итоговой строке (для человекочитаемого вида).

**Пример:**
```javascript
const user = {
  name: "Eleonora",
  role: "admin",
  id: 1
};

const str = JSON.stringify(user, null, 2);
/* Вывод:
{
  "name": "Eleonora",
  "role": "admin",
  "id": 1
}
*/
```

---

## 4. Особенности синтаксиса JSON

JSON является подмножеством синтаксиса JavaScript, но имеет строгие правила:

1.  **Кавычки:** Ключи и строковые значения должны быть заключены только в двойные кавычки (`"key"`). Одинарные кавычки запрещены.
2.  **Типы данных:** Разрешены строки, числа, объекты, массивы, логические значения (`true`, `false`) и `null`.
3.  **Запрещенные значения:** `undefined`, функции и символы (`Symbol`) не являются валидными данными в JSON.
    * В объектах они игнорируются при сериализации.
    * В массивах они заменяются на `null`.
4.  **Запятые:** Запрещены «висячие» запятые (запятая после последнего элемента в массиве или объекте).

---

## 5. Метод toJSON()

Если преобразуемый объект имеет метод с именем `toJSON`, то `JSON.stringify` вызовет его и будет использовать возвращаемое им значение для сериализации вместо самого объекта. Это часто используется для объектов `Date`, которые возвращают строку в формате ISO.

```javascript
const room = {
  number: 23,
  toJSON() {
    return this.number;
  }
};

console.log(JSON.stringify(room)); // "23"
```
