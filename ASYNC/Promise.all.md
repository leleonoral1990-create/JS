# Метод Promise.all()

Метод **`Promise.all()`** принимает массив (или любой итерируемый объект) промисов и возвращает один новый промис. Этот метод идеально подходит для случаев, когда вам нужно запустить несколько асинхронных операций одновременно и дождаться завершения **всех** из них.

---

## 1. Принцип работы: «Все или ничего»

`Promise.all` ведет себя согласно двум сценариям:

1.  **Успех:** Возвращенный промис выполнится только тогда, когда **все** переданные промисы завершатся успешно. Результатом будет массив значений в том же порядке, в котором шли исходные промисы.
2.  **Отказ:** Если хотя бы один промис из списка отклонится (ошибка), то `Promise.all` **немедленно** отклоняется с этой же ошибкой. Остальные промисы продолжат выполняться в фоне, но их результат будет проигнорирован.

---

## 2. Синтаксис

```javascript
const combinedPromise = Promise.all([promise1, promise2, promise3]);
```

---

## 3. Практический пример: Загрузка нескольких ресурсов

Представьте, что вам нужно получить данные пользователя и список его заказов одновременно.

```javascript
const userPromise = fetch('/api/user');
const ordersPromise = fetch('/api/orders');

Promise.all([userPromise, ordersPromise])
  .then(([userResponse, ordersResponse]) => {
    // Оба запроса завершены успешно
    return Promise.all([userResponse.json(), ordersResponse.json()]);
  })
  .then(([user, orders]) => {
    console.log('Пользователь:', user);
    console.log('Заказы:', orders);
  })
  .catch(error => {
    // Сработает, если упадет ХОТЯ БЫ ОДИН из запросов
    console.error('Ошибка при загрузке данных:', error);
  });
```

---

## 4. Сравнение с другими методами Promise

| Метод | Результат | Когда использовать |
| :--- | :--- | :--- |
| **`Promise.all`** | Массив результатов или первая ошибка. | Когда нужны **все** данные для продолжения работы. |
| **`Promise.allSettled`** | Массив объектов со статусами и результатами. | Когда нужно дождаться всех, даже если часть упадет. |
| **`Promise.race`** | Результат самого быстрого (успех или ошибка). | Для установки таймаутов. |
| **`Promise.any`** | Результат первого успешного. | Когда достаточно любого одного рабочего источника. |

---

## 5. Важные нюансы

* **Порядок сохраняется:** Даже если второй промис выполнился быстрее первого, в итоговом массиве его результат все равно будет под вторым индексом.
* **Не-промисы в массиве:** Если в массив передать обычное значение (число, строку), оно будет автоматически обернуто в `Promise.resolve()`.
* **Пустой массив:** `Promise.all([])` возвращает уже выполненный промис с пустым массивом `[]`.

---

### Резюме
Используйте `Promise.all()`, чтобы ускорить работу приложения за счет параллельного выполнения запросов. Но помните: если вам важен результат каждого отдельного запроса, даже если остальные упадут, лучше использовать `Promise.allSettled()`.
