# Планирование вызовов: setTimeout и setInterval

В JavaScript мы часто сталкиваемся с тем, что функцию нужно выполнить не прямо сейчас, а через некоторое время или с определенной периодичностью. Для этого существуют два основных метода: **`setTimeout`** и **`setInterval`**.



---

## 1. setTimeout (Разовый вызов)

Метод **`setTimeout`** позволяет вызвать функцию один раз через определенный интервал времени.

**Синтаксис:**
```javascript
let timerId = setTimeout(func|code, [delay], [arg1], [arg2], ...)
```

* **`func|code`**: Функция или строка кода (строки не рекомендуются).
* **`delay`**: Задержка в миллисекундах ($1000$ мс = $1$ сек). По умолчанию — $0$.
* **`arg1, arg2...`**: Аргументы, которые будут переданы в функцию при вызове.

**Пример:**
```javascript
function sayHi(phrase, name) {
  console.log(`${phrase}, ${name}!`);
}

setTimeout(sayHi, 2000, "Привет", "Элеонора"); // Выведет через 2 секунды
```

---

## 2. setInterval (Регулярный повтор)

Метод **`setInterval`** работает так же, как и `setTimeout`, но запускает функцию не один раз, а **регулярно** через равные промежутки времени.

```javascript
// Повторять каждые 2 секунды
let timerId = setInterval(() => console.log('Тик'), 2000);

// Остановить через 10 секунд
setTimeout(() => { clearInterval(timerId); console.log('Стоп!'); }, 10000);
```

---

## 3. Отмена вызова: clearTimeout и clearInterval

Когда мы вызываем таймер, он возвращает «идентификатор таймера» (`timerId`). Мы должны сохранять его в переменную, чтобы иметь возможность отменить запланированное действие.

* **`clearTimeout(timerId)`**: Отменяет выполнение.
* **`clearInterval(timerId)`**: Останавливает бесконечный цикл повторов.

> **Важно:** В браузерах `timerId` обычно является числом, но в Node.js это объект. В любом случае, работа с ними через методы `clear...` идентична.

---

## 4. Рекурсивный setTimeout (Продвинутый уровень)

Часто вместо `setInterval` разработчики используют «вложенный» или рекурсивный `setTimeout`. Это дает гораздо больше контроля над процессом.



**Почему это лучше, чем `setInterval`?**
1.  **Гарантированная пауза**: В `setInterval` время, затраченное на выполнение самой функции, «съедает» интервал. Если функция сложная и долгая, пауза между её завершением и новым стартом будет меньше запланированной. Вложенный `setTimeout` гарантирует фиксированный отдых *после* завершения работы кода.
2.  **Гибкость**: Вы можете менять задержку динамически в зависимости от результата предыдущего вызова (например, если сервер не отвечает, увеличивать интервал ожидания).

```javascript
let delay = 1000;

let timerId = setTimeout(function tick() {
  console.log('Выполняю тяжелую работу...');
  
  // Если сервер загружен, увеличиваем интервал до 5 секунд
  if (serverOverloaded) delay = 5000;

  timerId = setTimeout(tick, delay); // Планируем следующий вызов
}, delay);
```

---

## 5. Нулевая задержка: setTimeout(..., 0)

Иногда можно встретить код `setTimeout(func, 0)`. Это не значит, что функция выполнится мгновенно. Это значит «выполни её как можно скорее, но **только после того** как текущий основной поток кода (стек вызовов) полностью завершится».

**Зачем это нужно?**
* Чтобы разбить «тяжелую» задачу на части и не блокировать интерфейс браузера.
* Чтобы дать браузеру возможность отрисовать изменения в DOM перед тем, как продолжить вычисления.

---

## Нюансы и ограничения

1.  **Браузерная экономия**: Если вкладка неактивна (свернута), браузеры снижают минимальную частоту таймеров до $1000$ мс и более, чтобы экономить заряд батареи.
2.  **Задержка в 4 мс**: Согласно стандарту HTML5, после 5 вложенных вызовов таймера браузер принудительно устанавливает минимальную задержку в $4$ мс.
3.  **this**: Внутри `setTimeout` значение `this` теряется (оно будет ссылаться на глобальный объект `window`). Для решения используйте стрелочные функции или `.bind(this)`.

### Резюме

| Метод | Особенности |
| :--- | :--- |
| **`setTimeout`** | Один вызов. Идеально для простых отложенных действий. |
| **`setInterval`** | Повтор. Подходит, если точность пауз между вызовами не критична. |
| **Рекурсивный `setTimeout`** | Самый гибкий способ. Гарантирует паузу между выполнениями. |
