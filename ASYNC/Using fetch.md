# Использование Fetch API

**Fetch API** — это современный стандарт для выполнения сетевых запросов в JavaScript. Он пришел на смену старому `XMLHttpRequest`, предлагая более мощный и гибкий функционал, полностью построенный на **Промисах**.

Если Промис — это «обещание» данных, то `fetch` — это самый частый способ получить это обещание от реального сервера.



---

## 1. Базовый синтаксис (GET-запрос)

В самом простом виде `fetch` принимает URL и возвращает промис, который разрешается в объект **Response** (ответ сервера).

```javascript
fetch('https://api.example.com/data')
  .then(response => {
    // На этом этапе мы получили только заголовки ответа
    console.log('Статус ответа:', response.status); 
    
    // Чтобы прочитать само тело (данные), нужно вызвать метод .json()
    return response.json(); 
  })
  .then(data => {
    // Здесь уже доступны реальные данные
    console.log('Данные получены:', data);
  })
  .catch(error => {
    // Сюда попадем только если произошла сетевая ошибка (нет интернета)
    console.error('Ошибка запроса:', error);
  });
```

---

## 2. Важная деталь: Проверка успеха

Особенность `fetch` в том, что он **не переходит в состояние ошибки (`catch`)**, даже если сервер вернул `404` (Не найдено) или `500` (Ошибка сервера). Промис отклонится только при физическом сбое сети или если заблокирован CORS.

Поэтому всегда нужно проверять свойство **`response.ok`**:

```javascript
fetch(url)
  .then(response => {
    if (!response.ok) {
      throw new Error(`Ошибка HTTP: ${response.status}`);
    }
    return response.json();
  })
  .catch(err => console.error(err));
```

---

## 3. Отправка данных (POST-запрос)

Для отправки данных на сервер (например, при регистрации пользователя) во втором аргументе `fetch` передается объект настроек.

```javascript
const userData = { name: "Eleonora", job: "Developer" };

fetch('https://api.example.com/users', {
  method: 'POST', // Метод запроса
  headers: {
    'Content-Type': 'application/json' // Указываем серверу, что отправляем JSON
  },
  body: JSON.stringify(userData) // Превращаем объект в строку JSON
})
  .then(res => res.json())
  .then(result => console.log('Успех:', result));
```

---

## 4. Работа с объектом Response

Объект ответа (`Response`), который возвращает `fetch`, содержит много полезной информации:
* **`status`**: HTTP-код (200, 404, 500 и т.д.).
* **`ok`**: Булево значение, `true` если статус в диапазоне 200–299.
* **`headers`**: Объект со всеми заголовками ответа.
* **Методы чтения тела**:
    * `.json()` — парсит ответ как JSON.
    * `.text()` — возвращает ответ как обычный текст.
    * `.blob()` — для работы с бинарными данными (изображения, файлы).

---

## 5. Fetch + Async/Await

Хотя `fetch` отлично работает с `.then()`, в современном коде его чаще используют с синтаксисом **`async/await`**, что делает асинхронный код похожим на обычный линейный.

```javascript
async function getUserData() {
  try {
    const response = await fetch('https://api.example.com/user');
    if (!response.ok) throw new Error('Ошибка');
    
    const data = await response.json();
    console.log(data);
  } catch (error) {
    console.log('Случилось что-то плохое:', error);
  }
}
```

### Резюме
`Fetch` — это «окно» вашего JavaScript-кода во внешний мир. Он лаконичен, построен на современных стандартах и легко расширяется.
