# Метод Promise.race()

Метод **`Promise.race()`** (от англ. *race* — «гонка») принимает массив (или любой итерируемый объект) промисов и возвращает новый промис, который будет выполнен или отклонен, как только **любой** из исходных промисов будет завершен. 

Кто первым пришел к финишу (неважно, с успехом или с ошибкой) — тот и определяет результат всей гонки.



---

## 1. Как это работает?

Представь, что ты отправила запрос на три разных сервера (зеркала), чтобы получить один и тот же файл. Тебе не нужны все три ответа — тебе нужен тот, который придет **быстрее всего**. Как только один сервер ответил, «гонка» закончена.

* Если первый завершившийся промис **выполнился успешно**, итоговый промис переходит в состояние `fulfilled`.
* Если первый завершившийся промис **выдал ошибку**, итоговый промис переходит в состояние `rejected`.

---

## 2. Синтаксис

```javascript
const racePromise = Promise.race([promise1, promise2, ...]);
```

* **Аргумент:** Массив промисов (или других значений, которые будут автоматически обернуты в `Promise.resolve()`).
* **Результат:** Промис, результат которого совпадает с результатом самого быстрого «участника».

---

## 3. Практический пример: Таймаут запроса

Это самый популярный сценарий использования `Promise.race()`. Если запрос к серверу идет слишком долго, мы «сбрасываем» его, чтобы пользователь не ждал вечно.

```javascript
// 1. Наш обычный запрос к API
const fetchData = fetch('https://api.example.com/data');

// 2. Промис-таймаут, который выдает ошибку через 3 секунды
const timeout = new Promise((_, reject) => 
  setTimeout(() => reject(new Error('Время ожидания истекло')), 3000)
);

// 3. Гонка!
Promise.race([fetchData, timeout])
  .then(response => console.log('Данные получены:', response))
  .catch(error => console.error('Ошибка или таймаут:', error.message));
```

---

## 4. Сравнение с другими методами Promise

| Метод | Что возвращает? | Когда использовать? |
| :--- | :--- | :--- |
| **`Promise.race`** | Результат **первого** завершенного (любого). | Таймауты, выбор самого быстрого сервера. |
| **`Promise.any`** | Результат **первого успешного**. | Выбор первого рабочего ресурса, игнорируя ошибки остальных. |
| **`Promise.all`** | Результат **всех**, если все успешны. | Когда нужны данные из всех источников сразу. |
| **`Promise.allSettled`** | Результат **всех**, неважно — успех или ошибка. | Общая аналитика по списку задач. |

---

## Важные нюансы

1.  **Пустой массив:** Если передать в `Promise.race([])` пустой массив, возвращенный промис будет находиться в состоянии ожидания (`pending`) **вечно**. Будь осторожна с этим.
2.  **Не-промисы в массиве:** Если в массиве есть обычные значения (не промисы), они считаются «мгновенно завершенными» и, скорее всего, выиграют гонку.
3.  **Судьба «проигравших»:** Те промисы, которые не пришли первыми, **не отменяются**. Они продолжат выполняться в фоновом режиме, но их результат уже не повлияет на результат `Promise.race`.

---

### Резюме
Используй `Promise.race()`, когда тебе нужно ограничить время выполнения операции или когда тебе достаточно одного любого (но самого быстрого) результата из списка.
