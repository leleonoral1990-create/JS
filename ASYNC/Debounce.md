# Функция _.debounce (Lodash)

Функция **`debounce`** (от англ. *de-bounce* — «устранение дребезга») — это один из важнейших инструментов оптимизации производительности в JavaScript. Она позволяет ограничить частоту вызова функции, заставляя её ждать определенное время после последнего «события», прежде чем выполниться.



---

## 1. Зачем это нужно?

В веб-разработке есть события, которые происходят десятки раз в секунду:
* Изменение размера окна (`resize`).
* Прокрутка страницы (`scroll`).
* Ввод текста в поле поиска (`input`).

Если на каждое такое событие «вешать» тяжелую функцию (например, запрос к базе данных), браузер начнет тормозить. `debounce` решает эту проблему: функция сработает только тогда, когда пользователь **сделает паузу**.

---

## 2. Как это работает (на примере поиска)

Представь, что пользователь пишет слово «JavaScript» в строке поиска.
1. Он вводит букву «J» → таймер запускается.
2. Он тут же вводит «a» → старый таймер сбрасывается, запускается новый.
3. Он вводит остальные буквы → таймер каждый раз обнуляется.
4. Он закончил писать и **подождал 300 мс** → функция поиска наконец-то отправляет запрос на сервер.

---

## 3. Синтаксис _.debounce

```javascript
_.debounce(func, [wait=0], [options={}])
```

* **`func`**: Функция, которую нужно «замедлить».
* **`wait`**: Время ожидания в миллисекундах.
* **`options`**: Объект с настройками:
    * `leading`: Вызвать ли функцию в самом начале серии событий (по умолчанию `false`).
    * `trailing`: Вызвать ли функцию в конце серии (по умолчанию `true`).
    * `maxWait`: Максимальное время ожидания (гарантирует вызов, если события идут бесконечно).

---

## 4. Практический пример кода

Давай создадим «умный» поиск, который не спамит сервер запросами.

```javascript
// 1. Наша тяжелая функция запроса
function searchAPI(query) {
    console.log(`--- Отправка запроса на сервер: ${query} ---`);
}

// 2. Создаем дебаунс-версию функции с задержкой 500 мс
const debouncedSearch = _.debounce((event) => {
    searchAPI(event.target.value);
}, 500);

// 3. Вешаем её на инпут
const input = document.querySelector('#search-input');
input.addEventListener('input', debouncedSearch);
```

---

## 5. Методы управления

У дебаунс-функции в Lodash есть полезные методы:
* **`cancel()`**: Отменить запланированный вызов (например, если пользователь закрыл вкладку или стер всё из поиска).
* **`flush()`**: Немедленно вызвать функцию, если она была запланирована.

```javascript
// Пример отмены
window.addEventListener('unload', () => {
    debouncedSearch.cancel();
});
```

---

## 6. Debounce vs Throttle

Их часто путают, но разница принципиальна:

| Метод | Поведение | Аналогия |
| :--- | :--- | :--- |
| **`Debounce`** | Ждет паузу. Группирует много событий в **одно** (в конце). | Лифт: ждет, пока все зайдут. Если заходит новый человек, дверь снова открывается и ожидание начинается заново. |
| **`Throttle`** | Ограничивает частоту. Вызывает функцию не чаще чем раз в X мс. | Кран с водой: как бы сильно ты ни крутил ручку, вода капает с постоянной частотой — одна капля в секунду. |

---

## Резюме
Используй `_.debounce` везде, где ввод пользователя или события браузера могут перегрузить систему. Это один из самых простых способов сделать интерфейс «летающим».
