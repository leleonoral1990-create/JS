# Псевдокласс :not() (Отрицание в CSS)

Псевдокласс **`:not()`**, также известный как «отрицание» (negation pseudo-class), позволяет выбирать элементы, которые **не соответствуют** заданному селектору. Это мощный фильтр, который помогает избежать написания лишних переопределяющих правил.



---

## 1. Синтаксис

```css
/* Выбрать все <p>, кроме тех, у которых есть класс .fancy */
p:not(.fancy) {
  color: black;
}
```

**Параметры:**
* В качестве аргумента принимается один или несколько селекторов (через запятую в современных браузерах).
* Аргумент не может содержать другой псевдокласс `:not()` (запрещена вложенность) и псевдоэлементы (например, `::before`).

---

## 2. Ключевые особенности

### Специфичность (Specificity)
Это самый важный и коварный момент. Сам псевдокласс `:not()` **не добавляет** веса селектору. Однако его вес равен весу **самого тяжелого** селектора в его аргументах.

* `:not(div)` — специфичность `(0, 0, 1)` (как у обычного тега).
* `:not(.my-class)` — специфичность `(0, 1, 0)` (как у класса).
* `:not(#my-id)` — специфичность `(1, 0, 0)` (как у ID).

### Selectors Level 4 (Современный стандарт)
Раньше `:not()` принимал только «простые» селекторы (один класс, один тег). Теперь можно передавать **список** селекторов и **сложные** комбинации.

```css
/* Выбрать все кнопки, кроме "primary" И кроме "disabled" */
button:not(.primary, :disabled) {
  border: 1px solid gray;
}
```

---

## 3. На что обратить внимание

1.  **Инверсия логики**: Если вы пишете `:not(.a.b)`, это выберет элементы, у которых **нет одновременно** обоих классов. Если у элемента есть только `.a`, он будет выбран.
2.  **Повышение специфичности**: Используя `:not(#id)` на обычном теге, вы делаете этот тег невероятно «тяжелым». Это может помешать переопределить его стили позже.
3.  **Бесполезные селекторы**: Селектор `*:not(*)` никогда ничего не выберет, а `section:not(div)` выберет все секции (потому что секция — это не див по определению).

---

## 4. Примеры использования в коде

### Сценарий 1: Стилизация ссылок, кроме кнопок
Часто ссылки стилизуют под кнопки, и нам нужно, чтобы «обычные» ссылки в тексте не получали лишних отступов.

```css
/* Стили для всех ссылок в контенте, кроме тех, что выглядят как кнопки */
.content a:not(.btn) {
  text-decoration: underline;
  color: blue;
}
```

### Сценарий 2: Поля ввода (кроме чекбоксов)
Удобно, когда нужно задать общие стили для текстовых полей, не затрагивая флажки.

```css
/* Применяем ко всем input, кроме checkbox и radio */
input:not([type="checkbox"]):not([type="radio"]) {
  width: 100%;
  padding: 8px;
  border: 1px solid #ccc;
}
```

### Сценарий 3: Списки без последней границы
Классический прием, чтобы у последнего элемента списка не было нижней линии.

```css
li:not(:last-child) {
  border-bottom: 1px solid #eee;
  margin-bottom: 10px;
}
```

## Сравнение

| Характеристика | Старый стандарт (L3) | Новый стандарт (L4) |
| :--- | :--- | :--- |
| **Аргументы** | Только один простой селектор | Список селекторов через запятую |
| **Сложные селекторы** | Запрещены (`:not(p.info)`) | Разрешены (`:not(p .info)`) |
| **Поддержка** | Все браузеры (IE9+) | Все современные браузеры |
