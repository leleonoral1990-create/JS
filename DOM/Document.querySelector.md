# Метод document.querySelector()

Метод `querySelector()` — это универсальный "швейцарский нож" для поиска элементов в DOM. Он позволяет найти **первый** элемент, который соответствует заданному CSS-селектору. Если вам нужно быстро достать конкретный узел, не ограничиваясь только ID или классами, этот метод — лучший выбор.



---

## 1. Синтаксис

```javascript
const element = document.querySelector(selectors);
const element = parentElement.querySelector(selectors);
```

**Параметры:**
* **`selectors`**: Строка, содержащая один или несколько валидных CSS-селекторов. Можно использовать теги, классы, ID, атрибуты и сложные комбинации.

**Возвращаемое значение:**
* Первый найденный объект **`Element`**.
* **`null`**, если совпадений не обнаружено.

---

## 2. Ключевые особенности

### Правило первого вхождения
Метод выполняет обход дерева в глубину (depth-first pre-order traversal) и останавливается сразу же, как только находит **первое** совпадение. Даже если на странице десять элементов с классом `.btn`, `querySelector('.btn')` вернет только самый первый из них.

### Мощь CSS-селекторов
Вы можете использовать абсолютно любой селектор, который работает в CSS:
* **По атрибуту:** `querySelector('[type="email"]')`
* **По вложенности:** `querySelector('nav > ul > li.active')`
* **По псевдоклассам:** `querySelector('li:last-child')`

### Контекстный поиск
Вы можете вызывать метод не только у `document`, но и у любого другого элемента. В этом случае поиск будет ограничен только его дочерними узлами.

---

## 3. Примеры использования в коде

### 1. Базовый поиск
```javascript
// Поиск по ID (аналог getElementById, но медленнее)
const header = document.querySelector('#main-header');

// Поиск по классу
const submitBtn = document.querySelector('.btn-submit');

// Поиск по тегу
const firstParagraph = document.querySelector('p');
```

### 2. Сложные и составные селекторы
```javascript
// Найти первый активный пункт меню внутри конкретного списка
const activeItem = document.querySelector('ul.menu > li.active');

// Найти кнопку, которая одновременно имеет два класса
const primaryCancelBtn = document.querySelector('.btn.btn-cancel');
```

### 3. Обработка отсутствия элемента
Поскольку метод возвращает `null`, если ничего не найдено, всегда полезно добавлять проверку (или использовать *optional chaining*).

```javascript
const modal = document.querySelector('.modal');

// Безопасное использование
modal?.classList.add('is-visible');
```

---

## 4. Нюансы и сравнение

| Характеристика | `querySelector` | `getElementById` | `querySelectorAll` |
| :--- | :--- | :--- | :--- |
| **Что ищет** | Первое совпадение | Один элемент по ID | **Все** совпадения |
| **Селектор** | Любой CSS | Только ID | Любой CSS |
| **Результат** | `Element` или `null` | `Element` или `null` | `NodeList` (статичный) |
| **Скорость** | Средняя | **Максимальная** | Чуть ниже |

> **Интересный факт:** Метод `querySelector` работает по принципу "первый попавшийся". Если вы хотите убедиться, что выбрали именно тот элемент, который нужен, старайтесь делать селектор максимально специфичным.

---

### Подсказка
Помните, что `querySelector` возвращает **живую ссылку** на элемент. Если вы измените его свойства (например, цвет фона), они изменятся на странице мгновенно.
