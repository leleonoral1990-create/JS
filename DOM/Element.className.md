# Свойство Element.className

Свойство **`className`** интерфейса `Element` позволяет получать и устанавливать значение атрибута `class` указанного элемента. Оно работает со списком классов как с единой строкой, где названия разделены пробелами.



---

## 1. Синтаксис

```javascript
// Получение всех классов в виде строки
let cName = element.className;

// Установка (перезапись) всех классов
element.className = "new-class-name";
```

**Тип данных:**
* **Строка (`String`)**: содержит все классы элемента. Если классов нет, возвращается пустая строка.

---

## 2. Ключевые особенности

### Полная перезапись
Присваивание значения свойству `className` полностью удаляет все текущие классы элемента и заменяет их новыми. Это главное отличие от методов `classList.add()`.

```javascript
// Было: <div class="old-class"></div>
el.className = "new-class";
// Стало: <div class="new-class"></div> (old-class удален)
```

### Работа со списком классов
Поскольку это строка, для добавления одного класса без удаления старых приходится использовать конкатенацию, что менее удобно, чем `classList`.

```javascript
// Добавление класса через className (старый способ)
el.className += " added-class";
```

### SVG элементы
Для SVG-элементов свойство `className` возвращает объект `SVGAnimatedString`, а не обычную строку. В современных браузерах для SVG лучше использовать `classList` или `getAttribute('class')`.

---

## 3. Сравнение: className vs classList

| Характеристика | `className` | `classList` |
| :--- | :--- | :--- |
| **Формат** | Строка (`"btn active"`) | Объект-коллекция (`DOMTokenList`) |
| **Изменение** | Заменяет всё содержимое | Точечно добавляет/удаляет/переключает |
| **Удобство** | Низкое (нужен ручной парсинг) | Высокое (есть методы `add`, `remove`, `toggle`) |
| **Скорость** | Высокая для полной замены | Оптимальна для манипуляций с отдельными классами |



---

## 4. Примеры использования в коде

### 1. Быстрая очистка всех классов
```javascript
const box = document.querySelector('.box');

// Удалить абсолютно все классы у элемента
box.className = "";
```

### 2. Массовая замена классов (Смена состояния)
Удобно, когда нужно перевести элемент из одного набора состояний в другой целиком.

```javascript
function setStatus(element, status) {
  // Полностью сбрасываем старые стили и ставим новые базовые
  if (status === 'success') {
    element.className = 'message message-success is-visible';
  } else if (status === 'error') {
    element.className = 'message message-error is-visible';
  }
}
```

### 3. Проверка наличия класса (устаревший подход)
До появления `classList.contains()` проверку делали через поиск подстроки, что было небезопасно (можно случайно найти часть имени другого класса).

```javascript
// ОПАСНО: может найти "active" внутри "super-active"
if (el.className.indexOf('active') !== -1) {
  console.log('Класс найден');
}

// Современный и надежный способ
if (el.classList.contains('active')) {
  console.log('Класс найден');
}
```

## Резюме
В современной разработке `className` используется редко — в основном для полной очистки классов или когда нужно заменить весь набор классов одной строкой (например, при генерации из шаблона). В 95% случаев для добавления, удаления или проверки классов рекомендуется использовать **`classList`**.
