# Метод Element.hasAttribute()

Метод **`hasAttribute()`** возвращает логическое значение (`true` или `false`), указывающее, имеет ли указанный элемент заданный атрибут или нет.



---

## 1. Синтаксис

```javascript
const result = element.hasAttribute(name);
```

**Параметры:**
* **`name`**: Строка, представляющая имя атрибута, наличие которого нужно проверить.

**Возвращаемое значение:**
* **`true`**: если атрибут присутствует (даже если он пустой или равен пустой строке `""`).
* **`false`**: если атрибут отсутствует.

---

## 2. Ключевые особенности

1.  **Регистронезависимость**: В HTML-документах проверка имени атрибута происходит без учета регистра. `hasAttribute('DISABLED')` сработает так же, как и `hasAttribute('disabled')`.
2.  **Проверка наличия, а не значения**: Метод проверяет только факт существования атрибута в теге. Если атрибут есть, но он пустой (`<input disabled>`), метод всё равно вернет `true`.
3.  **Отличие от свойств объекта**: Наличие свойства в объекте JS (например, `element.disabled`) не всегда гарантирует наличие атрибута в HTML-коде, и наоборот. `hasAttribute` смотрит именно в HTML-разметку.

---

## 3. Сравнение: hasAttribute vs getAttribute

| Метод | Что возвращает | Когда использовать |
| :--- | :--- | :--- |
| **`hasAttribute()`** | `true` / `false` | Когда нужно просто проверить "флаг" (например, `required`, `readonly`). |
| **`getAttribute()`** | `string` / `null` | Когда нужно получить конкретное значение (например, `href` или `src`). |

---

## 4. Примеры использования в коде

### 1. Базовая проверка перед действием
```javascript
const link = document.querySelector('a');

if (link.hasAttribute('target')) {
  console.log('Эта ссылка откроется в новом окне или фрейме.');
}
```

### 2. Работа с пользовательскими атрибутами (data-*)
Хотя для них есть `dataset`, иногда `hasAttribute` удобнее для быстрой проверки.

```javascript
const userCard = document.querySelector('.user-card');

// Проверяем, является ли пользователь администратором через атрибут
if (userCard.hasAttribute('data-is-admin')) {
  userCard.classList.add('border-gold');
}
```

### 3. Логика для булевых атрибутов
Для таких атрибутов, как `checked`, `disabled` или `required`, важно наличие самого ключа, а не его значения.

```javascript
const input = document.querySelector('#username');

// Если поле обязательно, добавляем звездочку в лейбл
if (input.hasAttribute('required')) {
  const label = document.querySelector('label[for="username"]');
  label.textContent += ' *';
}
```
