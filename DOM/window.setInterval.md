# Метод window.setInterval()

Метод **`setInterval()`** позволяет многократно вызывать функцию или выполнять фрагмент кода через строго фиксированные промежутки времени. Он продолжает работу до тех пор, пока не будет остановлен или пока не будет закрыто окно (вкладка) браузера.



---

## 1. Синтаксис

```javascript
let intervalID = setInterval(callback, delay, arg1, arg2, ...);
```

**Параметры:**
* **`callback`**: Функция, которая будет выполняться каждые `delay` миллисекунд.
* **`delay`**: Задержка в миллисекундах (1/1000 секунды). Если значение меньше 10, браузер может автоматически увеличить его до 4–10 мс.
* **`arg1, arg2...`** (необязательно): Аргументы, которые будут переданы в функцию `callback` при её выполнении.

**Возвращаемое значение:**
* **`intervalID`**: Уникальный числовой идентификатор интервала. Он используется для последующей остановки таймера.

---

## 2. Остановка интервала: `clearInterval()`

Чтобы прекратить выполнение кода, необходимо вызвать метод `clearInterval()`, передав ему идентификатор, полученный при создании интервала.

```javascript
const timerId = setInterval(() => console.log('Тик'), 1000);

// Спустя 5 секунд останавливаем таймер
setTimeout(() => {
  clearInterval(timerId);
  console.log('Таймер остановлен');
}, 5000);
```

---

## 3. Ключевые особенности и нюансы

### Точность и задержки
Интервал **не гарантирует** идеальную точность. Если основной поток (Main Thread) занят тяжелыми вычислениями, выполнение функции может быть отложено. 

### Наложение вызовов
Если выполнение самой функции внутри `setInterval` занимает больше времени, чем установленная задержка, вызовы могут начать "наслаиваться" друг на друга или выполняться без пауз.
> **Решение:** Для тяжелых операций лучше использовать **рекурсивный `setTimeout`**, который гарантирует фиксированную паузу *между* завершением одного вызова и началом другого.



### Работа в фоновых вкладках
Для экономии ресурсов современные браузеры снижают частоту срабатывания таймеров в неактивных вкладках (обычно до 1 раза в секунду или реже).

---

## 4. Примеры использования в коде

### Сценарий: Секундомер
```javascript
let seconds = 0;

const clockId = setInterval(() => {
  seconds++;
  console.log(`Прошло времени: ${seconds} сек.`);

  if (seconds >= 10) {
    clearInterval(clockId);
    console.log("Время вышло!");
  }
}, 1000);
```

### Сценарий: Передача аргументов в функцию
```javascript
function greet(name, role) {
  console.log(`Привет, ${name}! Ваша роль: ${role}`);
}

// Передаем параметры после задержки
const greetInterval = setInterval(greet, 2000, 'Eleonora', 'Admin');

// Остановка через 7 секунд
setTimeout(() => clearInterval(greetInterval), 7000);
```

---

## 5. Сравнение: setInterval vs setTimeout

| Характеристика | `setInterval` | `setTimeout` |
| :--- | :--- | :--- |
| **Количество запусков** | Бесконечно (до очистки) | Один раз |
| **Пауза** | Между *началом* запусков | Между *концом* и *началом* (рекурсивно) |
| **Использование** | Часы, счетчики, опрос сервера | Отложенное действие, анимация |

### Резюме:
Используйте `setInterval` для простых задач, где важна общая частота запусков. Для сложных асинхронных операций, где время выполнения функции непредсказуемо, выбирайте рекурсивный `setTimeout`.
