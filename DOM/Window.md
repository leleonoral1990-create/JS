# Интерфейс Window

Интерфейс **`Window`** представляет собой окно, содержащее DOM-документ. В браузерном JavaScript это **глобальный объект**: любая переменная или функция, объявленная глобально, на самом деле становится свойством или методом объекта `window`.



---

## 1. Ключевые свойства

Объект `window` предоставляет доступ ко всем основным API браузера.

| Свойство | Описание |
| :--- | :--- |
| **`window.document`** | Возвращает ссылку на объект `document`, находящийся в окне. |
| **`window.location`** | Позволяет получать и изменять текущий URL-адрес страницы. |
| **`window.history`** | Предоставляет доступ к истории сессии браузера (назад/вперед). |
| **`window.navigator`** | Содержит информацию о браузере, ОС и состоянии сети. |
| **`window.localStorage`** | Позволяет хранить данные в браузере бессрочно. |
| **`window.innerWidth` / `innerHeight`** | Ширина и высота области просмотра (viewport) в пикселях. |

---

## 2. Основные методы

Многие методы, которые мы вызываем "напрямую" (например, `alert()`), на самом деле являются методами `window`.

* **Таймеры**: `setTimeout()`, `setInterval()`, `requestAnimationFrame()`.
* **Взаимодействие**: `alert()`, `confirm()`, `prompt()`.
* **Управление окнами**: `open()` (открыть новую вкладку), `close()` (закрыть текущую), `postMessage()` (безопасный обмен данными между окнами/iframe).
* **Стили**: `getComputedStyle()` (получение реальных CSS-значений элемента после применения всех правил).

---

## 3. События Window

Объект `window` — это главный узел для отслеживания событий, касающихся всей страницы целиком.

| Событие | Когда срабатывает |
| :--- | :--- |
| **`load`** | Когда вся страница (включая картинки и стили) полностью загружена. |
| **`resize`** | При изменении размера окна браузера. |
| **`scroll`** | При прокрутке страницы. |
| **`online` / `offline`** | При изменении статуса подключения к интернету. |
| **`popstate`** | При навигации по истории браузера (например, нажатие кнопки «Назад»). |

---

## 4. Window vs Document

Часто возникает путаница между этими двумя объектами.

| Объект | Представляет собой... | Пример использования |
| :--- | :--- | :--- |
| **`Window`** | Весь браузерный контекст (вкладку). | Изменение URL, определение размера экрана. |
| **`Document`** | Конкретную HTML-страницу внутри окна. | Поиск элементов, изменение текста, создание тегов. |

---

## 5. Важные нюансы

1.  **Глобальная область видимости**: Если вы напишете `var x = 10;`, вы сможете обратиться к ней как `window.x`. Однако современные ключевые слова `let` и `const` **не** создают свойств в объекте `window`.
2.  **`globalThis`**: В современном JS рекомендуется использовать `globalThis` вместо `window`, если вы хотите, чтобы код был универсальным (работал и в браузере, и в Node.js).
3.  **Безопасность**: Доступ к объекту `window` другого окна (через `iframe` или `window.open`) ограничен политикой одного источника (Same-Origin Policy). Вы не сможете прочитать `document` чужого сайта из соображений безопасности.

---

> **Интересный факт:** Свойство `window.window` ссылается на само себя. Это сделано для того, чтобы было легче ссылаться на глобальный объект в различных сценариях.
