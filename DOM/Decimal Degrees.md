# Десятичные градусы (Decimal Degrees, DD)

**Десятичные градусы** — это формат представления географических координат (широты и долготы), в котором доли градуса выражаются в виде десятичных дробей. Этот формат является стандартом для большинства современных геоинформационных систем (ГИС), GPS-устройств и веб-карт (таких как Google Maps или Leaflet).

## 1. Сравнение форматов

Традиционно координаты записывались в системе **DMS** (Degrees, Minutes, Seconds — Градусы, Минуты, Секунды). Десятичные градусы упрощают математические расчеты для компьютеров.

| Формат | Пример записи | Применение |
| :--- | :--- | :--- |
| **DMS** | $48^{\circ} 51' 24''$ N, $2^{\circ} 21' 03''$ E | Навигация, морские карты, история. |
| **DD** | `48.8566, 2.3510` | Программирование, базы данных, GPS. |

---

## 2. Математическая модель

Для перевода из традиционных минут и секунд в десятичный формат используется формула:

$$DD = D + \frac{M}{60} + \frac{S}{3600}$$

**Где:**
* $D$ — целые градусы.
* $M$ — минуты.
* $S$ — секунды.

> **Важно про знаки:**
> * **Широта (Latitude):** Север (+) / Юг (-).
> * **Долгота (Longitude):** Восток (+) / Запад (-).
> * *Пример:* $37^{\circ}$ западной долготы в формате DD записывается как **$-37.0$**.

---

## 3. Точность и количество знаков

Количество знаков после запятой в формате DD напрямую определяет физическую точность позиционирования на поверхности Земли (на уровне экватора).

| Знаков после запятой | Точность (приблизительно) | Объект |
| :--- | :--- | :--- |
| **0** | 111 км | Страна или крупный регион. |
| **2** | 1.1 км | Город или поселок. |
| **4** | 11 метров | Индивидуальный земельный участок. |
| **5** | 1.1 метра | Идентификация конкретного дерева. |
| **6** | 11 сантиметров | Точность профессионального GPS-оборудования. |

## Преимущества формата DD
1.  **Простота сортировки**: Координаты — это обычные числа с плавающей точкой, их легко сравнивать и индексировать в базах данных.
2.  **Экономия места**: Запись `43.2389` занимает меньше байт, чем строка `43° 14' 20"`.
3.  **Совместимость**: Все современные библиотеки (Leaflet, Mapbox, OpenLayers) используют DD как основной стандарт.
