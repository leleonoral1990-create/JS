# Элемент `<input type="range">`

Элемент **`<input type="range">`** позволяет пользователю выбирать числовое значение в заданном диапазоне с помощью графического ползунка (слайдера). Этот тип ввода используется, когда точное числовое значение менее важно, чем его относительное положение в диапазоне (например, громкость звука или яркость экрана).



---

## 1. Основные атрибуты

Поведение слайдера определяется набором специфических атрибутов. Если они не указаны, используются значения по умолчанию.

| Атрибут | Описание | Значение по умолчанию |
| :--- | :--- | :--- |
| **`min`** | Минимально допустимое значение. | `0` |
| **`max`** | Максимально допустимое значение. | `100` |
| **`step`** | Шаг изменения значения при перемещении ползунка. | `1` |
| **`value`** | Текущее значение ползунка. | Среднее между `min` и `max` |
| **`list`** | ID элемента `<datalist>`, который создает визуальные засечки (метки) на слайдере. | — |

---

## 2. Ключевые особенности

1.  **Отсутствие точного ввода**: Пользователь не может ввести число с клавиатуры напрямую, он только перемещает бегунок.
2.  **Визуализация**: Внешний вид слайдера сильно зависит от браузера и операционной системы. Для создания уникального дизайна требуются сложные CSS-псевдоэлементы (например, `::-webkit-slider-runnable-track` и `::-webkit-slider-thumb`).
3.  **Отображение значения**: По умолчанию браузер не показывает текущее число рядом с ползунком. Для этого обычно используется JavaScript или элемент `<output>`.

---

## 3. Работа через JavaScript

Для интерактивности важно понимать разницу между двумя событиями:

* **`input`**: Срабатывает непрерывно в процессе перемещения ползунка. Идеально для мгновенного обновления интерфейса.
* **`change`**: Срабатывает только тогда, когда пользователь отпустил кнопку мыши и завершил выбор.

```javascript
const range = document.querySelector('input[type="range"]');
const output = document.querySelector('.value-display');

range.addEventListener('input', (event) => {
  output.textContent = event.target.value; // Обновляем текст в реальном времени
});
```

---

## 4. Примеры использования

### Базовый слайдер с выводом значения
Использование тега `<output>` для автоматической связи с формой.

```html
<form oninput="result.value=parseInt(vol.value)">
  <label for="vol">Громкость:</label>
  <input type="range" id="vol" name="vol" min="0" max="100" step="10" value="50">
  <output name="result" for="vol">50</output>
</form>
```

### Слайдер с засечками (Datalist)
Позволяет пользователю видеть "остановки" на шкале.

```html
<label for="temp">Температура:</label>
<input type="range" id="temp" name="temp" list="markers">

<datalist id="markers">
  <option value="0" label="Заморозка"></option>
  <option value="50" label="Средне"></option>
  <option value="100" label="Кипение"></option>
</datalist>
```

---

## 5. Доступность (Accessibility)

* **Label**: Всегда связывайте слайдер с `<label>`. Это позволяет пользователям экранных дикторов понять, что именно они регулируют.
* **Клавиатура**: Пользователи могут управлять ползунком с помощью клавиш со стрелками (влево/вправо, вверх/вниз), а также клавиш **Home** и **End**. Убедитесь, что фокус на элементе визуально заметен.
