# Элемент `<input>` (HTML)

Элемент **`<input>`** — это самый универсальный и мощный инструмент в HTML-формах. Его поведение, внешний вид и тип принимаемых данных полностью зависят от атрибута `type`.



---

## 1. Основные атрибуты

| Атрибут | Описание |
| :--- | :--- |
| **`type`** | Определяет тип элемента управления (текст, кнопка, чекбокс и т.д.). По умолчанию — `text`. |
| **`name`** | Имя поля. Используется как ключ при отправке данных на сервер. |
| **`value`** | Текущее значение поля. |
| **`placeholder`** | Текст-подсказка, который отображается, когда поле пустое. |
| **`required`** | Делает поле обязательным для заполнения. |
| **`disabled`** | Делает элемент неактивным для взаимодействия и исключает его из отправки. |

---

## 2. Популярные типы (Type)

Элемент `<input>` может принимать более 20 различных значений `type`. Вот самые используемые:

| Тип | Описание | Визуализация |
| :--- | :--- | :--- |
| **`text`** | Однострочное текстовое поле. | Обычная строка. |
| **`password`** | Текстовое поле, где символы скрыты (маскированы). | Точки или звездочки. |
| **`checkbox`** | Флажок для выбора одного или нескольких вариантов. | Квадратная галочка. |
| **`radio`** | Переключатель для выбора одного варианта из группы. | Круглая кнопка. |
| **`email`** | Поле для ввода адреса почты с автоматической проверкой формата. | Вызывает клавиатуру с `@` на мобильных. |
| **`number`** | Поле для ввода чисел (поддерживает `min`, `max`, `step`). | Стрелочки вверх/вниз. |
| **`file`** | Кнопка для выбора файлов с компьютера. | Диалоговое окно выбора файла. |
| **`submit`** | Кнопка для отправки формы на сервер. | Выглядит как кнопка. |

---

## 3. Связь с `<label>` (Доступность)

Для того чтобы форма была доступной, каждый `<input>` должен быть связан с элементом **`<label>`**. Это не только помогает экранным дикторам, но и увеличивает область клика (нажатие на текст активирует поле).

```html
<label for="user-email">Ваш Email:</label>
<input type="email" id="user-email" name="email">

<label>
  <input type="checkbox" name="subscribe"> Подписаться на новости
</label>
```

---

## 4. Встроенная валидация

HTML5 позволяет проверять данные без JavaScript с помощью специальных атрибутов:

* **`pattern`**: Проверка по регулярному выражению.
* **`min` / `max`**: Для типов `number`, `range`, `date`.
* **`maxlength` / `minlength`**: Ограничение количества символов в тексте.

## 5. Примеры использования в коде

### Группа радиокнопок
Чтобы кнопки работали как группа (можно выбрать только одну), у них должен быть одинаковый атрибут `name`.

```html
<p>Выберите пол:</p>
<input type="radio" id="male" name="gender" value="m">
<label for="male">Мужской</label>

<input type="radio" id="female" name="gender" value="f">
<label for="female">Женский</label>
```

### Ползунок и выбор цвета
```html
<label for="volume">Громкость:</label>
<input type="range" id="volume" name="volume" min="0" max="100">

<label for="color">Цвет темы:</label>
<input type="color" id="color" name="theme_color">
```

## Работа через JavaScript

Для получения данных из инпута в JS чаще всего используется свойство `.value`.

```javascript
const input = document.querySelector('input[name="user_name"]');

// Получение значения
console.log(input.value);

// Отслеживание изменений в реальном времени
input.addEventListener('input', (event) => {
    console.log('Пользователь пишет:', event.target.value);
});
```

> **Важно:** У чекбоксов и радиокнопок для проверки состояния используется свойство `.checked` (true/false), а не `.value`.
