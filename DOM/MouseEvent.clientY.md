# Свойство MouseEvent.clientY

Свойство **`clientY`** интерфейса `MouseEvent` возвращает вертикальную координату (по оси $Y$) точки, в которой произошло событие, относительно **вьюпорта** (видимой части окна браузера).



---

## 1. Синтаксис

```javascript
const y = mouseEvent.clientY;
```

**Возвращаемое значение:**
* **Число (`double`)**: количество пикселей от верхнего края вьюпорта до точки события.

---

## 2. Ключевые особенности

1.  **Зависимость от окна, а не документа**: Значение `clientY` всегда отсчитывается от верхнего края видимой области окна. Если вы прокрутите страницу вниз и кликните в самом верху экрана, `clientY` все равно будет близок к `0`.
2.  **Только для чтения**: Вы не можете переместить курсор, изменив это значение. Оно генерируется браузером в момент события.
3.  **Взаимодействие с CSS**: Это свойство идеально подходит для работы с элементами, имеющими `position: fixed`, так как они позиционируются по тем же правилам (относительно окна).

---

## 3. Сравнение систем координат (Y-ось)

Понимание разницы между этими свойствами — залог корректной работы интерфейса.

| Свойство | Точка отсчета (0) | Влияет ли скролл? |
| :--- | :--- | :--- |
| **`clientY`** | **Верхний край окна (Viewport)** | **Нет** |
| `pageY` | Верхний край всего документа | Да (учитывает прокрутку) |
| `screenY` | Верхний край физического монитора | Нет |
| `offsetY` | Верхний край элемента-цели (`target`) | Нет |

---

## 4. Примеры использования в коде

### 1. Определение позиции клика
Простой способ узнать, "высоко" или "низко" кликнул пользователь в окне.

```javascript
document.addEventListener('mousedown', (event) => {
  console.log(`Клик по вертикали: ${event.clientY}px от верха окна`);
});
```

### 2. Расчет позиции для выпадающего меню
Если нам нужно показать меню рядом с курсором, и меню зафиксировано (`fixed`).

```javascript
const contextMenu = document.querySelector('.menu');

window.addEventListener('contextmenu', (e) => {
  e.preventDefault();
  
  contextMenu.style.top = `${e.clientY}px`;
  contextMenu.style.left = `${e.clientX}px`;
  contextMenu.style.display = 'block';
});
```

### 3. Определение `pageY` через `clientY` (если `pageY` не поддерживается)
```javascript
const pageY = event.clientY + window.scrollY;
```

---

## Резюме
Используйте `clientY`, когда вам нужно позиционировать элементы относительно экрана (например, всплывающие подсказки, кастомные курсоры или перетаскиваемые окна). Если же вам нужно поставить метку в конкретном месте длинного текста, которая должна "уезжать" вместе с ним при прокрутке, используйте `pageY`.
