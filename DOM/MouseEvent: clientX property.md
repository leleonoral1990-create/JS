# Свойство MouseEvent.clientX

Свойство **`clientX`** интерфейса `MouseEvent` возвращает горизонтальную координату (по оси $X$) точки, в которой произошло событие, относительно **вьюпорта** (видимой части окна браузера).



---

## 1. Синтаксис

```javascript
const x = mouseEvent.clientX;
```

**Возвращаемое значение:**
* **Число (`double`)**: количество пикселей от левого края вьюпорта.

---

## 2. Ключевые особенности

1.  **Относительность окна**: Значение `clientX` не зависит от того, насколько прокручена страница. Если вы кликните в левый верхний угол видимого окна, значение всегда будет близко к `0`, даже если документ прокручен на 2000 пикселей вниз.
2.  **Только чтение**: Вы не можете изменить положение курсора, присвоив значение этому свойству.
3.  **Дробные значения**: Хотя чаще всего вы видите целые числа, в современных браузерах (и при масштабировании экрана) координаты могут быть дробными для большей точности.

---

## 3. Сравнение систем координат

Это самый важный момент при работе с позиционированием в JS. Ошибка в выборе свойства — главная причина «улетающих» элементов.

| Свойство | Точка отсчета (0,0) | Влияние скролла |
| :--- | :--- | :--- |
| **`clientX`** | **Левый верхний угол окна (Viewport)** | **Нет** |
| `pageX` | Левый верхний угол всего документа | Да (учитывает прокрутку) |
| `screenX` | Левый верхний угол физического монитора | Нет |
| `offsetX` | Левый верхний угол элемента-цели (target) | Нет |

---

## 4. Практические примеры

### 1. Определение позиции клика
Самый простой способ узнать, где находится курсор пользователя в пределах окна.

```javascript
document.addEventListener('click', (event) => {
  console.log(`Клик по горизонтали: ${event.clientX}px`);
});
```

### 2. Следование элемента за мышью (Custom Cursor)
Для элементов с `position: fixed` идеально подходит именно `clientX`, так как они тоже позиционируются относительно вьюпорта.

```javascript
const pointer = document.querySelector('.custom-pointer');

window.addEventListener('mousemove', (e) => {
  // Используем clientX, так как элемент зафиксирован на экране
  pointer.style.left = e.clientX + 'px';
  pointer.style.top = e.clientY + 'px';
});
```

### 3. Расчет `pageX` через `clientX`
Если вам нужно узнать позицию относительно документа в старых браузерах, где нет `pageX`, это делается так:

```javascript
const pageX = event.clientX + window.scrollX;
```

---

## Резюме
Используйте `clientX`, когда вам нужно работать с элементами, которые не зависят от прокрутки (модальные окна, фиксированные меню, кастомные курсоры или UI-интерфейсы игр). Если же вам нужно поставить метку на конкретном абзаце длинной статьи, который может уехать вверх при скролле, ваш выбор — `pageX`.

Удобно ли вам такое сравнение координат, или стоит разобрать пример с перетаскиванием (Drag-and-Drop), где эти различия становятся критичными?
