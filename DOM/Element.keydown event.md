# Событие keydown

Событие **`keydown`** происходит в момент нажатия клавиши на клавиатуре. В отличие от устаревшего события `keypress`, `keydown` срабатывает для всех клавиш, включая служебные (Shift, Alt, Control, Meta).



---

## 1. Справочная информация

| Характеристика | Значение |
| :--- | :--- |
| **Всплывает** | Да |
| **Отменяемое** | Да (отмена предотвращает ввод символа или выполнение системных действий) |
| **Интерфейс** | `KeyboardEvent` |
| **Цель (Target)** | Элемент с фокусом (или `document`/`window`) |

---

## 2. Ключевые свойства объекта события

При срабатывании `keydown` обработчик получает объект `KeyboardEvent` со следующими важными свойствами:

* **`key`**: Возвращает значение нажатой клавиши (например, `"a"`, `"Enter"`, `"ArrowUp"`). Учитывает состояние регистра и раскладку клавиатуры.
* **`code`**: Возвращает физический код клавиши на клавиатуре (например, `"KeyA"`, `"Digit1"`, `"ShiftLeft"`). Не зависит от раскладки или регистра.
* **`repeat`**: Логическое значение (`true`), если клавиша удерживается нажатой и событие генерируется повторно автоповтором.
* **Модификаторы**:
    * `ctrlKey`: Нажат ли Ctrl.
    * `shiftKey`: Нажат ли Shift.
    * `altKey`: Нажат ли Alt.
    * `metaKey`: Нажата ли клавиша Meta (Cmd на Mac, Win на Windows).

---

## 3. Сравнение свойств: key vs code

| Клавиша | Раскладка | `event.key` | `event.code` |
| :--- | :--- | :--- | :--- |
| **Q** | Eng | `"q"` | `"KeyQ"` |
| **Q** (с Shift) | Eng | `"Q"` | `"KeyQ"` |
| **Й** | Rus | `"й"` | `"KeyQ"` |

> **Совет:** Используйте `code`, если вам важно физическое расположение клавиши (например, для управления в играх WASD). Используйте `key`, если вам нужно знать, какой символ ввел пользователь.

---

## 4. Поведение автоповтора (Auto-repeat)

Если пользователь зажмет клавишу, событие `keydown` будет генерироваться циклически до тех пор, пока клавиша не будет отпущена. При этом свойство `event.repeat` будет равно `true` для всех вызовов, кроме первого.

---

## 5. Предотвращение действий по умолчанию

Вызов `event.preventDefault()` в обработчике `keydown` может остановить:
* Ввод текста в `input` или `textarea`.
* Прокрутку страницы клавишами пробела или стрелками.
* Системные сочетания клавиш (если они не зарезервированы ОС).

---

## 6. Примеры использования

### Отслеживание нажатия Enter
```javascript
const input = document.querySelector('input');

input.addEventListener('keydown', (event) => {
  if (event.key === 'Enter') {
    console.log('Пользователь подтвердил ввод:', event.target.value);
  }
});
```

### Обработка комбинаций клавиш
```javascript
document.addEventListener('keydown', (event) => {
  if (event.ctrlKey && event.key === 's') {
    event.preventDefault(); // Отменяем стандартное сохранение страницы браузером
    console.log('Пользователь нажал Ctrl + S (ручное сохранение)');
  }
});
```

### Игнорирование повторных срабатываний
```javascript
window.addEventListener('keydown', (event) => {
  if (event.repeat) return; // Игнорируем, если клавиша зажата
  
  console.log('Клавиша нажата впервые:', event.key);
});
```

---

## Нюансы
* **Фокус:** Чтобы элемент поймал событие `keydown`, он должен быть в фокусе. Теги `<div>` или `<span>` по умолчанию не фокусятся. Чтобы это исправить, добавьте им атрибут `tabindex="0"`.
* **Регистр в коде:** Помните, что значения `key` чувствительны к регистру. Проверка `event.key === 'enter'` не сработает, так как значение будет `"Enter"`.
