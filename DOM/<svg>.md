# Элемент `<svg>` (Scalable Vector Graphics)

Элемент **`<svg>`** — это контейнер, который определяет систему координат для масштабируемой векторной графики. В отличие от растровых изображений (JPEG, PNG), SVG описывает фигуры математически, что позволяет им сохранять идеальную четкость при любом увеличении.



---

## 1. Ключевые атрибуты

| Атрибут | Описание |
| :--- | :--- |
| **`viewBox`** | Определяет "окно просмотра" (систему координат): `min-x, min-y, width, height`. |
| **`width` / `height`** | Задают размеры контейнера в пикселях, процентах или других единицах. |
| **`xmlns`** | Пространство имен XML (обычно `http://www.w3.org/2000/svg`). Обязательно для внешних файлов. |
| **`preserveAspectRatio`** | Определяет, как графика должна масштабироваться, если пропорции `viewBox` не совпадают с `width/height`. |

### Понимание `viewBox`
Это самый важный атрибут. Представьте его как объектив камеры.
* Если `viewBox="0 0 100 100"`, а `width="500px"`, то одна единица внутри SVG будет равна 5 пикселям на экране.

---

## 2. Популярные вложенные элементы

Внутри `<svg>` используются специализированные теги для отрисовки:
* **Базовые фигуры:** `<circle>`, `<rect>`, `<ellipse>`, `<line>`, `<polyline>`, `<polygon>`.
* **Сложные пути:** `<path>` (универсальный инструмент для любых кривых).
* **Группировка:** `<g>` (используется для объединения элементов и применения к ним общих стилей/трансформаций).
* **Текст:** `<text>`.
* **Определения:** `<defs>` (для градиентов, масок и фильтров, которые не отображаются сразу).

---

## 3. Сравнение: SVG vs Canvas

| Характеристика | SVG | Canvas |
| :--- | :--- | :--- |
| **Тип** | Векторный (на основе объектов) | Растровый (на основе пикселей) |
| **DOM** | Каждый элемент — узел в DOM | Один элемент (холст) |
| **События** | Можно вешать `click`, `hover` на каждую деталь | События только на весь холст |
| **Производительность** | Падает при тысячах объектов | Высокая даже при огромном кол-ве объектов |
| **Масштабирование** | Идеальное без потери качества | Пикселизация при увеличении |

## 4. Работа через JavaScript

### Создание элемента
Важный нюанс: так как SVG — это XML-формат, для его создания через JS нужно указывать пространство имен (Namespace). Обычный `createElement` может работать некорректно.

```javascript
// Правильный способ создания SVG-элемента
const svgNS = "http://www.w3.org/2000/svg";
const circle = document.createElementNS(svgNS, "circle");

circle.setAttributeNS(null, "cx", 50);
circle.setAttributeNS(null, "cy", 50);
circle.setAttributeNS(null, "r", 40);
circle.setAttributeNS(null, "fill", "red");

document.querySelector("svg").appendChild(circle);
```

### Стилизация
Многие свойства SVG (например, `fill`, `stroke`) можно менять через CSS, но они отличаются от стандартных свойств HTML (не `background-color`, а `fill`).

```css
svg circle {
  transition: fill 0.3s;
}

svg circle:hover {
  fill: blue;
}
```

## 5. Базовый пример кода

```html
<svg width="200" height="200" viewBox="0 0 100 100" xmlns="http://www.w3.org/2000/svg">
  <rect x="10" y="10" width="80" height="80" fill="transparent" stroke="black" stroke-width="2" />
  
  <circle cx="50" cy="50" r="30" fill="gold" />
  
  <text x="50" y="55" font-size="10" text-anchor="middle" fill="black">SVG</text>
</svg>
```
