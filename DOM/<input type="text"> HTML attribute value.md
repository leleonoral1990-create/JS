# Элемент `<input type="text">`

Элемент **`<input type="text">`** создает базовое однострочное текстовое поле. Это значение является состоянием по умолчанию для тега `<input>`, если атрибут `type` не указан или не распознан браузером.



---

## 1. Основные атрибуты

Помимо общих атрибутов, специфичных для всех инпутов, текстовое поле поддерживает следующие:

| Атрибут | Описание |
| :--- | :--- |
| **`value`** | Устанавливает начальное значение или возвращает текущее содержимое поля. |
| **`placeholder`** | Краткая подсказка, отображаемая внутри поля, когда оно пустое. |
| **`maxlength`** | Максимальное количество символов, которое пользователь может ввести. |
| **`minlength`** | Минимальное количество символов для прохождения валидации. |
| **`size`** | Визуальная ширина поля в символах (по умолчанию обычно 20). |
| **`pattern`** | Регулярное выражение для проверки введенных данных. |
| **`list`** | ID элемента `<datalist>`, содержащего варианты для автодополнения. |

---

## 2. Валидация данных

Текстовое поле поддерживает встроенную проверку без использования JavaScript.

* **`required`**: Поле обязательно для заполнения перед отправкой формы.
* **`pattern`**: Позволяет задать строгие правила (например, только латинские буквы или определенный формат ID).

```html
<input type="text" pattern="[A-Z]{3}" title="Введите 3 заглавные буквы">
```

---

## 3. События JavaScript

Для работы с текстовым вводом чаще всего используются следующие события:

1.  **`input`**: Срабатывает немедленно при каждом изменении значения (нажатие клавиши, вставка из буфера). Самый популярный вариант для "живого" поиска.
2.  **`change`**: Срабатывает только тогда, когда пользователь завершил ввод и "потерял фокус" с элемента (перешел к другому полю).
3.  **`focus` / `blur`**: Когда пользователь заходит в поле и выходит из него.

---

## 4. Примеры использования

### Базовое текстовое поле
```html
<label for="username">Имя пользователя:</label>
<input type="text" 
       id="username" 
       name="username" 
       placeholder="Введите логин..."
       maxlength="15"
       required>
```

### Использование с Datalist (Автодополнение)
Позволяет предложить пользователю список вариантов, при этом оставляя возможность ввести свой текст.

```html
<label for="city">Выберите город:</label>
<input type="text" id="city" list="cities-list">

<datalist id="cities-list">
  <option value="Алматы">
  <option value="Астана">
  <option value="Шымкент">
</datalist>
```

---

## 5. Доступность (Accessibility)

* **Связь с Label**: Всегда используйте `<label>`, связанный через `id`. Это позволяет пользователям экранных дикторов понимать назначение поля.
* **Скрытые подписи**: Если дизайн не подразумевает видимый текст рядом с полем, используйте атрибут `aria-label`.
* **Placeholder — не замена Label**: Текст внутри поля исчезает при вводе и может быть плохо виден, поэтому он никогда не должен заменять основной заголовок поля.

---

> **Совет по безопасности:** Текстовые поля являются основными векторами для XSS-атак. Всегда очищайте и проверяйте данные, полученные из `input type="text"`, перед тем как отображать их на странице или сохранять в базу данных.
