# Метод window.clearInterval()

Метод **`clearInterval()`** отменяет многократное выполнение кода, которое было ранее установлено с помощью вызова `setInterval()`.



---

## 1. Синтаксис

```javascript
clearInterval(intervalID);
```

**Параметры:**
* **`intervalID`**: Идентификатор интервала, который вы хотите остановить. Этот идентификатор возвращается методом `setInterval()`.

**Возвращаемое значение:**
* **`undefined`**.

---

## 2. Ключевые особенности

1.  **Связь с идентификатором:** Чтобы остановить таймер, вы должны сохранить результат вызова `setInterval` в переменную. Без этого идентификатора остановить выполнение будет невозможно (кроме как закрыв вкладку).
2.  **Безопасный вызов:** Если в метод передать `null`, `undefined` или невалидный идентификатор, код не выдаст ошибку — метод просто ничего не сделает.
3.  **Общий пул таймеров:** В браузерах `setInterval` и `setTimeout` используют общий пул идентификаторов. Технически `clearInterval()` и `clearTimeout()` могут заменять друг друга, но для чистоты и читаемости кода следует всегда использовать соответствующую пару.

---

## 3. Примеры использования в коде

### Сценарий 1: Остановка по условию
Автоматическая остановка счетчика при достижении определенного значения.

```javascript
let count = 0;

const intervalId = setInterval(() => {
  count++;
  console.log(`Проверка №${count}`);

  if (count === 5) {
    clearInterval(intervalId);
    console.log("Достаточно. Интервал остановлен.");
  }
}, 500);
```

### Сценарий 2: Управление через кнопки (Старт/Стоп)
Классическая реализация для пользовательского интерфейса.

```javascript
let timer;

function startTimer() {
  // Проверяем, не запущен ли уже таймер, чтобы не плодить интервалы
  if (!timer) {
    timer = setInterval(() => {
      console.log("Данные обновляются...");
    }, 2000);
  }
}

function stopTimer() {
  clearInterval(timer);
  timer = null; // Сбрасываем переменную
  console.log("Обновление данных прекращено.");
}
```

### Сценарий 3: Сброс "тиков" при клике
Пример, когда интервал нужно очистить, чтобы начать отсчет заново или полностью прекратить его.

```javascript
const bannerInterval = setInterval(showNextSlide, 3000);

// Если пользователь нажал на слайд, мы прекращаем автоматическую прокрутку
document.querySelector('.banner').addEventListener('click', () => {
  clearInterval(bannerInterval);
  console.log("Автоматическая прокрутка отключена пользователем.");
});
```

---

## Резюме
Использование `clearInterval` — это обязательная практика при работе с интервалами. Это предотвращает **утечки памяти** и нежелательное выполнение кода в фоновом режиме, когда в нем больше нет необходимости.
