# Свойство Node.textContent

Свойство **`textContent`** интерфейса `Node` позволяет получать или устанавливать текстовое содержимое узла и всех его потомков. Это один из самых часто используемых способов управления текстом на странице.



---

## 1. Синтаксис

```javascript
// Получение текста
let text = element.textContent;

// Установка текста
element.textContent = "Новое содержимое";
```

### Возвращаемое значение
* **Строка**: содержит объединенный текст всех дочерних текстовых узлов.
* **null**: если узел является документом или типом документа.

---

## 2. Ключевые особенности

### Глубокий захват
`textContent` возвращает текст **всех** дочерних узлов, включая те, что находятся внутри элементов `<script>` и `<style>`. Он просто "высасывает" все строковые значения из дерева.

### Игнорирование CSS
В отличие от `innerText`, свойство `textContent` не обращает внимания на стили. Если элемент скрыт через `display: none` или `visibility: hidden`, его текст всё равно будет включен в результат.

### Безопасность (XSS Protection)
При записи данных через `textContent` браузер интерпретирует строку как **сырой текст**, а не как HTML. Это защищает от XSS-атак, так как любые теги будут отображены как текст, а не исполнены.

```javascript
// Безопасно: выведет на экран теги <b> как текст
el.textContent = "<b>Привет!</b>"; 
```

---

## 3. Сравнение: textContent vs innerText vs innerHTML

| Характеристика | `textContent` | `innerText` | `innerHTML` |
| :--- | :--- | :--- | :--- |
| **Что видит** | Весь текст (вкл. `<script>`) | Только видимый текст | Весь HTML-код |
| **Учитывает CSS** | Нет | Да (триггерит Reflow) | Нет |
| **Безопасность** | **Высокая** | Высокая | Низкая (риск XSS) |
| **Производительность** | **Максимальная** | Ниже (считает стили) | Зависит от объема парсинга |



---

## 4. Примеры использования в коде

### 1. Безопасное обновление данных
Используйте `textContent` всегда, когда работаете с данными от пользователя.

```javascript
const userNameDisplay = document.querySelector('.username');
const userInput = "<img src=x onerror=alert(1)>"; // Попытка взлома

// ✅ ПРАВИЛЬНО: вредоносный код просто отобразится как текст
userNameDisplay.textContent = userInput;
```

### 2. Сбор данных из списка
Быстрый способ получить весь текст из контейнера одной строкой.

```javascript
const list = document.querySelector('#my-list');

// Получим строку со всеми пунктами списка вместе
console.log(list.textContent); 
```

### 3. Очистка элемента
Самый быстрый способ удалить всё содержимое (включая вложенные теги) и заменить его текстом.

```javascript
const container = document.querySelector('.main-content');

// Удаляет все дочерние узлы и ставит одну строку
container.textContent = "Загрузка завершена.";
```

---

## Важные нюансы
* **Производительность**: Если вам нужно часто менять текст в цикле, `textContent` — ваш лучший друг, так как он не заставляет браузер пересчитывать геометрию элементов (в отличие от `innerText`).
* **Пробелы**: `textContent` сохраняет все пробелы и переносы строк так, как они написаны в исходном коде, даже если они не видны на экране из-за особенностей рендеринга HTML.
