# Интерфейс KeyboardEvent

Интерфейс **`KeyboardEvent`** описывает взаимодействие пользователя с клавиатурой. Каждое событие содержит информацию о нажатой клавише, её физическом расположении и состоянии клавиш-модификаторов.



---

## 1. Типы событий

| Событие | Описание |
| :--- | :--- |
| **`keydown`** | Происходит в момент нажатия клавиши. Генерируется повторно при зажатии (auto-repeat). |
| **`keyup`** | Происходит в момент отпускания клавиши. |
| ~~`keypress`~~ | *Устарело.* Генерировалось при вводе символьного значения. Не использовать. |

---

## 2. Ключевые свойства

### Идентификация клавиши
* **`key`**: Значение нажатой клавиши (например, `"a"`, `"Enter"`, `"ArrowUp"`). Зависит от раскладки и регистра.
* **`code`**: Физический код клавиши (например, `"KeyA"`, `"Digit1"`, `"ShiftLeft"`). **Не зависит** от раскладки.
* **`location`**: Расположение клавиши (стандартная область, левая/правая сторона, цифровая панель).

### Клавиши-модификаторы (Boolean)
* **`altKey`**: Нажата ли клавиша Alt (или Option на Mac).
* **`ctrlKey`**: Нажата ли клавиша Control.
* **`metaKey`**: Нажата ли клавиша Meta (Command на Mac, Windows на ПК).
* **`shiftKey`**: Нажата ли клавиша Shift.

### Состояние
* **`repeat`**: Возвращает `true`, если клавиша удерживается нажатой (автоповтор).
* **`isComposing`**: `true`, если событие происходит в рамках сессии ввода символов (например, через IME для иероглифов).

---

## 3. Разница между key и code

Это критическое различие для интернационализации приложений.

| Клавиша | Раскладка | `event.key` | `event.code` |
| :--- | :--- | :--- | :--- |
| Физическая кнопка "Q" | EN (English) | `"q"` | `"KeyQ"` |
| Физическая кнопка "Q" | RU (Russian) | `"й"` | `"KeyQ"` |
| Физическая кнопка "1" | Любая | `"1"` | `"Digit1"` |
| Shift + 1 | EN (English) | `"#"` | `"Digit1"` |



---

## 4. Методы

* **`getModifierState(keyArg)`**: Позволяет проверить состояние конкретной клавиши (например, `"CapsLock"`, `"NumLock"`, `"ScrollLock"`). Возвращает `true`, если режим активен.

---

## 5. Практический пример

```javascript
document.addEventListener('keydown', (event) => {
  // 1. Идентификация клавиши
  const { key, code, repeat } = event;
  
  // 2. Игнорируем автоповтор
  if (repeat) return;

  // 3. Комбинация клавиш (например, сохранение)
  if ((event.ctrlKey || event.metaKey) && code === 'KeyS') {
    event.preventDefault(); // Отменяем системное сохранение
    console.log('Ручное сохранение вызвано');
  }

  // 4. Логика навигации
  if (key === 'Escape') {
    console.log('Закрыть модальное окно');
  }
  
  console.log(`Нажата клавиша: ${key}, Код: ${code}`);
});
```

---

## Важные нюансы

1.  **Всплытие (Bubbling)**: События клавиатуры всплывают от элемента с фокусом до `document` и `window`.
2.  **Фокус**: Элемент должен иметь фокус, чтобы генерировать события. Для неинтерактивных элементов (например, `div`) нужно добавить атрибут `tabindex`.
3.  **Отмена**: Вызов `preventDefault()` в событии `keydown` предотвращает ввод символа в текстовые поля и выполнение действий по умолчанию (например, прокрутку страницы стрелками).
