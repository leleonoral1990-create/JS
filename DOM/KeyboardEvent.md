# Свойство KeyboardEvent.key

Свойство **`key`** интерфейса `KeyboardEvent` возвращает значение клавиши, нажатой пользователем. Оно учитывает состояние клавиш-модификаторов (Shift, Caps Lock), а также текущую раскладку клавиатуры и локаль.



---

## 1. Синтаксис

```javascript
const string = event.key;
```

**Возвращаемое значение:**
* **Строка**: содержит символ, генерируемый нажатием (например, `"a"`, `"$"`, `"ё"`).
* Если нажата управляющая клавиша, возвращается специальное именованное значение (например, `"Enter"`, `"Tab"`, `"ArrowUp"`).
* Если клавиша не имеет печатного представления и не опознана, возвращается `"Unidentified"`.

---

## 2. Категории значений

| Тип клавиши | Примеры значений `key` |
| :--- | :--- |
| **Алфавитно-цифровые** | `"a"`, `"A"`, `"1"`, `" "` (пробел) |
| **Управляющие** | `"Shift"`, `"Control"`, `"Alt"`, `"Meta"` |
| **Навигация** | `"ArrowUp"`, `"PageDown"`, `"Home"`, `"End"` |
| **Редактирование** | `"Backspace"`, `"Delete"`, `"Enter"`, `"Tab"` |
| **Функциональные** | `"F1"`, `"F12"`, `"Escape"`, `"CapsLock"` |

---

## 3. Ключевые особенности

### Зависимость от регистра и раскладки
В отличие от свойства `code`, значение `key` меняется в зависимости от того, на каком языке печатает пользователь и нажат ли Shift.
* Нажатие физической клавиши "Q":
    * Английская раскладка: `"q"`
    * Английская + Shift: `"Q"`
    * Русская раскладка: `"й"`

### Многосимвольные значения
Некоторые клавиши возвращают целые слова, описывающие их функцию. Важно помнить, что эти значения **чувствительны к регистру** (всегда начинаются с заглавной буквы, если это не печатный символ).
* Правильно: `if (event.key === "Enter")`
* Неправильно: `if (event.key === "enter")`

### Обработка "мертвых" клавиш (Dead Keys)
Если клавиша используется для создания символа с диакритическим знаком (например, для ввода `á`), свойство `key` может вернуть значение `"Dead"`.

---

## 4. Сравнение: key vs code

| Ситуация | `event.key` | `event.code` |
| :--- | :--- | :--- |
| **Цель** | Получить символ или действие | Получить физическую кнопку |
| **Раскладка** | Влияет | **Не влияет** |
| **Shift / Caps** | Влияет | **Не влияет** |
| **Пример (клавиша Z)** | `"z"`, `"Z"`, `"я"`, `"Я"` | Всегда `"KeyZ"` |



---

## 5. Примеры использования в коде

### Обработка навигации
```javascript
window.addEventListener("keydown", (event) => {
  switch (event.key) {
    case "ArrowUp":
      console.log("Движение вверх");
      break;
    case "ArrowDown":
      console.log("Движение вниз");
      break;
    case "Escape":
      closeModal();
      break;
  }
});
```

### Проверка ввода цифр
```javascript
input.addEventListener("keydown", (event) => {
  // Разрешаем только цифры
  const isNumber = /^[0-9]$/.test(event.key);
  
  // Разрешаем также управляющие клавиши (Backspace, Tab и т.д.)
  const isControlKey = event.key.length > 1;

  if (!isNumber && !isControlKey) {
    event.preventDefault();
  }
});
```

### Отслеживание модификаторов
```javascript
document.addEventListener("keydown", (event) => {
  if (event.key === "s" && (event.ctrlKey || event.metaKey)) {
    event.preventDefault();
    console.log("Сохранение...");
  }
});
```

---

### Резюме
Используйте `event.key`, когда ваша задача — понять, **что именно** ввел пользователь или какую логическую команду он отправил (например, "отмена" через Esc или "подтверждение" через Enter). Если же вы строите управление для игры, где важны позиции кнопок (WASD), используйте `event.code`.
