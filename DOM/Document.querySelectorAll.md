# Метод document.querySelectorAll()

Метод `querySelectorAll()` — это самый гибкий и мощный инструмент для поиска элементов в DOM. Он позволяет находить все элементы, которые соответствуют заданному CSS-селектору (или группе селекторов).



---

## 1. Синтаксис

```javascript
const nodeList = document.querySelectorAll(selectors);
const nodeList = element.querySelectorAll(selectors);
```

**Параметры:**
* **`selectors`**: Строка, содержащая один или несколько валидных CSS-селекторов, разделенных запятыми.

**Возвращаемое значение:**
* **Статичный `NodeList`**: Список всех найденных элементов. Если ничего не найдено, возвращается пустой `NodeList` (длина 0).

---

## 2. Ключевые особенности

### Статичный NodeList (Static Collection)
В отличие от методов `getElementsBy...`, которые возвращают "живые" коллекции, `querySelectorAll` возвращает **статичный** список. Это значит, что если после вызова метода в DOM добавятся новые элементы, подходящие под селектор, ваш `nodeList` **не изменится**.

### Любой CSS-селектор
Вы не ограничены только ID или классами. Вы можете использовать всю мощь CSS:
* Селекторы атрибутов: `[type="text"]`
* Псевдоклассы: `li:nth-child(even)`
* Комбинаторы: `.container > div.active`
* Группы: `h1, h2, .main-title`

### Контекст поиска
Метод можно вызвать не только на `document`, но и на любом **`element`**. В этом случае поиск будет ограничен только потомками этого элемента.

---

## 3. NodeList vs HTMLCollection

Хотя `NodeList` похож на массив, у него есть свои нюансы.

| Характеристика | `NodeList` (из querySelectorAll) | `HTMLCollection` |
| :--- | :--- | :--- |
| **Состояние** | **Статичное** | Живое (Live) |
| **Метод .forEach()** | Есть (в большинстве браузеров) | Нет |
| **Как получить массив** | `[...list]` или `Array.from(list)` | `[...coll]` или `Array.from(coll)` |



---

## 4. Примеры использования в коде

### 1. Выбор по сложному селектору
```javascript
// Находим все отмеченные чекбоксы внутри формы с id "survey"
const checkedInputs = document.querySelectorAll('#survey input[type="checkbox"]:checked');

checkedInputs.forEach(input => {
    console.log(`Выбранное значение: ${input.value}`);
});
```

### 2. Манипуляция группой элементов
```javascript
const cards = document.querySelectorAll('.product-card');

// NodeList позволяет использовать forEach напрямую!
cards.forEach((card, index) => {
    card.style.transitionDelay = `${index * 100}ms`;
    card.classList.add('fade-in');
});
```

### 3. Групповой селектор
```javascript
// Найти все заголовки и подзаголовки одним махом
const headings = document.querySelectorAll('h1, h2, h3');
console.log(`Всего заголовков на странице: ${headings.length}`);
```

---

## Важные нюансы

1. **Производительность**: `querySelectorAll` работает немного медленнее, чем специализированные методы типа `getElementById`, потому что браузеру нужно распарсить CSS-селектор. В 99% случаев эта разница незаметна, но в циклах на тысячи итераций это стоит учитывать.
2. **Пустой результат**: Если элементов нет, метод вернет `NodeList` с длиной `0`, а не `null`. Это удобно, так как `.forEach()` просто не выполнится и не выдаст ошибку.
3. **Псевдоэлементы**: Метод не может находить псевдоэлементы (например, `::before` или `::after`), так как они не являются частью дерева DOM.
