# Элемент `<form>` (HTML)

Элемент **`<form>`** представляет собой раздел документа, содержащий интерактивные элементы управления, которые позволяют пользователю отправлять информацию на веб-сервер.



---

## 1. Ключевые атрибуты

| Атрибут | Описание |
| :--- | :--- |
| **`action`** | URL-адрес, на который будут отправлены данные формы. Если не указан, данные отправляются на текущую страницу. |
| **`method`** | HTTP-метод для отправки данных: **`GET`** (в строке URL) или **`POST`** (в теле запроса). |
| **`enctype`** | Тип кодирования данных. Для загрузки файлов используется `multipart/form-data`. |
| **`target`** | Где отобразить ответ после отправки (например, `_blank` для новой вкладки). |
| **`autocomplete`** | Разрешает или запрещает браузеру автоматически заполнять поля формы (`on` / `off`). |
| **`novalidate`** | Логический атрибут, который отключает встроенную валидацию браузера при отправке. |

---

## 2. Методы отправки: GET vs POST

Выбор метода зависит от типа передаваемых данных и требований безопасности.

| Метод | Описание | Использование |
| :--- | :--- | :--- |
| **`GET`** | Данные добавляются к URL в виде параметров. Видны пользователю. Имеют ограничение по длине. | Поиск, фильтрация, навигация. |
| **`POST`** | Данные передаются внутри тела запроса. Не видны в URL. Позволяют передавать большие объемы (файлы). | Регистрация, логин, отправка сообщений. |

---

## 3. Основные дочерние элементы

Форма — это лишь контейнер. Для сбора данных используются вложенные теги:

* **`<label>`**: Описание поля (критически важно для доступности).
* **`<input>`**: Универсальное поле ввода (текст, пароль, чекбокс, дата).
* **`<textarea>`**: Поле для многострочного текста.
* **`<select>`** и **`<option>`**: Выпадающие списки.
* **`<button>`**: Кнопка для отправки (`type="submit"`) или сброса (`type="reset"`) формы.
* **`<fieldset>`** и **`<legend>`**: Группировка связанных полей с заголовком.

---

## 4. Пример структуры формы

```html
<form action="/submit-data" method="POST">
  <fieldset>
    <legend>Контактная информация</legend>
    
    <div>
      <label for="name">Имя:</label>
      <input type="text" id="name" name="user_name" required>
    </div>

    <div>
      <label for="email">Email:</label>
      <input type="email" id="email" name="user_email" placeholder="example@mail.com">
    </div>

    <div>
      <label for="role">Роль:</label>
      <select id="role" name="user_role">
        <option value="admin">Администратор</option>
        <option value="editor">Редактор</option>
        <option value="viewer" selected>Зритель</option>
      </select>
    </div>

    <button type="submit">Отправить данные</button>
  </fieldset>
</form>
```

---

## 5. Валидация данных

Браузеры поддерживают автоматическую проверку данных перед отправкой с помощью специальных атрибутов:
* **`required`**: Поле не может быть пустым.
* **`minlength` / `maxlength`**: Ограничение количества символов.
* **`min` / `max`**: Диапазон для чисел и дат.
* **`pattern`**: Регулярное выражение для проверки (например, формат телефона).

## Работа через JavaScript

В JS форма представлена объектом `HTMLFormElement`.
* **Событие `submit`**: Срабатывает при попытке отправки. Это лучшее место для ручной валидации или отмены стандартной отправки через `event.preventDefault()`.
* **Объект `FormData`**: Позволяет легко собрать все данные формы в один объект для отправки через `fetch` или `XMLHttpRequest`.

```javascript
const form = document.querySelector('form');

form.addEventListener('submit', (event) => {
  event.preventDefault(); // Останавливаем переход на другую страницу
  
  const data = new FormData(form);
  console.log('Имя из формы:', data.get('user_name'));
});
```

## Резюме
Элемент `<form>` — это основа взаимодействия пользователя с сервером. При его создании всегда связывайте `input` и `label` через атрибуты `id` и `for`, используйте подходящие типы `input` (email, tel, number) и не забывайте про метод `POST` для передачи чувствительных данных.
