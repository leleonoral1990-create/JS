# Элемент `<style>` (HTML)

Элемент **`<style>`** предназначен для внедрения каскадных таблиц стилей (CSS) непосредственно внутрь HTML-документа. Стили, описанные внутри этого тега, применяются только к текущему документу.



---

## 1. Основные характеристики

* **Категория**: Метаданные (Metadata content).
* **Место размещения**: Обычно внутри `<head>`, но технически разрешен и в `<body>` (хотя это может вызвать перерисовку страницы).
* **Содержимое**: Только чистый CSS-код. HTML-теги внутри `<style>` не допускаются.

---

## 2. Атрибуты

| Атрибут | Описание |
| :--- | :--- |
| **`media`** | Определяет, для каких типов устройств/экранов предназначены стили (например, `print` или `(max-width: 600px)`). |
| **`nonce`** | Криптографическое число (одноразовый код) для проверки безопасности через Content Security Policy (CSP). |
| **`title`** | Определяет альтернативные наборы стилей. |
| **`blocking`** | (Экспериментально) Указывает, что элемент должен блокировать отрисовку до загрузки. |

> **Примечание:** Атрибут `type="text/css"` в современном HTML5 указывать необязательно, так как это значение по умолчанию.

---

## 3. Сравнение: `<style>` vs `<link>`

| Характеристика | `<style>` (Внутренние стили) | `<link>` (Внешние стили) |
| :--- | :--- | :--- |
| **Использование** | Для уникальных стилей одной страницы. | Для общих стилей всего сайта. |
| **Производительность** | Быстрее для первого рендеринга (нет лишнего HTTP-запроса). | Лучше для кэширования браузером. |
| **Удобство** | Сложно поддерживать в больших проектах. | Стандарт для профессиональной разработки. |

---

## 4. Работа через JavaScript

Каждый тег `<style>` представлен в DOM объектом **`HTMLStyleElement`**.

* **`sheet`**: Свойство, предоставляющее доступ к объекту `CSSStyleSheet`. Позволяет динамически добавлять или удалять правила CSS через `insertRule()` и `deleteRule()`.
* **`disabled`**: Позволяет программно включать или выключать весь блок стилей.

---

## 5. Примеры использования

### Базовое внедрение стилей
```html
<head>
  <style>
    body {
      background-color: #f0f0f0;
      font-family: sans-serif;
    }
    
    .content-block {
      padding: 20px;
      border: 1px solid #ccc;
    }
  </style>
</head>
```

### Использование атрибута media
```html
<style media="print">
  nav, .ads, .sidebar {
    display: none;
  }
  body {
    font-size: 12pt;
  }
</style>
```

### Динамическое создание через JS
```javascript
const customStyle = document.createElement('style');
customStyle.textContent = `
  .js-added-element {
    color: green;
    font-weight: bold;
  }
`;
document.head.append(customStyle);
```

## Безопасность и SEO
* **CSP**: Если на сайте настроена строгая политика безопасности, инлайновые стили могут быть заблокированы, если не указан атрибут `nonce`.
* **Критический CSS**: Техника вставки критически важных стилей в `<style>` внутри `<head>` используется для ускорения показа первого экрана (LCP) пользователю.
