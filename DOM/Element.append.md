# Метод Element.append()

Метод `append()` вставляет набор объектов `Node` или строк (`DOMString`) в конец списка дочерних элементов родителя. Это более современный и гибкий аналог старого метода `appendChild()`.



---

## 1. Синтаксис

```javascript
element.append(...nodesOrDOMStrings);
```

**Параметры:**
* **`nodesOrDOMStrings`**: Список объектов `Node` (элементы, текстовые узлы) или простых строк. Можно передать неограниченное количество аргументов через запятую.

**Возвращаемое значение:**
* **`undefined`**.

---

## 2. Ключевые особенности

1.  **Поддержка строк:** Если в метод передается строка, браузер автоматически преобразует её в текстовый узел (`Text node`). Вам не нужно вручную вызывать `document.createTextNode()`.
2.  **Множественная вставка:** Вы можете добавить несколько элементов и кусков текста за один вызов.
3.  **Отсутствие возвращаемого значения:** Метод ничего не возвращает, в отличие от `appendChild()`, который возвращает добавленный узел.
4.  **Порядок вставки:** Аргументы добавляются в том порядке, в котором они перечислены (слева направо), становясь последними дочерними элементами.

---

## 3. Сравнение: append() vs appendChild()

| Характеристика | `append()` | `appendChild()` |
| :--- | :--- | :--- |
| **Принимает строки** | **Да** (как текст) | Нет (только Node) |
| **Несколько аргументов** | **Да** | Нет (только один) |
| **Возвращает результат** | Нет (`undefined`) | Да (добавленный узел) |
| **Поддержка** | Современные браузеры (IE не подд.) | Все браузеры (Legacy) |

---

## 4. Примеры использования в коде

### 1. Вставка текста и элементов одновременно
```javascript
const div = document.createElement('div');
const p = document.createElement('p');
p.textContent = 'Это параграф.';

// Вставляем всё разом
div.append('Начало текста ', p, ' Конец текста.');

/* Результат в DOM:
<div>
  Начало текста 
  <p>Это параграф.</p>
  Конец текста.
</div>
*/
```

### 2. Создание списка из массива данных
```javascript
const list = document.createElement('ul');
const items = ['Protoss', 'Zerg', 'Terran'];

// Создаем массив элементов и разворачиваем его в аргументы append
const liElements = items.map(text => {
  const li = document.createElement('li');
  li.textContent = text;
  return li;
});

list.append(...liElements);
document.body.append(list);
```

### 3. Автоматическое перемещение
Если элемент уже существует в DOM, `append()` переместит его со старого места на новое (в конец указанного родителя).

```javascript
const boxA = document.querySelector('#box-a');
const boxB = document.querySelector('#box-b');
const item = document.querySelector('.item');

// Перемещаем .item из boxA в конец boxB
boxB.append(item);
```

---

## Нюанс с производительностью
Хотя `append()` удобен, частая вставка элементов в цикле напрямую в DOM заставляет браузер постоянно пересчитывать стили и перерисовывать страницу. Если нужно добавить сотни элементов, лучше сначала собрать их в **`DocumentFragment`** или один общий `div` в памяти, а затем вызвать `append()` один раз.
