# Глобальные атрибуты data-* (Custom Data Attributes)

Атрибуты **`data-*`** позволяют хранить дополнительную семантическую информацию в стандартных HTML-элементах, для которой не существует подходящих специализированных атрибутов или элементов.

---

## 1. Назначение и Правила

Главная цель — обмен данными между HTML и скриптами (JavaScript) или стилями (CSS). 

**Основные правила именования:**
1.  Имя должно начинаться с префикса **`data-`**.
2.  После префикса должен идти минимум один символ.
3.  Имя не должно содержать заглавных букв в HTML (в коде они преобразуются в нижний регистр).
4.  В именах нельзя использовать символы, отличные от букв латиницы, цифр, дефисов (`-`), точек (`.`), двоеточий (`:`) и подчеркиваний (`_`).



---

## 2. Использование в CSS

Вы можете стилизовать элементы на основе их данных, используя селекторы атрибутов.

```css
/* Стилизация всех элементов с атрибутом data-status */
[data-status] {
  border: 1px solid gray;
}

/* Стилизация конкретного значения */
[data-status="active"] {
  background-color: green;
  color: white;
}

/* Использование контента из атрибута в свойстве content */
.user::after {
  content: " (ID: " attr(data-id) ")";
}
```

---

## 3. Доступ через JavaScript

Для работы с этими атрибутами в JS предусмотрено специальное свойство **`dataset`**.

| Действие | Синтаксис |
| :--- | :--- |
| **Чтение** | `element.dataset.nameOfAttribute` |
| **Запись** | `element.dataset.nameOfAttribute = 'value'` |
| **Удаление** | `delete element.dataset.nameOfAttribute` |

> **Важно:** При обращении через `dataset` имя атрибута преобразуется из **kebab-case** (`data-user-id`) в **camelCase** (`userId`).

---

## 4. Сравнение подходов

| Характеристика | data-атрибуты | Классы (class) |
| :--- | :--- | :--- |
| **Цель** | Хранение данных / состояния | Стилизация |
| **Чтение в JS** | Очень удобно (`dataset`) | Требует парсинга или `contains` |
| **Семантика** | Хранит значения (id, цены, роли) | Описывает внешний вид или роль |

---

## 5. Примеры использования в коде

### Сценарий 1: Управление состоянием UI
```html
<div id="product" 
     data-id="101" 
     data-category="electronics" 
     data-stock="low">
  Смартфон
</div>

<script>
  const el = document.getElementById('product');
  
  // Проверяем остаток товара
  if (el.dataset.stock === 'low') {
    el.style.color = 'red';
  }
</script>
```

### Сценарий 2: Передача конфигурации скрипту
```html
<button class="track-click" 
        data-event-name="purchase" 
        data-amount="5000" 
        data-currency="KZT">
  Купить
</button>

<script>
  document.querySelector('.track-click').addEventListener('click', (e) => {
    const { eventName, amount, currency } = e.target.dataset;
    console.log(`Отправка события: ${eventName}, Сумма: ${amount} ${currency}`);
  });
</script>
```

---

## Резюме и Безопасность

* **Не храните чувствительные данные:** Помните, что `data-*` атрибуты видны любому пользователю через "Просмотр кода страницы". Не используйте их для паролей или личных данных.
* **Производительность:** Чтение из `dataset` работает немного медленнее, чем хранение данных в обычных переменных JavaScript, но это компенсируется удобством связи HTML и JS.
* **Поисковики:** Поисковые роботы обычно не индексируют содержимое `data-` атрибутов. Если информация важна для SEO, она должна быть в тексте элемента.
