# Свойство window.innerHeight

Свойство **`window.innerHeight`** возвращает высоту (в пикселях) области просмотра (вьюпорта) браузера. Проще говоря, это высота той части страницы, которую вы видите прямо сейчас, включая горизонтальную полосу прокрутки (если она есть).



---

## 1. Синтаксис

```javascript
let viewportHeight = window.innerHeight;
```

**Возвращаемое значение:**
* **Число (`integer`)**: Высота в пикселях.
* Это свойство **только для чтения**. Чтобы изменить высоту окна, нужно использовать методы вроде `window.resizeTo()`.

---

## 2. Сравнение высот: innerHeight vs outerHeight vs clientHeight

Различия между этими свойствами часто сбивают с толку, но они важны для точной верстки:

| Свойство | Что измеряет | Включает ли тулбары/рамки? |
| :--- | :--- | :--- |
| **`window.innerHeight`** | Внутренняя высота вьюпорта. | **Нет** (только контентная область). |
| **`window.outerHeight`** | Высота всего окна браузера. | **Да** (закладки, адресная строка, рамки ОС). |
| **`document.documentElement.clientHeight`** | Высота HTML-документа. | **Нет** (и не включает полосу прокрутки). |

---

## 3. Практическое применение

### 1. Создание секции "на весь экран"
Если вы хотите, чтобы ваш "Hero-блок" или лендинг занимал ровно 100% высоты экрана при загрузке.

```javascript
const heroSection = document.querySelector('.hero');

function setHeroHeight() {
    heroSection.style.height = `${window.innerHeight}px`;
}

// Устанавливаем при загрузке и обновляем при изменении размера окна
window.addEventListener('load', setHeroHeight);
window.addEventListener('resize', setHeroHeight);
```

### 2. Расчет точки "перелома" для ленивой загрузки
Чтобы понять, доскроллил ли пользователь до элемента, нам нужно знать высоту видимой области.

```javascript
const element = document.querySelector('.target');
const rect = element.getBoundingClientRect();

// Если верх элемента выше, чем нижняя граница экрана
if (rect.top < window.innerHeight) {
    console.log('Элемент появился в поле зрения!');
}
```

---

## 4. Особенности на мобильных устройствах

На мобильных браузерах (Safari на iOS, Chrome на Android) `window.innerHeight` может вести себя «капризно». 
* При скролле вниз адресная строка часто скрывается, и значение `innerHeight` **увеличивается**.
* Это вызывает «прыжки» в дизайне, если вы используете `100vh` в CSS.

> **Совет:** В современном CSS для решения этой проблемы лучше использовать единицы **`dvh`** (dynamic viewport height) или **`svh`** (small viewport height), которые учитывают динамику интерфейса браузера без использования JavaScript.

---

## Резюме
Используйте `window.innerHeight`, когда вам нужно динамически подстраивать элементы под высоту экрана пользователя или рассчитывать логику появления контента при скролле. Однако помните, что на мобильных устройствах это значение может меняться в процессе взаимодействия со страницей.
