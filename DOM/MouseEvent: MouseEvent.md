# Конструктор MouseEvent()

Конструктор **`MouseEvent()`** создает новый объект события мыши. Этот метод позволяет программно имитировать действия пользователя, такие как клики, перемещения курсора или нажатия кнопок мыши.



---

## 1. Синтаксис

```javascript
const event = new MouseEvent(type, options);
```

**Параметры:**
* **`type`**: Строка с названием события (например, `'click'`, `'mousedown'`, `'mouseover'`).
* **`options`** (необязательно): Объект, содержащий настройки события. Кроме свойств базовых интерфейсов `Event` и `UIEvent`, он включает специфические свойства мыши.

---

## 2. Параметры options (MouseEventInit)

Большинство свойств по умолчанию равны `0`, `false` или `null`.

| Свойство | Тип | Описание |
| :--- | :--- | :--- |
| **`screenX` / `screenY`** | Number | Координаты относительно экрана. |
| **`clientX` / `clientY`** | Number | Координаты относительно вьюпорта (окна браузера). |
| **`button`** | Number | Какая кнопка нажата: `0` (левая), `1` (средняя), `2` (правая). |
| **`buttons`** | Number | Битовая маска нажатых кнопок (1 - левая, 2 - правая, 4 - колесо). |
| **`ctrlKey` / `altKey`** | Boolean | Была ли зажата соответствующая клавиша-модификатор. |
| **`shiftKey` / `metaKey`** | Boolean | Была ли зажата Shift или Meta (Cmd/Win). |
| **`relatedTarget`** | Element | Дополнительный элемент (например, откуда ушел курсор при `mouseenter`). |



---

## 3. Ключевые особенности

1.  **Программная имитация**: События, созданные через конструктор, имеют флаг `isTrusted: false`. Это позволяет скриптам отличать реальные действия пользователя от действий кода.
2.  **Диспетчеризация**: После создания события его необходимо запустить на элементе с помощью метода `element.dispatchEvent(event)`.
3.  **Всплытие по умолчанию**: В отличие от некоторых других событий, созданных вручную, вы можете явно указать `bubbles: true` в настройках, чтобы событие поднималось вверх по DOM-дереву.

---

## 4. Сравнение свойств: button vs buttons

| Свойство | Значение | Когда использовать |
| :--- | :--- | :--- |
| **`button`** | Одиночное число (0-4) | Для определения, какая кнопка вызвала изменение состояния. |
| **`buttons`** | Битовое поле (сумма весов) | Чтобы понять, какие кнопки зажаты в текущий момент (например, при перемещении). |

---

## 5. Примеры использования в коде

### 1. Создание и запуск простого клика
```javascript
const btn = document.querySelector('#myButton');

// 1. Создаем событие
const myClick = new MouseEvent('click', {
  bubbles: true,
  cancelable: true,
  view: window
});

// 2. Запускаем на элементе
btn.dispatchEvent(myClick);
```

### 2. Имитация клика с зажатой клавишей Ctrl и координатами
```javascript
const element = document.elementFromPoint(150, 150);

const complexClick = new MouseEvent('mousedown', {
  clientX: 150,
  clientY: 150,
  ctrlKey: true,
  button: 0, // Левая кнопка
  bubbles: true
});

element.dispatchEvent(complexClick);
```

### 3. Использование relatedTarget (наведение)
```javascript
const box = document.querySelector('.box');
const prevElement = document.querySelector('.sidebar');

const enterEvent = new MouseEvent('mouseover', {
  relatedTarget: prevElement, // Указываем, с какого элемента пришел курсор
  bubbles: true
});

box.dispatchEvent(enterEvent);
```

---

## Резюме
Используйте `new MouseEvent()`, когда вам нужно программно вызвать логику, привязанную к действиям мыши, без участия пользователя. Это часто применяется в автоматизированном тестировании или при создании сложных UI-компонентов (например, drag-and-drop или виртуальных клавиатур).
