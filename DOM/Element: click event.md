# Событие click

Событие **`click`** происходит, когда пользователь нажимает и отпускает кнопку указывающего устройства (обычно левую кнопку мыши) на элементе. Это одно из самых часто используемых событий в веб-разработке.



---

## 1. Справочная информация

| Характеристика | Значение |
| :--- | :--- |
| **Всплывает** | Да |
| **Отменяемое** | Да |
| **Интерфейс** | `MouseEvent` (или `PointerEvent`) |
| **Цель (Target)** | Элемент, на котором произошло нажатие |

---

## 2. Порядок срабатывания

Событие `click` является «составным». Чтобы оно сработало, должны последовательно произойти следующие события на одном и том же элементе:
1.  **`mousedown`** (кнопка нажата).
2.  **`mouseup`** (кнопка отпущена).
3.  **`click`** (финальный результат).

Если пользователь нажмет кнопку на одном элементе, а переместит курсор и отпустит её на другом, событие `click` не сработает (или сработает на их общем родителе).

---

## 3. Доступность (Accessibility)

Важное преимущество `click` перед другими событиями мыши — его **универсальность**.
* Если элемент (например, `<button>` или `<a>`) находится в фокусе, нажатие клавиш **Enter** или **Space** (Пробел) также вызовет событие `click`.
* Это делает его предпочтительным для создания интерфейсов, доступных для пользователей с клавиатурой или экранными дикторами.



---

## 4. Сравнение с похожими событиями

| Событие | Когда срабатывает |
| :--- | :--- |
| **`click`** | Основная кнопка (обычно левая) или клавиатура. |
| **`dblclick`** | Двойной клик за короткий промежуток времени. |
| **`auxclick`** | Неосновные кнопки (колесо мыши, правая кнопка). |
| **`contextmenu`** | Обычно при клике правой кнопкой (вызов меню). |

---

## 5. Примеры использования

### 1. Простой обработчик
```javascript
const btn = document.querySelector('.submit-btn');

btn.addEventListener('click', (event) => {
  console.log('Кнопка нажата!');
  console.log(`Координаты клика: ${event.clientX}, ${event.clientY}`);
});
```

### 2. Делегирование событий
Вместо того чтобы вешать обработчик на каждую кнопку, мы вешаем один на родителя. Это эффективнее для памяти.

```javascript
const list = document.querySelector('.actions-list');

list.addEventListener('click', (event) => {
  // Проверяем, что кликнули именно по кнопке
  const target = event.target.closest('button');
  
  if (target) {
    console.log(`Выполнено действие: ${target.dataset.action}`);
  }
});
```

### 3. Отмена стандартного действия
Например, предотвращение перехода по ссылке или отправки формы.

```javascript
const link = document.querySelector('#secret-link');

link.addEventListener('click', (event) => {
  event.preventDefault(); // Ссылка не откроется
  console.log('Переход заблокирован скриптом.');
});
```

## Важные нюансы
* **Сенсорные экраны**: На мобильных устройствах `click` срабатывает с небольшой задержкой (около 300 мс), так как браузер ждет, не будет ли это двойным тапом для зума. В современных мета-тегах `viewport` эта задержка обычно минимизирована.
* **Правая кнопка**: В большинстве браузеров `click` не срабатывает при нажатии правой кнопкой мыши. Для этого используйте `auxclick` или `contextmenu`.
* **isTrusted**: Свойство `event.isTrusted` будет `true`, если клик совершил человек, и `false`, если событие было вызвано программно (через `.click()` или `dispatchEvent`).
