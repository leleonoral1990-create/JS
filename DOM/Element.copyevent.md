# Событие copy

Событие **`copy`** срабатывает, когда пользователь инициирует операцию копирования через интерфейс браузера (например, сочетанием клавиш **Ctrl+C** / **Cmd+C** или через контекстное меню).



---

## 1. Справочная информация

| Характеристика | Значение |
| :--- | :--- |
| **Всплывает** | Да |
| **Отменяемое** | Да |
| **Интерфейс** | `ClipboardEvent` |
| **Цель (Target)** | Элемент с выделением (или `<body>`, если ничего не выбрано) |

---

## 2. Свойство clipboardData

Самая важная часть события — объект **`clipboardData`** (типа `DataTransfer`). Он позволяет:
* **Читать** данные, которые попадают в буфер (хотя в событии `copy` данные обычно туда только записываются).
* **Записывать** свои данные в буфер обмена с помощью метода `setData()`.

```javascript
event.clipboardData.setData('text/plain', 'Ваш текст');
```

---

## 3. Основные сценарии использования

### 1. Изменение копируемого текста
Часто используется для добавления ссылки на источник или "водяного знака" к скопированному тексту.

```javascript
document.addEventListener('copy', (event) => {
  const selection = document.getSelection();
  const extraText = "\n\nИсточник: mysite.com";
  
  // Записываем в буфер измененную строку
  event.clipboardData.setData('text/plain', selection.toString() + extraText);
  
  // Отменяем стандартное поведение, чтобы применились наши данные
  event.preventDefault();
});
```

### 2. Запрет копирования
Если нужно защитить контент от простого копирования (хотя это не является абсолютной защитой).

```javascript
const sensitiveData = document.querySelector('.no-copy');

sensitiveData.addEventListener('copy', (event) => {
  event.preventDefault();
  alert('Копирование этого текста ограничено.');
});
```

### 3. Копирование сложных данных (HTML/JSON)
Вы можете поместить в буфер сразу несколько форматов данных. Браузер выберет подходящий при вставке.

```javascript
document.addEventListener('copy', (e) => {
  const html = "<b>Жирный текст</b>";
  const plain = "Жирный текст";
  
  e.clipboardData.setData('text/html', html);
  e.clipboardData.setData('text/plain', plain);
  
  e.preventDefault();
});
```

---

## 4. Ограничения и Безопасность

* **Доступ к буферу**: Вы можете изменять содержимое буфера обмена только внутри обработчика событий, инициированных пользователем (`copy`, `cut`). Произвольная запись в буфер "в любое время" может быть заблокирована политикой безопасности браузера.
* **Конфиденциальность**: Современные браузеры могут ограничивать чтение данных из `clipboardData` во время события `copy` (обычно данные доступны только для записи). Полный доступ на чтение предоставляется в событии `paste`.
* **События на скрытых элементах**: Если фокус находится на элементе, который не допускает выделения (например, картинка без текста), событие все равно может всплыть до `document`.

---

## Резюме
Событие `copy` — это ваш "контрольно-пропускной пункт" между контентом страницы и буфером обмена пользователя. Используйте его для улучшения UX (например, форматирования скопированного кода) или для аналитики того, какой контент на сайте наиболее популярен для распространения.
