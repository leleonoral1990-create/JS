# Событие mousemove

Событие **`mousemove`** происходит в тот момент, когда пользователь перемещает указатель мыши, находясь в пределах границ элемента. Это событие генерируется непрерывно, пока курсор находится в движении.



---

## 1. Справочная информация

| Характеристика | Значение |
| :--- | :--- |
| **Всплывает** | Да |
| **Отменяемое** | Да |
| **Интерфейс** | `MouseEvent` |
| **Цель (Target)** | Элемент, над которым движется курсор |

---

## 2. Ключевые свойства объекта события

При каждом движении создается объект `MouseEvent`, содержащий важные координаты:

* **`clientX` / `clientY`**: Позиция курсора относительно **окна браузера** (viewport).
* **`pageX` / `pageY`**: Позиция относительно всего **документа** (с учетом прокрутки).
* **`movementX` / `movementY`**: Разница в координатах между текущим событием и предыдущим (дельты). Удобно для реализации перетаскивания (drag-and-drop).
* **`buttons`**: Числовое значение, указывающее, какие кнопки мыши были зажаты в момент движения (например, `1` — левая кнопка).

---

## 3. Нюанс: Производительность (Throttling)

Это одно из самых «тяжелых» событий в DOM. Браузер может генерировать сотни событий в секунду. Если внутри обработчика выполнять сложные вычисления или манипуляции с DOM, страница начнет «тормозить».

**Рекомендация:** Используйте **Throttling** (ограничение частоты выполнения) или **`requestAnimationFrame()`**, чтобы обновлять интерфейс не чаще, чем это может отобразить монитор (обычно 60 раз в секунду).

---

## 4. Сравнение: mousemove vs mouseover

| Событие | Когда срабатывает |
| :--- | :--- |
| **`mouseover`** | Один раз в момент пересечения границы элемента. |
| **`mousemove`** | Постоянно, пока курсор движется внутри элемента. |

---

## 5. Примеры использования в коде

### 1. Отслеживание координат
Простой пример для вывода позиции курсора в реальном времени.

```javascript
const box = document.querySelector('.tracking-area');

box.addEventListener('mousemove', (event) => {
  const x = event.clientX;
  const y = event.clientY;
  console.log(`Курсор в точке: X=${x}, Y=${y}`);
});
```

### 2. Создание кастомного курсора
Пример реализации элемента, который «преследует» мышь.

```javascript
const cursor = document.querySelector('.custom-cursor');

document.addEventListener('mousemove', (e) => {
  // Используем requestAnimationFrame для плавности
  requestAnimationFrame(() => {
    cursor.style.transform = `translate(${e.clientX}px, ${e.clientY}px)`;
  });
});
```

### 3. Простой Drag-and-Drop (логика движения)
```javascript
let isDragging = false;

document.addEventListener('mousedown', () => isDragging = true);
document.addEventListener('mouseup', () => isDragging = false);

document.addEventListener('mousemove', (e) => {
  if (isDragging) {
    console.log(`Перемещение объекта на: ${e.movementX}px по горизонтали`);
    // Логика изменения позиции элемента...
  }
});
```
