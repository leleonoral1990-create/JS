# Функции (Function)

Принцип функции заключается в **преобразовании данных**. Она принимает входные значения, выполняет над ними ряд операций и возвращает результат.



---

## 1. Объявление и структура
В JavaScript функции являются значениями, поэтому их можно сохранять в переменные. Преобразование символизируется оператором «толстой стрелки» **=>**.

**Синтаксис: (входные данные) => результат**

```javascript
const add5 = (n) => n + 5
```

**Разбор структуры:**
* **add5**: Идентификатор переменной, в которой хранится функция.
* **(n)**: Аргумент (параметр) — входное значение.
* **=>**: Указывает на то, что это объявление функции.
* **n + 5**: Инструкция (тело), которая будет выполнена и результат которой будет возвращен.

---

## 2. Вызов функции (Invocation)
Чтобы выполнить код функции, её нужно вызвать, используя круглые скобки **()**. 
* **[]** используются для доступа к свойствам/индексам.
* **()** используются для вызова (выполнения) функции.

```javascript
console.log(add5(13)) // 18
console.log(add5(20)) // 25
```
При вызове `add5(13)` значение 13 передается в переменную `n`. Выполняется операция `13 + 5`, и функция возвращает результат `18`.

---

## 3. Типы данных и предсказуемость
Функция может принимать и возвращать любые значения, но результат может быть неожиданным, если типы смешиваются:

```javascript
console.log(add5('pouet')) // 'pouet5' (конкатенация строки и числа)
```

**Правило хорошего тона**: Предпочтительнее всегда передавать и возвращать значения одного и того же типа. Это делает код предсказуемым и позволяет JavaScript оптимизировать выполнение.

---

## 4. Функции с несколькими аргументами
Аргументы разделяются запятой, как элементы в массиве.

```javascript
const multiply = (a, b) => a * b

console.log(multiply(5, 10))   // 50
console.log(multiply(75, 1.5)) // 112.5
```

---

## 5. Вложенные вызовы и композиция
Поскольку функции возвращают значения, их можно использовать как аргументы для других функций или сохранять в переменные.

### Вложенные вызовы
JavaScript вычисляет вложенные функции изнутри наружу. Он должен получить результат внутренней функции, прежде чем завершить внешнюю.

```javascript
console.log(multiply(add5(5), 2)) // 20
```
**Логика выполнения:**
1. Вычисляется `add5(5)`, что возвращает `10`.
2. Код превращается в `multiply(10, 2)`.
3. Возвращается итоговый результат `20`.

### Вызов функций из других функций
Вы можете наращивать сложность, используя уже созданные функции внутри новых:

```javascript
const add10 = (n) => add5(add5(n))
const op1 = (n) => add10(multiply(n, add5(n)))
```
