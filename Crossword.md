# Полный разбор алгоритма crosswordSolver

| Строка кода | Подробное пояснение | Ключевые моменты |
| :--- | :--- | :--- |
| `function crosswordSolver(puzzle, words) {` | Объявление главной функции. Принимает текстовую строку сетки (`puzzle`) и массив слов (`words`). | Не забудьте открыть фигурные скобки `{` для тела функции. |
| `if (typeof puzzle !== 'string' \|\| !Array.isArray(words)) { ... }` | **Защита от "мусора".** Проверка типов: `puzzle` должен быть строкой, `words` — массивом. | Используйте `typeof` и `Array.isArray()`. |
| `if (new Set(words).size !== words.length) { ... }` | **Проверка на дубликаты.** `Set` оставляет только уникальные слова. | Сравнение `size` набора и `length` массива. |
| `const lines = puzzle.split('\n');` | Разрезание текста на строки по символу переноса строки. | Метод `.split('\n')` создает массив строк. |
| `if (lines.length === 0 \|\| lines[0].length === 0) { ... }` | **Защита от пустого ввода** или пустых строк. | Проверка длины массива и его первого элемента. |
| `const height = lines.length;`<br>`const width = lines[0].length;` | Определение габаритов кроссворда (высота и ширина). | Высота — количество строк, ширина — длина первой строки. |
| `for (let i = 0; i < height; i++) {`<br>`if (lines[i].length !== width) { ... } }` | **Проверка на прямоугольность сетки:** все строки должны быть одной длины. | Цикл по высоте с проверкой `.length` каждой строки. |
| `const grid = lines.map(line => line.split(''));` | Преобразование массива строк в 2D-массив символов. | Метод `.map()` и `.split('')` создают матрицу. |
| `const slots = [];`<br>`let totalWordCountFromGrid = 0;` | Создание хранилища для найденных мест (слотов) и счетчика цифр в сетке. | Массив `[]` для слотов, `let` для изменяемого счетчика. |
| `for (let y = 0; y < height; y++) {`<br>`for (let x = 0; x < width; x++) { ... } }` | Двойной цикл для обхода каждой клетки поля (сканирование). | Внешний цикл — Y (высота), внутренний — X (ширина). |
| `const char = grid[y][x];`<br>`if (char !== '.' && char !== '0') { ... }` | Поиск цифр-маркеров начала слов (пропускаем стены и пустые клетки). | Координаты пишутся как `[y][x]`. |
| `const count = parseInt(char);`<br>`totalWordCountFromGrid += count;` | Преобразование символа цифры в число и добавление к общему счету. | `parseInt()` превращает строку в математическое число. |
| `if (x === 0 \|\| grid[y][x - 1] === '.') { ... }` | **Проверка начала горизонтального слова** (край или стена слева). | Важно проверять край `x === 0`, чтобы не выйти за пределы массива. |
| `let len = 1;`<br>`while (x + len < width && grid[y][x + len] !== '.') len++;` | Измерение длины пустого пространства вправо (разведка). | `while` работает, пока условия истинны. |
| `if (len > 1) slots.push({ y, x, len, dir: 'h' });` | Сохранение найденного горизонтального места в массив `slots`. | Использование объекта `{ y, x, len, dir: 'h' }`. |
| `if (y === 0 \|\| grid[y - 1][x] === '.') { ... }` | **Проверка начала вертикального слова** (край сверху или стена выше). | Логика зеркальна горизонтальной, но работаем с осью Y. |
| `let len = 1;`<br>`while (y + len < height && grid[y + len][x] !== '.') len++;` | Измерение длины пустого пространства вниз. | Шагаем по этажам `y + len`. |
| `if (len > 1) slots.push({ y, x, len, dir: 'v' });` | Сохранение вертикального слота. | Направление `'v'` (vertical). |
| `if (totalWordCountFromGrid !== words.length \|\| slots.length !== words.length) { ... }` | **Момент истины:** сверка "обещанных" цифрами слов и реально найденных мест. | Защита от ошибок в условии задачи (например, цифра 1 дает два пути). |
| `const resultGrid = grid.map(row => [...row]);` | Создание глубокой копии сетки (чистовика) для решения. | `Spread`-оператор `[...]` гарантирует независимость копии. |
| `let isSolved = false;`<br>`function solve(slotIdx, remainingWords) { ... }` | Объявление рекурсивной функции для подбора слов. | Нужен флаг `isSolved`, чтобы остановить все ветки при успехе. |
| `if (isSolved) return;`<br>`if (slotIdx === slots.length) { isSolved = true; return; }` | **Базовые случаи рекурсии:** решение найдено или дырки закончились. | Это условия выхода из рекурсии, чтобы она не была бесконечной. |
| `const { y, x, len, dir } = slots[slotIdx];` | Распаковка данных текущего слота (деструктуризация). | Достаем координаты и направление для текущей итерации. |
| `for (let i = 0; i < remainingWords.length; i++) { ... }` | Цикл перебора всех оставшихся слов из мешка. | Перебираем слова по индексу `i`. |
| `if (word.length !== len) continue;` | Пропуск слова, если оно не подходит по размеру. | `continue` экономит время, переходя к следующему слову. |
| `let canPlace = true;`<br>`const changes = [];` | Подготовка к примерке: флаг совместимости и журнал изменений. | Сбрасываем их для каждого нового слова. |
| `const cy = dir === 'v' ? y + j : y;`<br>`const cx = dir === 'h' ? x + j : x;` | Расчет координат каждой буквы слова (**тернарный оператор**). | Краткая запись расчета в зависимости от направления. |
| `if (currentVal !== '' && currentVal !== word[j]) { canPlace = false; break; }` | **Проверка на столкновение букв (коллизию).** | Если буквы разные — `canPlace = false` и немедленный `break`. |
| `changes.push({ cy, cx, prev: currentVal });` | Запись старого значения клетки в журнал перед изменением. | Нужно для "отката" (Backtracking). |
| `if (canPlace) { ... solve(...) ... }` | Если слово подошло — вписываем его и зовем помощника для следующей дырки. | Рекурсивный вызов с уменьшенным набором слов (`filter`). |
| `for (let change of changes) { resultGrid[change.cy][change.cx] = change.prev; }` | **Ластик (Backtracking).** Стираем слово, если решение дальше не сошлось. | Очистка поля перед попыткой вставить другое слово. |
| `solve(0, words);` | Запуск процесса решения с первой дырки и полным списком слов. | Начальная точка рекурсии. |
| `return isSolved ? resultGrid.map(row => row.join('')).join('\n') : 'Error';` | Финальный вывод: либо склеенная сетка, либо Error. | `.join('')` превращает массивы обратно в текст. |
