
# Полный разбор алгоритма Crossword Solver (Финальная версия)

| Код (Строка или Блок) | Подробное пояснение | Ключевые моменты |
| :--- | :--- | :--- |
| `function crosswordSolver(puzzle, words) {` | Объявляем главную функцию, которая принимает сетку (`puzzle`) и список слов (`words`). | Точка входа в программу. |
| `if (typeof puzzle !== 'string' \|\| !Array.isArray(words)) { console.log('Error'); return; }` | **Защита от плохих данных:** проверяем, что сетка — это текст, а слова — это массив. Иначе выдаем ошибку. | Используем `typeof` для текста и `Array.isArray()` для массивов. |
| `if (new Set(words).size !== words.length) { console.log('Error'); return; }` | **Проверка на дубликаты:** прогоняем слова через `Set` (оставляет только уникальные) и сравниваем размеры. | `Set` — самый быстрый способ найти одинаковые слова. |
| `const lines = puzzle.split('\n');`<br>`if (lines.length === 0 \|\| lines[0].length === 0) { ... }` | Режем текст сетки на отдельные строки по символу Enter (`\n`) и защищаемся от пустых кроссвордов. | Метод `.split()` превращает текст в массив. |
| `const height = lines.length;`<br>`const width = lines[0].length;` | Вычисляем габариты кроссворда: высоту (кол-во строк) и ширину (кол-во символов в первой строке). | Счет индексов всегда начинается с нуля. |
| `for (let i = 0; i < height; i++) {`<br>`if (lines[i].length !== width) { ... } }` | **Проверка на ровный прямоугольник:** убеждаемся, что ни одна строка не короче и не длиннее первой. | Цикл обходит каждую строку для сверки длины. |
| `const grid = lines.map(line => line.split(''));` | Создаем удобную 2D-сетку (матрицу), разбивая каждую строку на отдельные символы (буквы). | Конвейер `.map()` обрабатывает каждый элемент массива. |
| `const slots = [];`<br>`let totalWordCount = 0;` | Готовим пустую папку `slots` для найденных мест и счетчик цифр, найденных на поле. | `const` для массива (можно добавлять элементы), `let` для счетчика (будет меняться). |
| `for (let y = 0; y < height; y++) {`<br>`for (let x = 0; x < width; x++) {` | **Старт сканирования:** двойной цикл проходит абсолютно по всем клеткам сверху вниз и слева направо. | `y` — этажи (строки), `x` — комнаты (столбцы). |
| `const char = grid[y][x];`<br>`if (char !== '.' && char !== '0') {` | Робот смотрит в клетку. Если там не стена `.` и не пустота `0` — значит, мы нашли цифру начала слова! | Двойной амперсанд `&&` означает строгое "И". |
| `totalWordCount += parseInt(char);` | Превращаем текст (например, `'2'`) в математическое число `2` и плюсуем в общий блокнот. | `parseInt()` нужен для корректного сложения чисел. |
| `if (x === 0 \|\| grid[y][x - 1] === '.') { ... }` | **Проверка горизонтали:** если мы на левом краю поля или слева от нас стена, слово может идти вправо. | Обязательно проверять край, чтобы не получить ошибку `undefined`. |
| `let len = 1;`<br>`while (x + len < width && grid[y][x + len] !== '.') len++;` | Разведчик с рулеткой: шагает вправо (`x + len`), пока не упрется в край или в стену. Считает длину. | `while` идеально подходит для шагов с неизвестным концом. |
| `if (len > 1) slots.push({ y, x, len, dir: 'h' });` | Если длина больше 1 клетки, сохраняем координаты и направление `h` (horizontal) в папку `slots`. | Объект `{}` группирует все свойства одной дырки. |
| `if (y === 0 \|\| grid[y - 1][x] === '.') { ... dir: 'v' }` | **Проверка вертикали:** зеркальная логика. Смотрим наверх, шагаем вниз, сохраняем направление `v` (vertical). | Меняем координату `y` вместо `x`. |
| `if (totalWordCount !== words.length \|\| slots.length !== words.length) { return; }` | **Сверка реальности:** совпадает ли количество запрошенных цифрами слов с физически найденными местами и списком слов? | Защита от криво составленных сеток. |
| `const resultGrid = grid.map(row => [...row]);`<br>`const solutions = [];` | Создаем чистовик (глубокую копию сетки) и коробку `solutions` для сохранения готовых ответов. | Спрэд-оператор `...` делает копию независимой от оригинала. |
| `function solve(slotIdx, remainingWords) {` | Создаем внутреннего мини-робота (рекурсию) для примерки слов в дырки. | На вход принимает номер дырки и мешок оставшихся слов. |
| `if (solutions.length > 1) return;` | **Оптимизация:** если мы уже нашли два разных ответа, кроссворд не уникален. Нет смысла искать дальше. | Сильно ускоряет работу программы. |
| `if (slotIdx === slots.length) {`<br>`solutions.push(resultGrid.map(row => row.join('')).join('\n')); return; }` | **Условие победы:** дошли до последней дырки? Склеиваем чистовик в текст, кидаем в коробку ответов и жмем `return`. | `return` здесь запускает возврат назад, чтобы найти *другие* варианты. |
| `const { y, x, len, dir } = slots[slotIdx];` | Деструктуризация: достаем координаты текущей дырки из папки для удобного использования. | Распаковка объекта в отдельные переменные. |
| `for (let i = 0; i < remainingWords.length; i++) {` | Начинаем перебирать мешок со словами. | Обычный цикл от 0 до конца массива слов. |
| `if (word.length !== len) continue;` | Если длина слова не совпадает с размером дырки — бросаем его и переходим к следующему. | `continue` перескакивает на следующий шаг цикла перебора слов. |
| `let canPlace = true; const changes = [];` | Подготовка к примерке: оптимистичный флажок и пустой журнал для ластика. | Обнуляется для каждого нового примеряемого слова. |
| `for (let j = 0; j < len; j++) {`<br>`const cy = dir === 'v' ? y + j : y;`<br>`const cx = dir === 'h' ? x + j : x;` | Запускаем примерку каждой буквы слова. Тернарный оператор `? :` высчитывает координаты в зависимости от направления. | Красивая замена длинной конструкции `if-else`. |
| `if (currentVal !== '' && currentVal !== '0' && currentVal !== '1' && currentVal !== '2' && currentVal !== word[j]) { canPlace = false; break; }` | **Проверка коллизии:** если в клетке уже есть чужая буква, и она не совпадает с нашей — случилась авария! | `break` немедленно ломает цикл примерки букв. |
| `changes.push({ cy, cx, prev: currentVal });` | Записываем в журнал, что лежало в клетке до нас (пустота или цифра). | Жизненно необходимо для правильной работы ластика. |
| `if (canPlace) {`<br>`for (let j=0...) resultGrid[cy][cx] = word[j];` | Если аварии не было, берем маркер и вписываем наше слово в чистовик по тем же координатам. | Переносим буквы `word[j]` в матрицу. |
| `solve(slotIdx + 1, remainingWords.filter((_, idx) => idx !== i));` | **Шаг в глубину:** зовем помощника для следующей дырки (`+1`) и отдаем ему мешок без использованного слова (`filter`). | Метод `.filter()` возвращает новый массив без одного элемента. |
| `for (let change of changes) {`<br>`resultGrid[change.cy][change.cx] = change.prev; }` | **Ластик (Backtracking):** когда помощник вернулся, стираем свое слово, возвращая старые значения из журнала. | Очищает поле, чтобы Робот мог примерить следующее слово из мешка. |
| `solve(0, words);` | Даем Роботу стартовый пинок: начни с нулевой дырки и полного списка слов. | Запуск всей рекурсивной машины. |
| `if (solutions.length === 1) { console.log(solutions[0]); }`<br>`else { console.log('Error'); }` | **Финальная проверка уникальности:** если в коробке ответов строго один вариант — печатаем его. Иначе — ошибка. | Полностью закрывает требование "unique solution" из задания. |
