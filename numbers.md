# Глобальный объект Number

В JavaScript **Number** — это не только тип данных, но и объект-помощник, который содержит инструменты для работы с числами. Эти инструменты делятся на статические свойства (константы), статические методы (проверки) и методы прототипа (форматирование).

---

## 1. Константы (Статические свойства)
Это готовые значения, которые используются для сравнения и определения границ вычислений.

* **Number.MAX_VALUE** и **Number.MIN_VALUE**: Самое большое и самое маленькое положительное число, которое может существовать в JS.
* **Number.MAX_SAFE_INTEGER**: $2^{53} - 1$. Максимальное целое число, которое JS может вычислить точно.
* **Number.MIN_SAFE_INTEGER**: $-(2^{53} - 1)$. Минимальное безопасное целое число.
* **Number.EPSILON**: Крошечное число, представляющее разницу между 1 и ближайшим числом с плавающей точкой. Используется для корректного сравнения дробных чисел. Например: $\text{Math.abs}(0.1 + 0.2 - 0.3) < \text{Number.EPSILON}$.
* **Number.NaN**: Соответствует глобальному значению `NaN` («не число»).
* **Number.POSITIVE_INFINITY** / **NEGATIVE_INFINITY**: Бесконечности ($\infty$ и $-\infty$).

---

## 2. Статические методы (Проверки и парсинг)
Эти методы вызываются напрямую от конструктора `Number`. Они нужны для валидации значений или преобразования строк.

* **Number.isInteger(x)**: Проверяет, является ли число целым.
* **Number.isSafeInteger(x)**: Проверяет, входит ли число в диапазон «безопасных» целых чисел.
* **Number.isNaN(x)**: Самый надежный способ проверить, является ли значение `NaN`. 
* **Number.isFinite(x)**: Проверяет, является ли число конечным (не `Infinity` и не `NaN`).
* **Number.parseInt(str)** / **Number.parseFloat(str)**: Извлекают из строки целое или дробное число.
    * Пример: `Number.parseInt("42px")` вернет `42`.

> **Важный нюанс:** Метод `Number.isNaN()` работает строже, чем старый глобальный `isNaN()`. Глобальный метод сначала пытается принудительно превратить значение в число, что может дать ложный результат. Всегда рекомендуется использовать версию `Number.isNaN()`.

---

## 3. Методы прототипа (Форматирование)
Эти методы вызываются у конкретной переменной или числа. Они изменяют внешний вид значения и обычно возвращают строку.

* **.toString(base)**: Превращает число в строку. Можно указать систему счисления (от 2 до 36).
    * Пример: `(255).toString(16)` вернет `"ff"`.
* **.toFixed(n)**: Округляет число до $n$ знаков после запятой.
    * Пример: `(0.1 + 0.2).toFixed(2)` вернет `"0.30"`.
* **.toPrecision(n)**: Форматирует число, оставляя в нем ровно $n$ значащих цифр.
* **.toExponential(n)**: Записывает число в научном (экспоненциальном) формате.
* **.toLocaleString()**: Преобразует число в строку, учитывая региональные стандарты (разделители тысяч, десятичные знаки).
* **.valueOf()**: Возвращает примитивное значение числового объекта.

---

## Шпаргалка по использованию

| Задача | Метод |
| :--- | :--- |
| Проверить, является ли число целым | `Number.isInteger(num)` |
| Округлить число для вывода в интерфейс | `num.toFixed(2)` |
| Извлечь число из строки с единицами измерения (напр. "100px") | `Number.parseInt("100px")` |
| Сравнить результат сложения $0.1 + 0.2$ с $0.3$ | `Math.abs(a - b) < Number.EPSILON` |
| Узнать максимально допустимый предел точности целых чисел | `Number.MAX_SAFE_INTEGER` |
