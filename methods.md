# Методы

Методы — это особый вид функций, которые связаны с определенными данными. Каждый тип данных в JavaScript имеет свой набор встроенных методов для решения типичных задач.

---

## 1. Использование методов
Доступ к методам осуществляется через точку `.` (как к обычному свойству), после чего они вызываются с помощью круглых скобок `()`.

```javascript
'pouet'.toUpperCase() // Вернет 'POUET'
```

### Контекст vs Аргументы
В отличие от обычной функции, метод использует саму строку (или другие данные), к которой он применен, в качестве **контекста**. 
* Обычная функция: `toUpperCase('pouet')`
* Метод: `'pouet'.toUpperCase()` — здесь строка сама является "скрытым" первым аргументом.

---

## 2. Методы с аргументами
Многие методы принимают входные параметры. Рассмотрим на примере метода `.split()`:

```javascript
const baseStr = 'hey-this-is-fun'
console.log(baseStr.split('-')) // ['hey', 'this', 'is', 'fun']
```
Метод `.split('-')` берет строку и разделяет её на части в тех местах, где встречается символ, переданный в качестве аргумента. Результатом всегда является **Массив**.



---

## 3. Цепочки методов (Chaining)
Настоящая сила методов проявляется при их объединении в цепочки. Это возможно, если каждый метод в цепочке возвращает данные, у которых есть следующий нужный нам метод.

```javascript
console.log(baseStr.split('-').join('_')) // 'hey_this_is_fun'
```

**Как это работает:**
1. `baseStr.split('-')` — превращает строку в **Массив**.
2. `.join('_')` — вызывается уже у этого Массива и превращает его обратно в **Строку**, соединяя элементы через нижнее подчеркивание.



### Примеры со `split` и `join`:
* **В массив букв:** `baseStr.split('')` — разбить по пустой строке.
* **Удаление разделителей:** `baseStr.split('-').join('')` — разбить и склеить "намертво".

---

## 4. Конструкторы и Прототипы (OOP)

Методы являются частью объектно-ориентированного программирования (ООП). 

### Конструкторы
Все типы данных имеют функции-конструкторы для создания новых данных: `Boolean`, `Number`, `String`, `Array`, `Object`.
Некоторые из них содержат "статические" функции, которые вызываются от имени самого конструктора:
* `Array.isArray(data)`
* `Object.keys(obj)`

### Прототип (Prototype)
Общие методы (такие как `.toUpperCase()` или `.split()`) физически хранятся в специальном объекте, который называется **prototype**.
* Для строк это: `String.prototype`
* Для массивов это: `Array.prototype`

Все строки, которые вы создаете, автоматически получают доступ к методам, описанным в `String.prototype`.
