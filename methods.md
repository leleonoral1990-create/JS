# Методы в JavaScript (Methods)

**Методы** — это специальные функции, которые не существуют сами по себе, а привязаны к определенным данным (строкам, массивам, числам и т.д.). У каждого типа данных есть свой арсенал встроенных методов для решения частых задач.

## 1. Синтаксис и вызов методов
Методы вызываются через точку `.`, как обычные свойства объектов, но в конце обязательно ставятся круглые скобки `()`, так как это функция, которую нужно выполнить.

Главная особенность метода в том, что он берет данные, к которым привязан, как "скрытый" контекст (базу для работы).

```javascript
// Метод toUpperCase() не принимает аргументов, он просто переводит исходную строку в верхний регистр
console.log('pouet'.toUpperCase()); 
// Результат: 'POUET'
```

## 2. Методы с аргументами: `split` и `join`
Многие методы принимают аргументы, которые указывают, *как именно* нужно обработать данные.

### Строковый метод `.split(separator)`
Разбивает строку на массив подстрок, используя переданный разделитель.

```javascript
const baseStr = 'hey-this-is-fun';

// Разбиваем строку по дефису
console.log(baseStr.split('-'));
// Результат: [ 'hey', 'this', 'is', 'fun' ]

// Трюк: разбиваем строку на массив отдельных букв (используя пустую строку '')
console.log(baseStr.split(''));
// Результат: [ 'h', 'e', 'y', '-', 't', 'h', 'i', 's', ... ]
```

### Метод массивов `.join(separator)`
Выполняет обратное действие: берет массив и склеивает все его элементы в одну строку, вставляя между ними переданный разделитель.

```javascript
const arr = [ 'hey', 'this', 'is', 'fun' ];

// Склеиваем массив через нижнее подчеркивание
console.log(arr.join('_')); 
// Результат: 'hey_this_is_fun'
```

## 3. Цепочки методов (Method Chaining)
Самая мощная особенность методов — их можно вызывать один за другим. Если первый метод возвращает массив, вы можете сразу же через точку вызвать метод массива.

```javascript
const baseStr = 'hey-this-is-fun';

// Цепочка: Строка -> Массив -> Новая строка
console.log(baseStr.split('-').join('_'));
// Результат: 'hey_this_is_fun'

// Цепочка: удаляем все дефисы (разбиваем по дефису и склеиваем "вплотную" пустой строкой)
console.log(baseStr.split('-').join(''));
// Результат: 'heythisisfun'
```

## 4. Под капотом: Конструкторы и Прототипы (Основы ООП)
Методы — это часть концепции объектно-ориентированного программирования (ООП). 

* **Конструкторы (Constructors):** В JS есть встроенные функции, создающие типы данных: `Boolean`, `Number`, `String`, `Array`, `Object`. Обычно мы ими не пользуемся напрямую (пишем `[]` вместо `new Array()`).
* **Статические методы:** Прямо в конструкторах лежат некоторые полезные функции, которые не привязаны к конкретным данным, а являются глобальными утилитами (например, `Array.isArray(...)` или `Object.keys(...)`).
* **Прототипы (Prototypes):** Все методы, которые мы вызываем у строк или массивов (как `split` или `join`), на самом деле хранятся в специальном объекте-прототипе этого типа данных. Например, методы строк лежат в `String.prototype`.

*(Совет: полный список методов для каждого типа данных всегда можно найти в официальной документации MDN).*
