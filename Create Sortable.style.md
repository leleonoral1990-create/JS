| Строка кода | Для чего она нужна (простым языком) | Важные нюансы (синтаксис) | Пример использования еще |
| :--- | :--- | :--- | :--- |
| `:root {` | Это «склад» переменных для всего сайта. Здесь мы задаем главные цвета (светлая тема). | `:root` означает самый главный корень документа (по сути тег `<html>`). | `:root { --main-size: 16px; }` |
| `--bg: #f4f7f6; --surf: #ffffff; --txt: #2c3e50;` | Создаем свои переменные: `--bg` (фон сайта), `--surf` (поверхность карточек - белая), `--txt` (цвет текста - темно-синий). | Переменные в CSS **всегда** начинаются с двух тире `--`. Цвета заданы в формате HEX (коды с решеткой). | `--my-color: red;` |
| `--prim: #3498db; --brd: #dcdde1; --hover: #f1f2f6;` | Еще переменные: `--prim` (главный цвет кнопок - синий), `--brd` (цвет рамок), `--hover` (цвет при наведении мышки). | - | `--shadow: #000000;` |
| `}` | Закрываем склад переменных светлой темы. | Фигурные скобки `{ }` обязательны. | - |
| `body.dark {` | А это «склад» для **темной темы**. Эти цвета включатся, только если у тега `<body>` появится класс `dark` (его добавит твой JS-код при клике на кнопку 🌓). | Селектор `body.dark` значит "найди тег body, у которого есть класс dark". Слитно, без пробела. | `div.active { ... }` |
| `--bg: #121212; --surf: #1e1e1e; --txt: #f5f6fa;` | Перезаписываем переменные! Фон теперь почти черный, поверхность темно-серая, текст почти белый. | Имена переменных те же, поменялись только цвета. | - |
| `--prim: #e74c3c; --brd: #2f3640; --hover: #2d3436;` | Главный цвет (кнопки, выделение) в темной теме будет красным (`#e74c3c`), рамки темными. | - | - |
| `}` | Закрываем склад темной темы. | - | - |
| `body { font-family: 'Segoe UI', sans-serif; background: var(--bg); color: var(--txt); margin: 0; padding: 20px; transition: 0.3s; }` | Задаем стиль всему тегу `<body>`: шрифт (Segoe UI), фон берем со склада (`var(--bg)`), текст тоже (`var(--txt)`). Убираем внешние отступы (`margin: 0`), делаем внутренние (`padding: 20px`). | **`var(--имя)`** — так мы достаем значение со склада. **`transition: 0.3s`** — супер-фишка! Благодаря ей смена светлой темы на темную будет плавной (0.3 секунды), а не резкой. | `div { padding: 10px; }` |
| `header { margin-bottom: 20px; }` | Делаем отступ снизу (`margin-bottom`) от шапки сайта, чтобы она не прилипала к таблице. | - | `footer { margin-top: 50px; }` |
| `h1 { color: var(--prim); margin: 0 0 15px 0; }` | Красим главный заголовок в наш главный цвет. Задаем отступ снизу 15 пикселей. | Запись `margin: 0 0 15px 0;` читается по часовой стрелке: верх, право, низ, лево. | `p { margin: 10px 0; }` |
| `.toolbar { display: flex; gap: 15px; align-items: center; flex-wrap: wrap; }` | Превращаем панель управления в "гибкую строку" (`flex`). `gap` делает пробелы между элементами по 15px. `align-items` выравнивает их по центру по вертикали. `flex-wrap` разрешает им переноситься на новую строку, если экран телефона узкий. | **Flexbox** — современный способ ровно расставлять элементы на сайте. | `.menu { display: flex; }` |
| `input, select, button { padding: 10px; border-radius: 6px; border: 1px solid var(--brd); background: var(--surf); color: var(--txt); outline: none; }` | Применяем одинаковый стиль сразу к полям ввода, спискам и кнопкам: скругляем углы (`border-radius`), рисуем тонкую рамку, убираем стандартную синюю обводку браузера (`outline: none`). | Перечисление через запятую применяет стили сразу ко всем указанным тегам. | `h1, h2, h3 { color: red; }` |
| `input:focus { border-color: var(--prim); }` | Когда пользователь кликнет в поле поиска (оно в "фокусе"), рамка станет главного цвета (синего или красного в темной теме). | `:focus` — это псевдокласс. Он срабатывает, когда элемент активен (в него тыкнули). | `button:focus { ... }` |
| `button { cursor: pointer; font-weight: bold; }` | При наведении на кнопки курсор мыши станет "рукой с пальцем" (`pointer`). Текст на кнопках делаем жирным. | Без `cursor: pointer` кнопки иногда выглядят как обычный текст. | `a { cursor: pointer; }` |
| `.table-container { background: var(--surf); border-radius: 10px; overflow-x: auto; box-shadow: 0 4px 15px rgba(0,0,0,0.1); }` | Коробка с таблицей: белая (или серая), скругленная. `box-shadow` рисует красивую легкую тень. | **`overflow-x: auto;`** — спасение для телефонов! Если таблица не влезет в экран, появится горизонтальная прокрутка (скролл), и сайт не сломается. | `div { box-shadow: 2px 2px black; }` |
| `table { width: 100%; border-collapse: collapse; min-width: 1000px; }` | Таблица занимает 100% ширины коробки. `border-collapse` убирает двойные рамки между ячейками. | `min-width: 1000px` заставляет таблицу всегда быть не уже 1000 пикселей (поэтому на телефоне и нужен скролл из прошлой строки). | `table { width: 50%; }` |
| `th { padding: 15px; text-align: left; cursor: pointer; background: var(--hover); border-bottom: 2px solid var(--brd); user-select: none; }` | Заголовки колонок: текст слева, фон чуть серее обычного, снизу жирная полоска (2px). | `user-select: none;` запрещает выделять текст мышкой. Это нужно, чтобы при быстром кликании для сортировки текст не выделялся синим. | `p { user-select: none; }` |
| `th:hover { color: var(--prim); }` | Когда наводишь мышку на заголовок колонки, текст окрашивается в главный цвет (подсказка, что можно кликнуть). | `:hover` срабатывает только в момент наведения мыши. | `a:hover { color: red; }` |
| `td { padding: 12px 15px; border-bottom: 1px solid var(--brd); cursor: pointer; }` | Обычные ячейки с данными: добавляем отступы и тонкую линию снизу, чтобы строки не сливались. | - | - |
| `tr:hover td { background: var(--hover); }` | Подсветка целой строки! Если навести мышь на строку (`tr:hover`), у всех ячеек (`td`) внутри нее меняется фон. Очень помогает не потерять глазами длинную строку. | Здесь используется вложенность: найди `td` внутри `tr`, на который навели мышь. | `ul:hover li { ... }` |
| `img.xs { width: 40px; height: 40px; border-radius: 50%; object-fit: cover; border: 2px solid var(--brd); }` | Стиль для маленьких аватарок в таблице. `border-radius: 50%` делает их идеально круглыми. | `object-fit: cover;` обрезает картинку так, чтобы она красиво заполнила квадрат 40х40, даже если она была прямоугольной. | `img { object-fit: cover; }` |
| `mark { background: var(--prim); color: white; border-radius: 2px; }` | Это стиль для подсветки текста при поиске. (Если введешь букву "а", все буквы "а" в таблице обернутся в тег `<mark>`). | Фон становится главным цветом, текст белым. | `<mark>Важно</mark>` |
| `.pagination { display: flex; gap: 8px; margin-top: 20px; justify-content: center; flex-wrap: wrap; }` | Контейнер для кнопок страниц: делаем их гибкими (`flex`), выставляем по центру (`justify-content: center`). | - | - |
| `.page-btn { padding: 8px 12px; border: 1px solid var(--brd); background: var(--surf); color: var(--txt); cursor: pointer; border-radius: 4px; }` | Рисуем сами кнопочки страниц (1, 2, 3...): квадратненькие, с тонкой рамкой. | - | - |
| `.page-btn.active { background: var(--prim); color: white; border-color: var(--prim); }` | Стиль для **активной** кнопки (текущая страница, на которой мы находимся). Она становится залитой главным цветом. | Селектор без пробела `.page-btn.active` значит: элемент, у которого есть ОБА этих класса одновременно. | `.btn.danger { ... }` |
| `/* Modal Styles */` | Это просто комментарий в CSS. Браузер его игнорирует. | Комментарии в CSS пишутся строго между `/*` и `*/`. | `/* Мой код */` |
| `.modal { display: none; position: fixed; inset: 0; background: rgba(0,0,0,0.8); backdrop-filter: blur(5px); align-items: center; justify-content: center; z-index: 1000; padding: 20px; }` | Темный фон всплывающего окна. Изначально скрыт (`display: none`). Занимает весь экран (`fixed; inset: 0;`). `z-index: 1000` кладет его поверх всех остальных элементов сайта. | `backdrop-filter: blur(5px);` — очень красивая фишка! Она размывает (блюрит) сайт позади темного фона окна. Как матовое стекло. | `.overlay { z-index: 99; }` |
| `.modal-content { background: var(--surf); padding: 30px; border-radius: 15px; display: flex; gap: 30px; max-width: 700px; width: 100%; position: relative; flex-wrap: wrap; }` | Сама белая карточка персонажа поверх темного фона. Внутри нее фотка и текст стоят рядом (`display: flex`). | `position: relative;` нужно, чтобы крестик закрытия (ниже) мог позиционироваться относительно углов этой карточки. | - |
| `.close-btn { position: absolute; top: 10px; right: 15px; font-size: 24px; border: none; background: none; color: var(--txt); cursor: pointer; }` | Кнопка-крестик. `position: absolute; top: 10px; right: 15px;` прибивает её жестко в правый верхний угол карточки (с отступами 10px и 15px). | `border: none; background: none;` стирает стандартный серый фон кнопки, оставляя только сам крестик. | `.icon { position: absolute; }` |
| `#mImg { width: 250px; border-radius: 10px; box-shadow: 0 5px 15px rgba(0,0,0,0.3); }` | Большое фото персонажа в карточке. Скругляем углы и добавляем красивую тень. | `#mImg` — это поиск по ID (решетка). В HTML это `<img id="mImg">`. | `#logo { width: 100px; }` |
| `.modal-info h2 { color: var(--prim); margin-top: 0; }` | Заголовок (имя) внутри карточки персонажа красится в главный цвет (синий/красный). | Пробел значит "найди все `h2`, которые лежат внутри элемента `.modal-info`". | `.card h1 { ... }` |
| `.modal-info p { margin: 8px 0; border-bottom: 1px solid var(--brd); padding-bottom: 4px; }` | Абзацы (строчки с данными типа Рост, Вес). Каждая строчка подчеркнута снизу тонкой линией (`border-bottom`), как в тетрадке. | - | - |
