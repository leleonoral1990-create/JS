# Метод Object.entries()

`Object.entries()` — это статический метод, который возвращает массив собственных перечисляемых свойств указанного объекта в формате пар `[ключ, значение]`. 

Порядок элементов в массиве соответствует порядку, который получается при обходе объекта циклом `for...in` (за исключением того, что `for...in` также перечисляет свойства из цепочки прототипов).

## Синтаксис

```javascript
Object.entries(obj)
```

**Параметры:**
* `obj`: Объект, чьи собственные перечисляемые свойства в виде пар `[ключ, значение]` должны быть возвращены.

**Возвращаемое значение:**
* Массив массивов, где каждый вложенный массив — это пара `[ключ, значение]`.

---

## Примеры использования

### 1. Базовое использование с объектом
Метод преобразует ключи объекта в строки (если они еще ими не являются).

```javascript
const user = {
  name: 'Alex',
  age: 30,
  isAdmin: true
};

console.log(Object.entries(user));
// [ ['name', 'Alex'], ['age', 30], ['isAdmin', true] ]
```

### 2. Использование с массивами
Поскольку массивы в JavaScript являются объектами, где индексами выступают ключи, `Object.entries()` вернет индекс в качестве ключа (в виде строки).

```javascript
const fruits = ['яблоко', 'банан'];
console.log(Object.entries(fruits));
// [ ['0', 'яблоко'], ['1', 'банан'] ]
```

### 3. Использование со строками
Символы в строке индексируются так же, как элементы в массиве.

```javascript
const str = 'JS';
console.log(Object.entries(str));
// [ ['0', 'J'], ['1', 'S'] ]
```

---

## Применение в реальном коде

### Циклы и итерация
`Object.entries()` часто используется вместе с деструктуризацией массивов в цикле `for...of`, чтобы удобно перебирать ключи и значения объектов.

```javascript
const scores = { math: 90, english: 85, science: 92 };

for (const [subject, score] of Object.entries(scores)) {
  console.log(`Предмет: ${subject}, Балл: ${score}`);
}
// Предмет: math, Балл: 90
// Предмет: english, Балл: 85
// Предмет: science, Балл: 92
```



### Преобразование объекта в Map
Конструктор `new Map()` принимает массив пар `[ключ, значение]`, что делает `Object.entries()` идеальным инструментом для конвертации.

```javascript
const settingsObj = { theme: 'dark', notifications: true };

const settingsMap = new Map(Object.entries(settingsObj));

console.log(settingsMap.get('theme')); // 'dark'
```

## Важные нюансы

1.  **Собственные свойства:** Метод возвращает только те свойства, которые принадлежат самому объекту (не наследуются через прототип).
2.  **Перечисляемые свойства:** Если свойство создано с помощью `Object.defineProperty()` и помечено как `enumerable: false`, оно не попадет в результат.
3.  **Ключи-символы (Symbols):** Свойства, ключами которых являются `Symbol`, игнорируются методом `Object.entries()`.
4.  **Сортировка:** Для строковых ключей порядок сохраняется согласно порядку создания (в современных движках), однако для числовых ключей (или строк, которые могут быть числами) JavaScript отсортирует их по возрастанию.

```javascript
const objWithNumbers = { 10: 'десять', 1: 'один', name: 'тест' };
console.log(Object.entries(objWithNumbers));
// [ ['1', 'один'], ['10', 'десять'], ['name', 'тест'] ]
```
