# Math.min()

---

## Описание
Статический метод **Math.min()** возвращает наименьшее из чисел, переданных в качестве входных параметров. Если параметры отсутствуют, метод возвращает `Infinity`.

Поскольку `Math` не является конструктором, метод всегда используется как `Math.min()`, а не как метод созданного экземпляра.

---

## Синтаксис

```javascript
Math.min()
Math.min(value1)
Math.min(value1, value2)
Math.min(value1, value2, /* …, */ valueN)
```

**Параметры:**
* **value1, ..., valueN**: Ноль или более чисел, среди которых будет выбрано наименьшее.

---

## Возвращаемое значение
* **Наименьшее число** из заданных.
* **NaN**: Если хотя бы один из параметров является `NaN` или не может быть преобразован в число.
* **Infinity**: Если параметры не были предоставлены.

---

## Технические подробности
* Свойство `Math.min.length` равно 2. Это указывает на то, что метод спроектирован для обработки как минимум двух параметров, хотя он может принимать любое их количество.

---

## Примеры использования

### Базовое нахождение минимума
```javascript
const x = 10;
const y = -20;
const z = Math.min(x, y); // -20

console.log(Math.min(2, 3, 1));     // 1
console.log(Math.min(-2, -3, -1));  // -3
```

### Работа с массивами
Для нахождения минимального значения в массиве используется spread-синтаксис (`...`):
```javascript
const array = [2, 3, 1];
console.log(Math.min(...array)); // 1
```

---

## Ограничение значения (Clipping)



`Math.min()` часто применяется для «отсечения» значения, чтобы оно не превышало определенную верхнюю границу.

**Классическое условие:**
```javascript
let x = f(foo);
if (x > boundary) {
  x = boundary;
}
```

**Аналог с использованием Math.min():**
```javascript
const x = Math.min(f(foo), boundary);
```

В этой связке значение `x` никогда не станет больше, чем `boundary`. Если результат функции `f(foo)` окажется меньше границы, выберется он; если больше — выберется сама граница.
