# Синтаксис расширения (Spread syntax `...`)

Синтаксис расширения (`...`) позволяет «разворачивать» итерируемые объекты (такие как массивы или строки) в местах, где ожидается ноль или более аргументов (при вызове функций) или элементов (в литералах массивов). В литералах объектов он используется для перечисления собственных свойств объекта и добавления их в создаваемый объект.

## Синтаксис

```javascript
// 1. В аргументах функции:
myFunction(a, ...iterableObj, b);

// 2. В литералах массивов:
[1, ...iterableObj, '4', 'five', 6];

// 3. В литералах объектов:
{ ...obj, key: 'value' };
```

---

## 1. Использование в вызовах функций

Синтаксис расширения — это современная замена метода `Function.prototype.apply()`, когда элементы массива нужно передать как отдельные аргументы функции.

```javascript
function sum(x, y, z) {
  return x + y + z;
}

const numbers = [1, 2, 3];

// Старый способ (через apply):
console.log(sum.apply(null, numbers)); // 6

// Современный способ (через spread):
console.log(sum(...numbers)); // 6
```

Можно использовать `...` несколько раз и комбинировать с обычными аргументами:

```javascript
function myFunction(v, w, x, y, z) {}
const args = [0, 1];

myFunction(-1, ...args, 2, ...[3]); 
// Эквивалентно: myFunction(-1, 0, 1, 2, 3)
```

---

## 2. Использование в литералах массивов

**Конкатенация и сборка новых массивов:**
Вместо использования методов `push()`, `unshift()` или `concat()`, вы можете легко собирать массивы:

```javascript
const parts = ["плечи", "колени"];
const lyrics = ["голова", ...parts, "и", "пальцы"]; 
// ["голова", "плечи", "колени", "и", "пальцы"]

const arr1 = [0, 1, 2];
const arr2 = [3, 4, 5];
const merged = [...arr1, ...arr2]; 
// [0, 1, 2, 3, 4, 5]
```

**Поверхностное копирование массива (Shallow Copy):**
```javascript
const arr = [1, 2, 3];
const arr2 = [...arr]; // Аналог arr.slice()

arr2.push(4); 
// arr2 стало [1, 2, 3, 4]
// arr остался [1, 2, 3] (оригинал не изменился)
```
*⚠️ Важно: Spread делает копию только на один уровень вглубь. Многомерные массивы или вложенные объекты внутри массива будут скопированы по ссылке.*

**Условное добавление элементов:**
Используя тернарный оператор, можно добавлять элементы при определенном условии:
```javascript
const isSummer = false;
const fruits = ["apple", "banana", ...(isSummer ? ["watermelon"] : [])];
// ['apple', 'banana']
```

## 3. Использование в литералах объектов

**Копирование и слияние объектов:**
Spread позволяет легко объединять объекты в один новый.
```javascript
const obj1 = { foo: "bar", x: 42 };
const obj2 = { bar: "baz", y: 13 };

const clonedObj = { ...obj1 }; 
// { foo: "bar", x: 42 }

const mergedObj = { ...obj1, ...obj2 }; 
// { foo: "bar", x: 42, bar: "baz", y: 13 }
```

**Переопределение свойств:**
Если в сливаемых объектах есть ключи с одинаковыми именами, приоритет будет у того свойства, которое добавлено **последним** (находится правее).
```javascript
const obj1 = { foo: "bar", x: 42 };
const obj2 = { foo: "baz", y: 13 };

const merged = { x: 41, ...obj1, ...obj2, y: 9 };
// { x: 42, foo: "baz", y: 9 }
```

**Отличия от `Object.assign()`:**
1. `...` всегда создает *новый* объект и не мутирует существующие. `Object.assign(obj1, obj2)` изменяет целевой объект `obj1`.
2. Spread игнорирует и не запускает функции-сеттеры (setters) при клонировании.

---

## ⚠️ Важные нюансы и ограничения

1. **Итерируемость в массивах/функциях:** Принимаются только объекты, реализующие протокол итерации (Array, String, Map, Set). Использовать обычный объект с массивом нельзя:
   ```javascript
   const obj = { key: "value" };
   const array = [...obj]; // ❌ TypeError: obj is not iterable
   ```

2. **Spread примитивов в объекты:**
   При разворачивании любых примитивов в литерал объекта используются только их перечисляемые свойства. Из всех примитивов они есть только у строк:
   ```javascript
   const obj = { ...true, ..."test", ...10 }; 
   // { '0': 't', '1': 'e', '2': 's', '3': 't' }
   // true и 10 были тихо проигнорированы.
   ```
