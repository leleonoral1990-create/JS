# Math.max()

---

## Описание
Статический метод **Math.max()** возвращает наибольшее из чисел, переданных в качестве входных параметров. Если параметры отсутствуют, метод возвращает $- \infty$ (`-Infinity`).

Поскольку `Math` не является конструктором, метод всегда используется как `Math.max()`, а не как метод созданного экземпляра.

---

## Синтаксис

```javascript
Math.max()
Math.max(value1)
Math.max(value1, value2)
Math.max(value1, value2, /* …, */ valueN)
```

**Параметры:**
* **value1, ..., valueN**: Ноль или более чисел, среди которых будет выбрано наибольшее.

---

## Возвращаемое значение
* **Наибольшее число** из заданных.
* **NaN**: Если хотя бы один из параметров является `NaN` или не может быть преобразован в число.
* **-Infinity**: Если параметры не были предоставлены.

---

## Технические подробности
* Свойство `Math.max.length` равно 2. Это косвенно указывает на то, что метод предназначен для обработки как минимум двух параметров.

---

## Примеры использования

### Базовое нахождение максимума
```javascript
Math.max(10, 20);    // 20
Math.max(-10, -20);  // -10
Math.max(-10, 20);   // 20
```

### Поиск максимального элемента в массиве

#### 1. Spread-синтаксис (оператор расширения `...`)
Самый современный и короткий способ для небольших и средних массивов.
```javascript
const arr = [1, 2, 3];
const max = Math.max(...arr); // 3
```

#### 2. Метод apply()
Более старый способ передачи элементов массива в качестве аргументов.
```javascript
function getMaxOfArray(numArray) {
  return Math.max.apply(null, numArray);
}
```

#### 3. Метод reduce()
Этот способ не имеет ограничений по размеру массива и является самым надежным для огромных наборов данных.
```javascript
const arr = [1, 2, 3];
const max = arr.reduce((a, b) => Math.max(a, b), -Infinity);
```

---

## Важное ограничение: Лимит аргументов


При использовании **spread-синтаксиса (`...`)** или **`apply()`** JavaScript пытается передать каждый элемент массива как отдельный параметр функции. У движков JavaScript есть лимит на количество аргументов (стек вызовов). Если в массиве слишком много элементов (десятки или сотни тысяч), эти методы либо вернут ошибку, либо неправильный результат.

В таких случаях всегда следует использовать **`reduce()`**, так как он обрабатывает элементы по очереди и не перегружает стек.
