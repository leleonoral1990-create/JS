# Динамическое управление свойствами

Понимание того, как обращаться к свойствам, позволяет динамически изменять объекты и массивы в процессе выполнения кода.

---

## 1. Работа с объектами

Вы можете присваивать значения свойствам объекта так же, как значения переменным. Для этого не нужно использовать ключевые слова `let` или `const`, так как вы не создаете новую переменную, а модифицируете существующий объект.

### Создание и заполнение свойств
Вы можете начать с пустого объекта и постепенно добавлять в него данные:

```javascript
const street = {}
console.log(street.name) // Выведет undefined (объект пуст)

// Присваивание значений
street.name = 'Matabiau'
street.number = 175

console.log(street.name) // 'Matabiau'
```

### Комбинированный подход
Свойства можно объявлять как при создании объекта, так и добавлять их позже. В качестве значений можно использовать другие переменные или объекты.

```javascript
const address = {
  country: 'Peru',
  town: 'Toulouse',
}

// Добавление нового свойства позже
address.postalCode = 31000

// Использование значения переменной
address.street = street
```

### Вложенные свойства
Присваивание работает и для глубоко вложенных структур:

```javascript
address.street.type = 'boulevard'
```

---

## 2. Переназначение значений

Если свойство уже существует, вы можете легко исправить или изменить его значение, просто присвоив новое.

```javascript
address.country = 'France' // Исправляем ошибку в данных
console.log(address.country) // 'France'
```

---

## 3. Ограничения и ошибки

При попытке задать свойство для значения, которое является `undefined`, возникнет ошибка. Перед тем как обращаться к вложенному свойству, необходимо убедиться, что родительский объект существует.

```javascript
// ОШИБКА:
// address.postalCode.type = 'boulevard' 
// Приведет к ошибке, так как address.postalCode — это число, а не объект
```

---

## 4. Динамическое заполнение массивов

Для массивов логика идентична: вы обращаетесь к индексу и присваиваете ему значение.

```javascript
const multipleOf5 = []
multipleOf5[0] = 5
multipleOf5[1] = 10
multipleOf5[2] = 15

console.log(multipleOf5) // [5, 10, 15]
```

*Примечание: Существуют специальные методы массивов для добавления элементов (например, push), которые будут рассмотрены позже.*

---

## 5. Принцип симметрии

Способ обращения к свойству для **получения** (чтения) значения и для его **установки** (записи) абсолютно одинаков. Все правила именования и синтаксиса (точечная нотация, квадратные скобки), применимые к чтению свойств, действуют и при их динамическом назначении.
