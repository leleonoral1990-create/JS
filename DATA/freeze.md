# Object.freeze()

---

## Описание
Статический метод **Object.freeze()** замораживает объект, обеспечивая самый высокий уровень целостности в JavaScript.

Замороженный объект становится полностью неизменяемым:
* Нельзя добавлять новые свойства.
* Нельзя удалять существующие свойства.
* Нельзя изменять значения свойств.
* Нельзя изменять атрибуты дескрипторов (перечисляемость, настраиваемость, доступность для записи).
* Нельзя переназначать прототип объекта.

---

## Синтаксис

```javascript
Object.freeze(obj)
```

**Параметры:**
* `obj` — Объект, который необходимо заморозить.

**Возвращаемое значение:**
* Тот же самый объект, который был передан в функцию (метод не создает копию).

---

## Технические детали

Замораживание эквивалентно выполнению двух шагов для всех существующих свойств:
1. Установка атрибута `configurable` (настраиваемость) в значение `false`.
2. Установка атрибута `writable` (доступность для записи) в значение `false`.

### Поведение в разных режимах
Любая попытка изменить замороженный объект приведет к следующему:
* **В обычном режиме**: Операция будет проигнорирована (молчаливая неудача).
* **В строгом режиме (strict mode)**: Будет выброшено исключение `TypeError`.

### Исключения для TypedArray
Метод выбросит `TypeError` при попытке заморозить `TypedArray` (например, `Uint8Array`) или `DataView`, если они содержат элементы, так как они являются представлениями над памятью.

---

## Примеры использования

### 1. Замораживание объекта
```javascript
const obj = {
  foo: "bar"
};

Object.freeze(obj);

// Попытки изменения
obj.foo = "new value";  // Не сработает
obj.newProp = "test";   // Свойство не будет добавлено
delete obj.foo;         // Свойство не будет удалено

console.log(obj.foo);    // "bar"
console.log(Object.isFrozen(obj)); // true
```

### 2. Замораживание массива
Замороженный массив нельзя модифицировать, включая использование мутирующих методов (например, `push`).

```javascript
const a = [0];
Object.freeze(a);

a[0] = 1;  // Не сработает
a.push(2); // TypeError
```

---

## Поверхностная заморозка (Shallow Freeze)

Важно понимать, что `Object.freeze()` работает **поверхностно**. Если значением свойства является другой объект, этот вложенный объект останется доступным для изменений.

```javascript
const user = {
  name: "Mayank",
  address: {
    city: "Delhi"
  }
};

Object.freeze(user);

user.name = "New Name";      // Не сработает
user.address.city = "Noida"; // Сработает! Вложенный объект не заморожен

console.log(user.address.city); // "Noida"
```

---

## Глубокая заморозка (Deep Freeze)

Чтобы сделать объект полностью неизменяемым (константным), необходимо рекурсивно заморозить каждое непримитивное свойство.

### Шаблон реализации:
```javascript
function deepFreeze(object) {
  // Получаем все ключи (включая символы)
  const propNames = Reflect.ownKeys(object);

  for (const name of propNames) {
    const value = object[name];

    // Если значение - объект или функция, замораживаем его рекурсивно
    if ((value && typeof value === "object") || typeof value === "function") {
      deepFreeze(value);
    }
  }

  return Object.freeze(object);
}

const obj2 = {
  internal: {
    a: null
  }
};

deepFreeze(obj2);
obj2.internal.a = "changed"; // Теперь это изменение не сработает
console.log(obj2.internal.a); // null
```

*Примечание: При использовании рекурсии следует учитывать возможные циклические ссылки в графе объектов во избежание бесконечного цикла.*

### Дополнительные нюансы Object.freeze()

**1. Геттеры и сеттеры**
Заморозка не блокирует работу аксессоров. Если в объекте есть геттер, он продолжит возвращать значения (которые могут меняться), а сеттер можно будет вызвать без ошибок (хотя само свойство-аксессор изменить или удалить нельзя).

**2. Приватные элементы**
Приватные поля класса (начинающиеся с `#`) не являются обычными свойствами. `Object.freeze()` их «не видит», поэтому их значения можно изменять даже в замороженном объекте. 

**3. Проверка состояния**
Для проверки, был ли объект заморожен, используется метод:
```javascript
Object.isFrozen(obj); // вернет true или false
```
