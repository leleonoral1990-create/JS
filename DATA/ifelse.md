## Условные операторы (if / else)

Хотя тернарные операторы удобны для простых условий, **if / else** незаменим, когда логика становится сложнее. 



### Основные отличия от тернарного оператора:
* **Гибкость**: Можно использовать `if` без обязательного блока `else`.
* **Многострочность**: Внутри блока `{}` можно выполнить сразу несколько команд (выражений).
* **Отсутствие возврата**: Сам по себе `if` не возвращает значение. Чтобы функция что-то выдала наружу, нужно использовать ключевое слово **return**.

---

### Работа с блоками кода
Если условие в скобках истинно (**truthy**), выполняется код внутри фигурных скобок.

```javascript
const condition = true

if (condition) {
  console.log('Условие истинно')
  console.log('Здесь может быть сколько угодно строк кода')
}
```

Вы можете инвертировать условие с помощью оператора **!**:
```javascript
if (!condition) {
  // Этот блок сработает, если condition равно false
} else {
  console.log('Условие истинно')
}
```

---

### Ключевое слово `return`
Внутри функции `return` делает две вещи:
1.  Указывает, какой результат должна вернуть функция.
2.  **Мгновенно прерывает** выполнение функции. Весь код, который идет после `return`, будет проигнорирован.

---

### Принцип «Раннего возврата» (Early Return)
Благодаря тому, что `return` прерывает функцию, мы можем писать более чистый код без лишних `else` и `else if`.

Рассмотрим пример (в твоем тексте была небольшая путаница: если `a < b`, то возвращая `b`, мы на самом деле ищем **максимум**, а не минимум):

```javascript
const max = (a, b) => {
  if (a < b) {
    return b // Если условие верно, функция завершится здесь
  }
  return a // Если условие ложно, мы попадем сюда без всяких else
}

console.log(max(4, 29)) // 29
console.log(max(4, 2))  // 4
```

Этот подход делает код «плоским» и более читаемым: если условие выполнилось — мы выходим, если нет — просто продолжаем идти дальше по функции. Используя ранний возврат, ты практически перестанешь нуждаться в сложных конструкциях `else if`.
