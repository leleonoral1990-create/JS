# Метод JSON.stringify()

`JSON.stringify()` — это статический метод, который преобразует значение JavaScript (объект, массив, строку, число и т.д.) в строку формата JSON. Это необходимо для передачи данных по сети, сохранения в локальное хранилище или записи в файлы.



## Синтаксис

```javascript
JSON.stringify(value)
JSON.stringify(value, replacer)
JSON.stringify(value, replacer, space)
```

**Параметры:**
1.  **`value`**: Значение, которое нужно преобразовать в JSON.
2.  **`replacer`** (необязательно): Функция или массив имен свойств, которые определяют, какие части объекта должны быть включены в итоговую строку.
3.  **`space`** (необязательно): Строка или число, используемое для вставки пробелов (отступов) в выходную строку для улучшения читаемости (красивый вывод).

**Возвращаемое значение:**
* Строка в формате JSON, представляющая переданное значение.
* Если передано значение, которое нельзя преобразовать (например, функция или `undefined`), метод может вернуть `undefined`.

---

## Примеры использования

### 1. Базовое использование
```javascript
const user = {
  name: "Alex",
  age: 25,
  isAdmin: false
};

const json = JSON.stringify(user);
console.log(json); 
// '{"name":"Alex","age":25,"isAdmin":false}'
```

### 2. Использование отступов (`space`)
Если передать число в третий параметр, JSON станет "многострочным" с указанным количеством пробелов для каждого уровня вложенности.
```javascript
const user = { name: "Alex", age: 25 };
console.log(JSON.stringify(user, null, 2));
/*
{
  "name": "Alex",
  "age": 25
}
*/
```

### 3. Использование `replacer` (массив)
Можно указать только те ключи, которые мы хотим видеть в итоговой строке.
```javascript
const user = { name: "Alex", age: 25, secretId: 999 };
const json = JSON.stringify(user, ['name', 'age']);
console.log(json); // '{"name":"Alex","age":25}'
```

## Поведение для разных типов данных

Метод имеет строгие правила преобразования, так как формат JSON поддерживает не все типы данных JavaScript:

* **Числа, Строки, Логические значения:** Преобразуются в соответствующие значения JSON.
* **Объекты и Массивы:** Преобразуются рекурсивно.
* **`undefined`, Функции, Символы (`Symbol`):**
    * Внутри **объекта**: Просто пропускаются (ключ удаляется).
    * Внутри **массива**: Превращаются в `null`.
    * Если переданы как **самостоятельные значения**: Метод вернет `undefined`.
* **Объекты `Date`:** Автоматически преобразуются в ISO-строки (через вызов `date.toJSON()`).
* **`NaN` и `Infinity`:** Превращаются в `null`.

```javascript
const data = {
  test: undefined,
  func: () => {},
  arr: [undefined, 42, () => {}]
};

console.log(JSON.stringify(data)); 
// '{"arr":[null,42,null]}' (test и func в объекте исчезли)
```

## Важные нюансы

### Циклические ссылки
Если объект ссылается сам на себя (напрямую или через другие объекты), `JSON.stringify()` выдаст ошибку `TypeError: cyclic object value`.

### Метод `toJSON()`
Если у объекта есть метод с именем `toJSON`, то `JSON.stringify()` вызовет его и будет сериализовать результат выполнения этого метода вместо самого объекта.
```javascript
const room = {
  number: 23,
  toJSON() {
    return "Room number " + this.number;
  }
};

console.log(JSON.stringify(room)); // '"Room number 23"'
```

### Потеря точности BigInt
Значения типа `BigInt` не могут быть сериализованы в JSON напрямую. Попытка сделать это вызовет ошибку `TypeError`. Их нужно предварительно преобразовывать в строку.
