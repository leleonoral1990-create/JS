# Метод Object.fromEntries()

`Object.fromEntries()` — это статический метод, который преобразует список пар «ключ-значение» в объект. Он является логической противоположностью метода `Object.entries()`.



## Синтаксис

```javascript
Object.fromEntries(iterable);
```

**Параметры:**
* `iterable`: Итерируемый объект, такой как `Array` или `Map`, элементы которого являются списком пар (массивами из двух элементов) `[ключ, значение]`.

**Возвращаемое значение:**
* Новый объект, свойства которого определены переданными парами.

---

## Примеры использования

### 1. Преобразование массива в объект
Это самый простой случай использования, когда у вас есть массив массивов.

```javascript
const entries = [
  ['foo', 'bar'],
  ['baz', 42]
];

const obj = Object.fromEntries(entries);

console.log(obj);
// { foo: "bar", baz: 42 }
```

### 2. Преобразование Map в объект
Поскольку `Map` по умолчанию является итерируемым объектом, возвращающим пары `[ключ, значение]`, его можно напрямую конвертировать в обычный объект.

```javascript
const map = new Map();
map.set('name', 'John');
map.set('age', 25);

const user = Object.fromEntries(map);

console.log(user);
// { name: "John", age: 25 }
```

---

## Применение в реальном коде

### Трансформация (фильтрация) объектов
Обычные объекты нельзя фильтровать напрямую методами вроде `.filter()`. С помощью связки `entries` + `fromEntries` это становится возможным.

**Задача:** Оставить в объекте только те продукты, цена которых больше 100.

```javascript
const prices = {
  banana: 50,
  apple: 120,
  orange: 150
};

// 1. Превращаем объект в массив: Object.entries(prices)
// 2. Фильтруем массив: .filter(...)
// 3. Превращаем результат обратно в объект: Object.fromEntries(...)

const expensiveFruits = Object.fromEntries(
  Object.entries(prices).filter(([name, price]) => price > 100)
);

console.log(expensiveFruits);
// { apple: 120, orange: 150 }
```

---

## Важные нюансы

1. **Дублирование ключей:** Если итерируемый объект содержит несколько пар с одинаковым ключом, в итоговый объект попадет значение из **последней** встреченной пары.
   ```javascript
   const arr = [['a', 1], ['a', 2]];
   console.log(Object.fromEntries(arr)); // { a: 2 }
   ```
2. **Типы ключей:** При создании объекта ключи будут автоматически приведены к строкам (String) или символам (Symbol), даже если в исходном итерируемом объекте (например, в `Map`) они были числами или другими типами.
3. **Совместимость:** Метод появился в стандарте ES2019. В очень старых браузерах (например, IE) он не поддерживается без полифила.
