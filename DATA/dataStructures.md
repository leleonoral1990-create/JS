# Структуры данных

Структуры данных позволяют структурировать и организовывать множество примитивных данных.

---

## Объекты (Object)

Объекты — самая распространенная структура данных в JavaScript, служащая основой для всех остальных структур. Они состоят из свойств, где каждое свойство представляет собой пару **ключ / значение**.



### Основные правила
* **Ключ**: Всегда является строкой. Он связывается со значением (аналогично переменным).
* **Синтаксис**: Используются фигурные скобки `{}`.

```javascript
console.log({}) // Вывод пустого объекта
```

### Создание свойств
Для разделения ключа и значения используется двоеточие `:`, а для разделения нескольких свойств — запятая `,`.

```javascript
console.log({
  'awesome key': 'great value',
  'first key': 1,
  'second key': 22
})
```

### Допустимые идентификаторы
Если ключ является допустимым идентификатором (соответствует правилам именования переменных), кавычки можно опустить. В JavaScript предпочтительно использовать **camelCase**.

```javascript
console.log({
  validKey: 'valid value !'
})
```

### Вложенность и переменные
Объекты могут содержать другие объекты. Также в качестве значений свойств можно использовать переменные.

```javascript
const myStreet = {
  number: 175,
  label: 'boulevard',
  name: 'Matabiau',
}

const address = {
  country: 'France',
  town: 'Toulouse',
  postalCode: 31000,
  street: myStreet, // Вложенный объект из переменной
}
```

### Сокращенная запись (Property Shorthand)
Если идентификатор переменной совпадает с именем ключа, ключ можно опустить.

```javascript
console.log({
  firstname: 'Clement',
  lastname: 'Denis',
  address, // Автоматически будет использован ключ "address"
})
```

## Массивы (Array)

Массивы используются для хранения упорядоченных списков значений. По сути, в JavaScript массив — это объект со специальными правилами.



### Особенности массивов
* **Индексы**: Вместо строковых ключей используются числа, начиная с **0**.
* **Порядок**: Содержимое всегда сохраняет заданный порядок.
* **Свойство length**: Позволяет быстро получить количество элементов в списке.

### Синтаксис
Используются квадратные скобки `[]`. Указывать индексы вручную при создании не нужно.

```javascript
console.log([])        // Пустой массив
console.log([1, 2, 3]) // Массив с тремя числами
```

Это упрощенный синтаксис, который интерпретируется движком примерно так:
`{ '0': 1, '1': 2, '2': 3 }`

### Работа с переменными и вложенность
Массивы, как и объекты, являются значениями, поэтому их можно хранить в переменных, вкладывать друг в друга или смешивать с объектами.

```javascript
const allowedCountries = ['France', 'Spain', 'Russia']

// Массив массивов (матрица)
console.log([
  [32, 45],
  [-38, 57]
])

// Смешанная структура (объект, содержащий массивы с объектами)
console.log({
  head: [
    { x: 5, y: 5 },
    { x: 6, y: 4 }
  ],
  tail: [
    { x: 3, y: 7 }
  ]
})
```
