# Falsy значения в JavaScript

В JavaScript **falsy** (ложное) значение — это значение, которое приводится к `false` (лжи) при вычислении в логическом (boolean) контексте (например, в условиях `if` или циклах).

JavaScript автоматически использует приведение типов (type coercion), чтобы преобразовать любое значение в `Boolean` там, где это необходимо.

## Полный список Falsy-значений
В JavaScript существует строго ограниченный список значений, которые считаются ложными. Запомните их, так как **все остальные значения в языке являются truthy (истинными)**.

| Значение | Тип данных | Описание |
| :--- | :--- | :--- |
| `null` | Null | Ключевое слово `null` — означает намеренное отсутствие какого-либо значения. |
| `undefined` | Undefined | Примитивное значение `undefined` — переменная объявлена, но значение не задано. |
| `false` | Boolean | Само логическое значение "ложь". |
| `NaN` | Number | Not-A-Number (не число). Возникает при математических ошибках. |
| `0` | Number | Число ноль. Сюда же относятся `0.0`, `0x0` (в 16-ричной системе) и т.д. |
| `-0` | Number | Отрицательный ноль (в JS есть разница между 0 и -0). Включает `-0.0`, `-0x0` и т.д. |
| `0n` | BigInt | Ноль в формате BigInt. Сюда же относится `0x0n`. *(Примечание: отрицательного -0n не существует)*. |
| `""` | String | Пустая строка. Включает двойные `""`, одинарные `''` и обратные ` `` ` кавычки, внутри которых ничего нет. |
| `document.all` | Object | **Единственный falsy-объект** во всем JavaScript. Это историческое исключение (встроенное свойство браузера), оставленное для совместимости со старым кодом. |

*(Дополнительно: значения `null` и `undefined` также образуют отдельную группу так называемых **nullish** значений).*

## Примеры применения в коде

### Пропуск блока `if`
Поскольку все эти значения приводятся к `false`, код внутри условия не выполнится ни в одном из этих случаев:

```javascript
if (false)     { /* Не выполнится */ }
if (null)      { /* Не выполнится */ }
if (undefined) { /* Не выполнится */ }
if (0)         { /* Не выполнится */ }
if (-0)        { /* Не выполнится */ }
if (0n)        { /* Не выполнится */ }
if (NaN)       { /* Не выполнится */ }
if ("")        { /* Не выполнится */ }
```

### Поведение с логическим оператором И (`&&`)
Оператор логического "И" (`&&`) читает значения слева направо. Если он встречает **первое же falsy-значение**, он немедленно возвращает именно его (а не логическое `false`), и дальше код не проверяет.

```javascript
// Возвращает первый falsy-элемент (само значение false)
console.log(false && "dog"); 
// Результат: false

// 0 — это falsy, поэтому возвращается именно 0, строка "dog" игнорируется
console.log(0 && "dog");     
// Результат: 0

// "" (пустая строка) — это falsy, возвращается она
console.log("" && 42);       
// Результат: ""
```
