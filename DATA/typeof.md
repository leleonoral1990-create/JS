# Оператор `typeof`

Оператор `typeof` — это инструмент, который возвращает **строку**, указывающую тип значения (операнда), который вы ему передали. Это один из самых часто используемых операторов для проверки данных в JavaScript.

---

### Сводная таблица результатов

Вот все возможные значения, которые может вернуть этот оператор. Этот список исчерпывающий — движки JavaScript не возвращают ничего, кроме этого набора.



| Тип данных | Результат `typeof` |
| :--- | :--- |
| **Undefined** | `"undefined"` |
| **Null** | **`"object"`** (историческая ошибка) |
| **Boolean** | `"boolean"` |
| **Number** | `"number"` (включая `NaN` и `Infinity`) |
| **BigInt** | `"bigint"` |
| **String** | `"string"` |
| **Symbol** | `"symbol"` |
| **Function** | `"function"` |
| **Любой другой объект** (массивы, даты и т.д.) | `"object"` |

---

### Особенности и «странности»

#### 1. Числа и NaN
Даже если значение — `NaN` («не число»), `typeof` всё равно скажет, что это число.
```javascript
typeof NaN === "number"; // true
typeof Infinity === "number"; // true
```

#### 2. Великая ошибка `null`
Это классика JavaScript: `typeof null` возвращает `"object"`. 
> **Почему так?** В первой версии JS значения имели теги типа. Тег объекта был `0`. `null` представлялся как пустой указатель (0x00). Из-за этого нуля в теге он до сих пор считается «объектом». Попытки это исправить были отклонены, чтобы не сломать миллионы старых сайтов.

#### 3. Массивы vs Объекты
`typeof` не умеет отличать массив от обычного объекта — для него это всё `"object"`. 
Для точной проверки используйте `Array.isArray()` или `Object.prototype.toString.call()`.

#### 4. Обёртки через `new`
Если вы создаете строку или число через конструктор `new`, тип меняется на `"object"`. **Избегайте этого**, это считается плохой практикой.
```javascript
typeof new String("abc") === "object"; // Избегайте этого!
```

---

### Синтаксис и приоритеты

Оператор `typeof` имеет высокий приоритет. Это значит, что он выполнится раньше, чем, например, сложение. Чтобы узнать тип *результата* выражения, используйте скобки.

```javascript
const data = 99;
typeof data + " foo";   // "number foo" (сначала узнал тип 99, потом приклеил строку)
typeof (data + " foo"); // "string" (сначала сложил, потом узнал тип результата)
```

---

### Безопасность и «Мертвая зона» (TDZ)

`typeof` — единственный оператор, который «безопасен» для **необъявленных** переменных. Если переменной не существует, он просто вернет `"undefined"`, не вызывая ошибку.

**Однако**, это не работает с переменными `let` и `const` внутри их области видимости до того, как они объявлены. Это состояние называется **Временной мертвой зоной (TDZ)**.



```javascript
typeof someVar; // ReferenceError! (если someVar объявлена ниже через let или const)
let someVar;
```

### Создание более точной проверки

Поскольку стандартный `typeof` часто дает слишком общие ответы (например, `"object"` для всего), можно использовать кастомную функцию. Она опирается на `constructor.name` или `Symbol.toStringTag`.

```javascript
function type(value) {
  if (value === null) return "null";
  const baseType = typeof value;

  // Если не объект и не функция — возвращаем как есть
  if (!["object", "function"].includes(baseType)) return baseType;

  // Ищем имя конструктора (например, "Array", "Date", "Map")
  const className = value.constructor.name;
  if (className) return className;

  return baseType;
}

console.log(type([]));        // "Array"
console.log(type(new Date())); // "Date"
```
