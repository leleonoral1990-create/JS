# Math.sign()

---

## Описание
Статический метод **Math.sign()** определяет знак числа. Он сообщает нам, является ли число положительным, отрицательным или нулём.

Поскольку `Math` не является конструктором, метод всегда вызывается как `Math.sign()`.

---

## Синтаксис

```javascript
Math.sign(x)
```

**Параметры:**
* **x**: Число, знак которого нужно определить.

---

## Возвращаемое значение
Метод возвращает одно из пяти возможных значений:

| Условие | Результат |
| :--- | :--- |
| Число положительное | **1** |
| Число отрицательное | **-1** |
| Положительный ноль | **0** |
| Отрицательный ноль | **-0** |
| Невозможно определить (NaN, строка и т.д.) | **NaN** |

## Приведение типов (Coercion)
Как и другие методы `Math`, он пытается преобразовать аргумент в число перед проверкой:

```javascript
Math.sign("-3");  // -1 (строка превратилась в число -3)
Math.sign("foo"); // NaN (строку нельзя превратить в число)
Math.sign();      // NaN (аргумент отсутствует)
```

---

## Примеры

```javascript
Math.sign(3);     //  1
Math.sign(-3);    // -1
Math.sign(0);     //  0
Math.sign(-0);    // -0
Math.sign(NaN);   // NaN
```
