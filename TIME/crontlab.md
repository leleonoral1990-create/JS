# Синтаксис Cron-выражений (crontab.guru)

**Cron** — это классический планировщик задач в Unix-подобных операционных системах. Он позволяет запускать скрипты, программы или команды автоматически по заданному расписанию.

Сайт **[crontab.guru](https://crontab.guru/)** — это самый популярный и удобный интерактивный редактор, который переводит сложный синтаксис cron на человеческий язык.

---

## Формат выражения

Стандартное выражение cron состоит из **5 полей**, разделенных пробелами:

```text
* * * * *
| | | | |
| | | | +---- День недели (0 - 6) (Воскресенье = 0 или 7)
| | | +------ Месяц (1 - 12)
| | +-------- День месяца (1 - 31)
| +---------- Час (0 - 23)
+------------ Минута (0 - 59)
```

---

## Специальные символы (Операторы)

Вместо конкретных чисел можно использовать специальные символы для создания гибких расписаний:

1. **`*` (Звездочка) — Любое значение.**
   Означает "каждый". Если стоит в поле минут, значит "каждую минуту".
2. **`,` (Запятая) — Список значений.**
   Разделяет конкретные числа. `1,15,30` в поле минут означает запуск на 1-й, 15-й и 30-й минуте.
3. **`-` (Дефис) — Диапазон.**
   Определяет промежуток. `9-17` в поле часов означает "каждый час с 9:00 до 17:00".
4. **`/` (Слеш) — Шаг.**
   Используется вместе со звездочкой или диапазоном. `*/5` в поле минут означает "каждые 5 минут" (то есть 0, 5, 10, 15 и т.д.).

## Популярные примеры (Шпаргалка)

Здесь собраны самые частые сценарии, которые пригодятся в работе:

### Базовые
* `* * * * *` — Каждую минуту
* `0 * * * *` — Каждый час (в 00 минут)
* `0 0 * * *` — Каждый день в полночь (00:00)
* `0 0 * * 0` — Каждое воскресенье в полночь
* `0 0 1 * *` — В полночь 1-го числа каждого месяца

### С использованием операторов
* `*/15 * * * *` — Каждые 15 минут
* `0 */2 * * *` — Каждые 2 часа
* `0 9 * * 1-5` — В 09:00 каждый будний день (с понедельника по пятницу)
* `30 18 * * 1,3,5` — В 18:30 по понедельникам, средам и пятницам
* `0 9-18 * * *` — Каждый час с 09:00 до 18:00

## Важные нюансы

1. **Дни недели:** В классическом cron воскресенье можно обозначать как `0` так и `7`.
2. **ИЛИ между днем месяца и днем недели:** Если вы укажете конкретное значение и для *Дня месяца*, и для *Дня недели* (например, `0 0 15 * 1`), то задача выполнится **и** 15-го числа каждого месяца, **и** в каждый понедельник. Это частая ловушка!
3. **Нестандартные макросы:** Некоторые системы (но не все) поддерживают текстовые сокращения вместо 5 звездочек:
   * `@reboot` — Запуск один раз при загрузке системы
   * `@daily` (или `@midnight`) — Эквивалент `0 0 * * *`
   * `@hourly` — Эквивалент `0 * * * *`
