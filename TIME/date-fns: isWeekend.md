# Функция isWeekend() (библиотека date-fns)

Функция `isWeekend()` проверяет, выпадает ли указанная дата на выходной день (то есть на **субботу** или **воскресенье**).

Эта функция невероятно полезна при написании бизнес-логики. Например, когда вам нужно рассчитать сроки доставки товаров (исключая выходные), определить рабочие часы поддержки или просто по-другому подсветить дни в календаре (UI).

---

## Синтаксис

```javascript
import { isWeekend } from 'date-fns';

isWeekend(date)
```

**Параметры:**
* **`date`**: Дата для проверки. Должна быть объектом `Date` или числом (timestamp в миллисекундах).

**Возвращаемое значение:**
* `true`, если переданная дата — суббота или воскресенье.
* `false`, если это будний день (с понедельника по пятницу) или если передана некорректная дата (Invalid Date).

---

## Примеры использования

### 1. Проверка конкретных дат
Обратите внимание, что при создании даты через `new Date(год, месяц, день)`, месяцы в JavaScript начинаются с нуля (поэтому апрель — это `3`).

```javascript
import { isWeekend } from 'date-fns';

// 25 апреля 2026 года (Суббота)
const saturday = new Date(2026, 3, 25); 

// 27 апреля 2026 года (Понедельник)
const monday = new Date(2026, 3, 27);

console.log(isWeekend(saturday)); // true
console.log(isWeekend(monday));   // false
```

### 2. Проверка текущего дня
Часто используется в связке с `new Date()` или `Date.now()`, чтобы проверить сегодняшний день.

```javascript
if (isWeekend(Date.now())) {
  console.log("Ура, выходные! Служба поддержки работает в дежурном режиме.");
} else {
  console.log("Будний день. Офис открыт.");
}
```

---

## Важные нюансы

1. **Жесткая привязка к дням недели:** В логике `date-fns` выходными днями *всегда* считаются суббота и воскресенье. Если вы разрабатываете приложение для стран, где официальные выходные приходятся на другие дни (например, пятница и суббота в некоторых странах Ближнего Востока), стандартная `isWeekend()` вам не подойдет — придется писать кастомную проверку (например, используя функцию `getDay()`).
2. **Как всегда, никаких строк:** Начиная со второй версии `date-fns`, вы не можете передать строку вроде `'2026-04-25'` напрямую в функцию. Обязательно преобразуйте её в объект `Date`.
