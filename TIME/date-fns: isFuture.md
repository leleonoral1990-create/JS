# Функция isFuture() (библиотека date-fns)

Функция `isFuture()` проверяет, находится ли переданная дата в будущем относительно **текущего момента времени**. 

По сути, это очень удобный ярлык (шорткат), который заменяет более длинную конструкцию `isAfter(date, new Date())`. Она идеально подходит для проверки сроков годности, будущих записей в календаре или запланированных задач.

---

## Синтаксис

```javascript
import { isFuture } from 'date-fns';

isFuture(date)
```

**Параметры:**
* **`date`**: Дата, которую мы хотим проверить. Должна быть объектом `Date` или числом (timestamp).

**Возвращаемое значение:**
* `true`, если переданная дата наступит позже текущего момента.
* `false`, если дата уже прошла или является ровно текущей миллисекундой.

---

## Примеры использования

### 1. Проверка будущих и прошедших дат
```javascript
import { isFuture } from 'date-fns';

// Допустим, сегодня 2026 год.
const sciFiYear = new Date(2077, 0, 1); // 1 января 2077
const retroYear = new Date(1999, 11, 31); // 31 декабря 1999

console.log(isFuture(sciFiYear)); // true
console.log(isFuture(retroYear)); // false
```

### 2. Точность до миллисекунд
Поскольку проверка идет относительно `Date.now()`, даже сдвиг на одну секунду вперед будет считаться будущим.

```javascript
const now = Date.now();
const oneSecondLater = now + 1000;
const oneSecondAgo = now - 1000;

console.log(isFuture(oneSecondLater)); // true
console.log(isFuture(oneSecondAgo));   // false
```

---

## Важные нюансы

1. **Зависимость от системного времени:** Метод `isFuture()` напрямую зависит от того, какое время установлено на устройстве пользователя, выполняющего код. Если у пользователя на компьютере сбиты часы, функция выдаст результат относительно этого сбитого времени.
2. **Парсинг строк:** Как и в других функциях библиотеки (начиная со 2-й версии), не передавайте строки напрямую. Обязательно преобразуйте их в `Date`.
    ```javascript
    // ❌ Плохо
    isFuture('2030-01-01'); 
    
    // ✅ Хорошо
    isFuture(new Date('2030-01-01'));
    ```
