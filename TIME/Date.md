# Объект Date в JavaScript

`Date` — это встроенный объект в JavaScript для работы с датами и временем. Под капотом любая дата хранится как одно большое число — количество миллисекунд, прошедших с полуночи 1 января 1970 года по UTC (Unix Epoch).

---

## 1. Создание дат (Конструктор)

Создать объект даты можно четырьмя способами. Обратите внимание: метод всегда вызывается с ключевым словом `new`.

```javascript
// 1. Текущие дата и время
const now = new Date();

// 2. Из числа (timestamp в миллисекундах)
const fromTimestamp = new Date(1612137600000); 

// 3. Из строки (парсинг)
// Рекомендуется использовать только формат ISO 8601 (YYYY-MM-DDTHH:mm:ss.sssZ)
const fromString = new Date('2026-04-26T12:00:00');

// 4. Из компонентов: год, месяц, день, часы, минуты, секунды, мс
// ВНИМАНИЕ: Месяцы начинаются с 0 (0 = январь, 11 = декабрь)
const fromComponents = new Date(2026, 3, 26, 12, 30, 0); // 26 апреля 2026, 12:30
```

---

## 2. Получение данных (Геттеры)

У объекта `Date` есть множество методов для извлечения конкретных частей даты. Большинство из них работают по локальному времени пользователя.

```javascript
const date = new Date(2026, 3, 26, 15, 30); // 26 апреля 2026 (Воскресенье)

console.log(date.getFullYear()); // 2026 (всегда 4 цифры)
console.log(date.getMonth());    // 3 (Апрель, так как счет с нуля)
console.log(date.getDate());     // 26 (День месяца)
console.log(date.getDay());      // 0 (День недели: 0 = Воскресенье, 1 = Понедельник...)
console.log(date.getHours());    // 15
console.log(date.getMinutes());  // 30
console.log(date.getTime());     // 1777199400000 (Timestamp)
```
*Примечание: Для каждого такого метода существует аналог для UTC-времени, например: `getUTCHours()`, `getUTCDate()`.*

---

## 3. Изменение данных (Сеттеры)

Вы можете изменять компоненты существующей даты. 
**Важно:** Методы `set...` **мутируют** (изменяют) оригинальный объект.

```javascript
const myDate = new Date(2026, 0, 15); // 15 января 2026
myDate.setFullYear(2030);
myDate.setMonth(11); // Декабрь

console.log(myDate); // 15 декабря 2030
```

### Магия автоисправления (Автокоррекция)
Если вы передадите сеттеру (или конструктору) значение, выходящее за допустимые пределы, `Date` автоматически пересчитает дату:

```javascript
// В январе 31 день. Попробуем установить 33-е января.
const autoDate = new Date(2026, 0, 33); 
console.log(autoDate); // 2 Февраля 2026 (перескочил на следующий месяц!)
```

---

## 4. Статические методы

Эти методы вызываются напрямую у класса `Date`, а не у созданного объекта `new Date()`.

* **`Date.now()`**: Возвращает текущий timestamp (число миллисекунд) без создания объекта даты. Это самый быстрый способ засечь время.
* **`Date.parse(dateString)`**: Читает строку и возвращает timestamp. Если строка некорректна, вернет `NaN`.

```javascript
const start = Date.now();
// ... какой-то долгий код ...
const end = Date.now();
console.log(`Прошло ${end - start} мс`);
```

---

## 5. Форматирование в строку

Встроенные методы для превращения даты в читаемый текст:

```javascript
const d = new Date('2026-04-26T12:00:00Z');

console.log(d.toISOString());       // "2026-04-26T12:00:00.000Z" (Идеально для API и баз данных)
console.log(d.toDateString());      // "Sun Apr 26 2026" (Только дата, по-английски)
console.log(d.toLocaleDateString());// "26.04.2026" (Формат зависит от настроек браузера юзера)
console.log(d.toLocaleString());    // "26.04.2026, 17:00:00" (Дата + Время)
```

---

## 🚨 Главные ловушки (Шпаргалка ошибок)

1.  **Месяцы с нуля:** `new Date(2026, 1, 1)` — это 1 **Февраля**, а не января!
2.  **Дни недели с нуля:** `getDay()` возвращает от `0` (Воскресенье) до `6` (Суббота).
3.  **Разница между Date и Day:**
    * `getDate()` — день месяца (1-31).
    * `getDay()` — день недели (0-6).
4.  **Мутабельность:** Если вы присвоите дату новой переменной и измените её, оригинал тоже изменится.
    ```javascript
    const d1 = new Date();
    const d2 = d1; 
    d2.setFullYear(2099); // d1 тоже станет 2099 годом!
    // Правильно клонировать: const d2 = new Date(d1);
    ```
