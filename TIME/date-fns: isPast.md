# Функция isPast() (библиотека date-fns)

Функция `isPast()` проверяет, находится ли переданная дата в прошлом относительно **текущего момента времени**.

Это логическая противоположность функции `isFuture()`. Она очень удобна для проверки того, истек ли срок действия (например, подписки, токена авторизации или купона на скидку).

---

## Синтаксис

```javascript
import { isPast } from 'date-fns';

isPast(date)
```

**Параметры:**
* **`date`**: Дата, которую необходимо проверить. Должна быть объектом `Date` или числом (timestamp в миллисекундах).

**Возвращаемое значение:**
* `true`, если переданная дата уже наступила (находится в прошлом).
* `false`, если дата находится в будущем или является ровно текущей миллисекундой.

---

## Примеры использования

### 1. Базовая проверка дат
```javascript
import { isPast } from 'date-fns';

// Допустим, сегодня 2026 год.
const retroYear = new Date(1999, 11, 31); // 31 декабря 1999
const sciFiYear = new Date(2077, 0, 1); // 1 января 2077

console.log(isPast(retroYear)); // true (уже прошло)
console.log(isPast(sciFiYear)); // false (еще не наступило)
```

### 2. Точность до миллисекунд
Как и `isFuture()`, функция `isPast()` сравнивает время с точностью до миллисекунды (используя `Date.now()`).

```javascript
const now = Date.now();
const oneSecondAgo = now - 1000;
const oneSecondLater = now + 1000;

console.log(isPast(oneSecondAgo));   // true
console.log(isPast(oneSecondLater)); // false
```

### 3. Пример из реальной жизни (Проверка токена)
Частый сценарий — проверить, истек ли срок действия токена безопасности пользователя:
```javascript
const tokenExpirationDate = new Date('2026-04-26T12:00:00');

if (isPast(tokenExpirationDate)) {
  console.log("Ваша сессия истекла. Пожалуйста, войдите снова.");
} else {
  console.log("Доступ разрешен.");
}
```

---

## Важные нюансы

Правила работы с `isPast()` абсолютно идентичны правилам `isFuture()`:

1. **Зависимость от локального времени:** Функция смотрит на часы того устройства, на котором выполняется код. Если локальное время пользователя спешит или отстает, результат будет рассчитываться относительно этого (возможно, неверного) времени.
2. **Никаких строк напрямую (v2+):** Начиная со второй версии библиотеки, передача строк (например, `isPast('2020-01-01')`) недопустима. Сначала обязательно преобразуйте строку в объект даты: `isPast(new Date('2020-01-01'))`.
