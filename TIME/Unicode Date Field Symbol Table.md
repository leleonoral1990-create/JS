# Таблица символов форматирования дат Unicode (UTS #35)

Эта таблица описывает стандарт форматирования дат Unicode (Unicode Technical Standard #35). Именно этот стандарт используется под капотом в современных библиотеках, таких как **`date-fns`** (в функции `format()`), а также во многих других языках и фреймворках.

Ниже собраны самые важные и часто используемые токены (символы).

*Примечание: Примеры приведены для даты **26 апреля 2026 года, 15:05:09 (воскресенье)**.*

## Год, Месяц и День

| Токен | Описание | Пример | Разница / Нюанс |
| :--- | :--- | :--- | :--- |
| **`y`** | Год | `2026` | 1, 2026 |
| **`yy`** | Год (2 цифры) | `26` | Только последние 2 цифры |
| **`yyyy`** | Год (4 цифры) | `2026` | Дополняется нулями слева (0045, 2026) |
| **`M`** | Месяц (число) | `4` | 1..12 |
| **`MM`** | Месяц (2 цифры) | `04` | 01..12 |
| **`MMM`** | Месяц (сокр. слово) | `Apr` / `апр.` | Локализуется (зависит от языка) |
| **`MMMM`** | Месяц (полное слово) | `April` / `апрель` | Локализуется |
| **`d`** | День месяца | `26` | 1..31 |
| **`dd`** | День месяца (2 цифры)| `26` | 01..31 |
| **`D`** | День в году | `116` | 1..365 (366 в високосный). **Не путайте с `d`!** |
| **`DDD`** | День в году (3 цифры)| `116` | 001..365 |

## Дни недели и Недели

| Токен | Описание | Пример | Разница / Нюанс |
| :--- | :--- | :--- | :--- |
| **`E`**..**`EEE`** | День недели (сокр.) | `Sun` / `вс` | Локализуется |
| **`EEEE`** | День недели (полный) | `Sunday` / `воскресенье` | Локализуется |
| **`i`** | Номер дня недели | `7` | По стандарту ISO (1 - пн, 7 - вс) |
| **`w`** | Неделя в году | `17` | 1..53 |
| **`ww`** | Неделя в году (2 цифры) | `17` | 01..53 |

## Время (Часы, Минуты, Секунды)

⚠️ **Частая ловушка:** Заглавные и строчные буквы имеют огромное значение! `m` — это минуты, а `M` — месяцы.

| Токен | Описание | Пример | Разница / Нюанс |
| :--- | :--- | :--- | :--- |
| **`a`** | AM / PM | `PM` | До полудня / После полудня |
| **`h`** | Час (12-часовой формат)| `3` | 1..12 (AM/PM) |
| **`hh`** | Час (12-ч, 2 цифры) | `03` | 01..12 (AM/PM) |
| **`H`** | Час (24-часовой формат)| `15` | 0..23 |
| **`HH`** | Час (24-ч, 2 цифры) | `15` | 00..23 |
| **`m`** | Минуты | `5` | 0..59 |
| **`mm`** | Минуты (2 цифры) | `05` | 00..59 |
| **`s`** | Секунды | `9` | 0..59 |
| **`ss`** | Секунды (2 цифры) | `09` | 00..59 |
| **`SSS`**| Миллисекунды | `042` | 000..999 |

## Часовые пояса

| Токен | Описание | Пример | Описание |
| :--- | :--- | :--- | :--- |
| **`Z`** | Смещение базовое | `+0500` | Разница с UTC без двоеточия |
| **`ZZZZZ`** | Смещение по ISO | `+05:00` | Разница с UTC с двоеточием |
| **`z`** | Короткая зона | `EST` | Аббревиатура временной зоны |
| **`zzzz`** | Полная зона | `Eastern Standard Time` | Полное название |

### Экранирование текста (Escape-последовательности)

Если вам нужно вставить в формат обычный текст, который случайно совпадает с токенами (например, буквы `h`, `m`, `s`), его нужно обернуть в одинарные кавычки `' '`.

**Пример в коде (date-fns):**
```javascript
import { format } from 'date-fns';

const date = new Date(2026, 3, 26, 15, 5, 0);

// "Today is 26th of April, 2026"
console.log(format(date, "'Today is' do 'of' MMMM, yyyy")); 

// "15:05"
console.log(format(date, "HH:mm")); 
```
