# Функция isAfter() (библиотека date-fns)

Функция `isAfter()` сравнивает две даты и проверяет, находится ли первая дата **строго позже** (хронологически), чем вторая.

Это отличная, читаемая альтернатива стандартному сравнению через оператор больше (`date1 > date2`), которая делает код более понятным (декларативным).

---

## Синтаксис

```javascript
import { isAfter } from 'date-fns';

isAfter(date, dateToCompare)
```

**Параметры:**
1.  **`date`**: Дата, которую мы проверяем (первая дата).
2.  **`dateToCompare`**: Дата, с которой мы сравниваем (вторая дата).

*Оба параметра должны быть объектами `Date` или числами (timestamp в миллисекундах).*

**Возвращаемое значение:**
* `true`, если первая дата произошла позже второй.
* `false`, если первая дата произошла раньше второй или если они абсолютно равны.

---

## Примеры использования

### 1. Базовое сравнение
```javascript
import { isAfter } from 'date-fns';

const date1 = new Date(2026, 4, 25); // 25 мая 2026 (месяцы в JS с нуля)
const date2 = new Date(2026, 4, 20); // 20 мая 2026

console.log(isAfter(date1, date2)); // true (25 мая идет после 20 мая)
console.log(isAfter(date2, date1)); // false
```

### 2. Сравнение одинаковых дат (Строгость)
Функция выполняет **строгое** сравнение (аналог `>`). Если даты совпадают вплоть до миллисекунды, функция вернет `false`.

```javascript
const time1 = new Date('2026-04-26T12:00:00');
const time2 = new Date('2026-04-26T12:00:00');

console.log(isAfter(time1, time2)); // false (они равны, одна не позже другой)
```

### 3. Работа с числами (Timestamp)
Вместо объектов Date можно смело передавать метки времени.
```javascript
const currentMs = Date.now();
const pastMs = currentMs - 10000; // 10 секунд назад

console.log(isAfter(currentMs, pastMs)); // true
```

---

## Важные нюансы

1. **Точность до миллисекунд:** Метод `isAfter()` сравнивает точное время. Если у вас две даты обозначают один и тот же день, но первая произошла в `10:00`, а вторая в `09:00`, метод вернет `true`. (Если вам нужно сравнить только календарные дни без учета времени, используйте `isAfter` в связке с очисткой времени, либо специализированные методы, о которых вы, вероятно, узнаете дальше).
2. **Типы данных (v2+):** Как и в функции `isValid`, начиная со второй версии `date-fns`, вы **не можете** передавать строки напрямую (например, `isAfter('2026-01-01', '2025-01-01')` вызовет ошибку или вернет непредсказуемый результат). Строки нужно сначала оборачивать в `new Date(...)` или парсить с помощью функции `parseISO()`.
