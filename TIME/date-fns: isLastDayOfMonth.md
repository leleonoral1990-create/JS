# Функция isLastDayOfMonth() (библиотека date-fns)

Функция `isLastDayOfMonth()` проверяет, выпадает ли указанная дата на **последний день своего месяца**.

Главная ценность этой функции в том, что она "знает" календарь. Вам не нужно вручную прописывать массивы с количеством дней (`[31, 28, 31, ...]`) и высчитывать високосные годы — функция делает это под капотом.

---

## Синтаксис

```javascript
import { isLastDayOfMonth } from 'date-fns';

isLastDayOfMonth(date)
```

**Параметры:**
* **`date`**: Дата, которую мы проверяем. Должна быть объектом `Date` или числом (timestamp).

**Возвращаемое значение:**
* `true`, если переданная дата — это последний день текущего месяца.
* `false`, если это любой другой день.

---

## Примеры использования

### 1. Базовая проверка месяцев (30 и 31 день)
*Напоминание: при создании `new Date(год, месяц, день)`, счет месяцев начинается с нуля (0 - январь, 3 - апрель).*

```javascript
import { isLastDayOfMonth } from 'date-fns';

const endOfJan = new Date(2026, 0, 31); // 31 января 2026
const middleOfJan = new Date(2026, 0, 30); // 30 января 2026
const endOfApr = new Date(2026, 3, 30); // 30 апреля 2026 (в апреле 30 дней)

console.log(isLastDayOfMonth(endOfJan));     // true
console.log(isLastDayOfMonth(middleOfJan));  // false
console.log(isLastDayOfMonth(endOfApr));     // true
```

### 2. Умная работа с февралем (Високосные годы)
Функция автоматически определяет високосный год, поэтому вам не нужно переживать за 28-е и 29-е февраля.

```javascript
// 2024 год - високосный
const leapYearFeb28 = new Date(2024, 1, 28);
const leapYearFeb29 = new Date(2024, 1, 29);

console.log(isLastDayOfMonth(leapYearFeb28)); // false (в 2024 году есть 29-е)
console.log(isLastDayOfMonth(leapYearFeb29)); // true

// 2026 год - обычный
const normalYearFeb28 = new Date(2026, 1, 28);

console.log(isLastDayOfMonth(normalYearFeb28)); // true (в 2026 году февраль заканчивается 28-го)
```

---

## Важные нюансы

1. **Время игнорируется:** Функция проверяет именно *календарный день*. Неважно, какое время установлено в объекте `Date` (будь то `00:00:01` или `23:59:59`) — если дата выпадает на последний день месяца, результат будет `true`.
2. **Как всегда, никаких строк напрямую:** В `date-fns` версии 2+ нельзя передавать строки (например, `'2026-02-28'`). Обязательно "оборачивайте" их в объект: `isLastDayOfMonth(new Date('2026-02-28'))`.
