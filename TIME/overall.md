# Итоговый конспект: Работа со временем в JavaScript (TIME)

Этот блок охватывает всё: от базовых манипуляций с датами в чистом JS до продвинутых библиотек, форматирования по мировым стандартам и планирования задач по расписанию.

---

## 1. Нативный объект `Date`
Объект `Date` — это фундамент. Время в JS измеряется в миллисекундах, прошедших с 1 января 1970 года (Unix Epoch).



### Основные правила:
* **Месяцы начинаются с 0:** `0` — январь, `11` — декабрь.
* **Дни недели:** `0` — воскресенье, `6` — суббота.
* **Мутабельность:** Методы `set...` изменяют текущий объект. Чтобы создать копию, используйте `new Date(originalDate)`.

```javascript
// Создание
const now = new Date();
const spring = new Date(2026, 2, 1); // 1 марта 2026

// Получение (Getters)
console.log(spring.getFullYear()); // 2026
console.log(spring.getMonth());    // 2 (Март)
console.log(spring.getDate());     // 1 (Число)
console.log(spring.getDay());      // 0 (Воскресенье)

// Статика
const timestamp = Date.now(); // Текущие мс без создания объекта
```

## 2. Библиотека `date-fns`
Библиотека предоставляет "чистые" функции для работы с датами, которые не мутируют исходные данные и делают код читаемым.

| Функция | Описание |
| :--- | :--- |
| **`isValid(date)`** | Проверяет, является ли объект корректной датой (не `Invalid Date`). |
| **`isAfter(d1, d2)`** | Возвращает `true`, если первая дата строго позже второй. |
| **`isBefore(d1, d2)`** | Возвращает `true`, если первая дата строго раньше второй. |
| **`isFuture(date)`** | Проверяет, наступит ли дата позже текущего момента (`Date.now()`). |
| **`isPast(date)`** | Проверяет, прошла ли уже эта дата. |
| **`isWeekend(date)`** | Проверяет, является ли день субботой или воскресеньем. |
| **`isLastDayOfMonth(d)`** | Возвращает `true`, если это последний день календарного месяца. |

```javascript
import { isAfter, isWeekend, isLastDayOfMonth } from 'date-fns';

const date = new Date(2024, 1, 29); // 29 февраля 2024 (високосный)

console.log(isWeekend(date));        // false (четверг)
console.log(isLastDayOfMonth(date)); // true
```

## 3. Таблица символов форматирования (Unicode)
Эти токены используются в `date-fns` (метод `format`) и других системах для превращения даты в строку.



* **`yyyy`** — Год из 4 цифр (2026).
* **`MM`** — Месяц числом с нулем (04). **`MMMM`** — Полное название (Апрель).
* **`dd`** — Число месяца с нулем (01-31).
* **`do`** — Число с порядковым номером (1-е, 2-е).
* **`EEEE`** — Полный день недели (Воскресенье).
* **`HH:mm:ss`** — Время в 24-часовом формате.
* **`'текст'`** — Экранирование обычных слов внутри шаблона.

## 4. Синтаксис Cron (Планировщик)
Используется для запуска кода по расписанию (например, "каждый понедельник в 9 утра").

```text
* * * * *
|  |  |  |  |
|  |  |  |  +-- День недели (0-6)
|  |  |  +----- Месяц (1-12)
|  |  +-------- Число месяца (1-31)
|  +----------- Час (0-23)
+-------------- Минута (0-59)
```

**Операторы:**
* `*` — Любое значение (каждую минуту/час).
* `,` — Список (запуск в `10,20,30` минут).
* `-` — Диапазон (с `9-17` часов).
* `/` — Шаг (`*/15` — каждые 15 единиц).

## Комплексный пример кода

Представим задачу: проверить, является ли сегодня крайним сроком оплаты (последний день месяца), и если да — вывести красиво отформатированную дату.

```javascript
import { isLastDayOfMonth, format, isFuture, isValid } from 'date-fns';
import { ru } from 'date-fns/locale';

function checkPaymentStatus(userDate) {
    // 1. Проверка на валидность
    if (!isValid(userDate)) return "Ошибка: некорректная дата";

    // 2. Проверка, не в прошлом ли дата
    if (!isFuture(userDate) && !isLastDayOfMonth(userDate)) {
        return "Срок оплаты уже прошел.";
    }

    // 3. Логика последнего дня месяца
    if (isLastDayOfMonth(userDate)) {
        // Форматируем дату в стиле: "Воскресенье, 31-е мая 2026"
        const prettyDate = format(userDate, "EEEE, do MMMM yyyy", { locale: ru });
        return `Сегодня дедлайн! Крайний срок: ${prettyDate}`;
    }

    return "До конца месяца еще есть время.";
}

const today = new Date(2026, 4, 31); // 31 мая 2026
console.log(checkPaymentStatus(today));
// Вывод: "Сегодня дедлайн! Крайний срок: воскресенье, 31-е мая 2026"
```
