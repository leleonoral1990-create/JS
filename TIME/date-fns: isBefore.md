# Функция isBefore() (библиотека date-fns)

Функция `isBefore()` сравнивает две даты и проверяет, находится ли первая дата **строго раньше** (хронологически), чем вторая. 

По сути, это логическая противоположность уже изученной вами функции `isAfter()`. Она делает код, проверяющий прошедшие или будущие события, читаемым как обычный английский текст.

---

## Синтаксис

```javascript
import { isBefore } from 'date-fns';

isBefore(date, dateToCompare)
```

**Параметры:**
1.  **`date`**: Дата, которую мы проверяем (первая дата).
2.  **`dateToCompare`**: Дата, с которой мы сравниваем (эталонная вторая дата).

*Оба параметра должны быть объектами `Date` или числами (timestamp в миллисекундах).*

**Возвращаемое значение:**
* `true`, если первая дата произошла раньше второй (меньше).
* `false`, если первая дата произошла позже второй или если они абсолютно равны.

---

## Примеры использования

### 1. Базовое сравнение дат
```javascript
import { isBefore } from 'date-fns';

const date1 = new Date(2026, 4, 15); // 15 мая 2026
const date2 = new Date(2026, 4, 20); // 20 мая 2026

console.log(isBefore(date1, date2)); // true (15 мая наступает раньше 20 мая)
console.log(isBefore(date2, date1)); // false
```

### 2. Сравнение одинаковых дат (Строгость)
Как и `isAfter`, функция `isBefore` выполняет **строгое** сравнение (аналог `<`). Если даты совпадают до миллисекунды, она вернет `false`.

```javascript
const time1 = new Date('2026-04-26T12:00:00');
const time2 = new Date('2026-04-26T12:00:00');

console.log(isBefore(time1, time2)); // false (они равны, первая дата не раньше)
```

### 3. Работа с числами (Timestamp)
Вы можете передавать количество миллисекунд напрямую, что удобно при работе с `Date.now()`.
```javascript
const currentMs = Date.now();
const futureMs = currentMs + 60000; // 1 минута в будущем

console.log(isBefore(currentMs, futureMs)); // true (текущее время раньше будущего)
```

---

## Важные нюансы (напоминание)

Правила работы здесь точно такие же, как и у остальных функций семейства `date-fns` версии 2+:

1. **Точность до миллисекунд:** Если две даты приходятся на один и тот же день, но у одной время `10:00`, а у другой `15:00`, функция будет учитывать это время. (Первая окажется `before` второй).
2. **Никаких строк:** Не передавайте строки напрямую `isBefore('2026-01-01', '2026-02-01')`. Во второй версии `date-fns` это приведет к ошибкам. Всегда переводите строки в объекты `Date` перед сравнением.
